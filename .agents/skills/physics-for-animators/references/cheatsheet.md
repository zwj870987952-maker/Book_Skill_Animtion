# 决策规则速查 — 动画师物理学

| 能力 | 一句话规则 |
|---|---|
| 奇数定律加速标尺 | 恒定加速度下逐帧位移增量比为 1:3:5:7:9，累计位移与时间平方成正比 |
| 自由落体与抛体运动解耦 | 自由落体时间与高度平方根成正比；时间过半仅下落 25% 距离；抛体水平匀速与垂直重力严格正交解耦 |
| 重心稳定与支撑面倾覆判定 | 重力垂线必须穿过触地支撑多边形底面内部；一旦超出边界立即产生重力倾覆力矩倒地或触发迈步代偿 |
| 摩擦阻尼与风阻终端速度 | 动摩擦力产生恒定反向减速度使物体平稳刹停；高空下落受空气阻力限制在终端速度（人类约54m/s）不再加速 |
| 关节生物杠杆与转动惯量调速 | 肢体主要关节为第三类速度杠杆以小位移换高末端速度；空中角动量守恒下抱膝团身使转动惯量暴跌、旋转角速度飙升 |
| 打击冲量与后坐受力时序 | 打击破坏力由接触压缩时间 delta t 决定（硬撞1帧爆发巨力，软撞6帧平滑缓冲）；出拳端必须承受等大反向后坐力矩 |
| 角色跳跃全周期动力学 | 跳跃由推地蓄力（4-6帧）、空中重力抛体与深蹲着地缓冲（3-8帧）三段闭环组成 |
| 行走倒单摆能量转换与肩髋扭转 | 行走如同倒单摆，过路点势能最高速度最慢，触地点动能最高速度最快；骨盆与肩甲骨反向旋转抵消角动量 |
| 次级运动长度单摆与表面积风阻 | 悬垂物自振周期与长度平方根成正比（短发延迟1-2帧，长发长披风延迟5-8帧）；迎风表面积决定阻力凹陷曲率 |
| 液体黏度倾倒与浅水碎浪动力学 | 低黏度液体倾倒飞溅成薄膜雨滴，高黏度流体呈光滑连续圆柱堆叠成线圈；水深小于半波长时底部摩擦促使波峰向前卷倒成管浪 |
| 爆炸热浮力涡流与脆性碎裂扩散 | 大爆炸由闪爆、热浮力上升外翻形成甜甜圈状环形涡流蘑菇头与地面吸附烟柱组成；脆性碎裂先由中心辐射直线裂纹，再由同心环裂纹贯通 |
| 光线平方反比衰减与几何半影光学 | 光照强度按距离平方反比二次方衰减；点光源产生全本影硬边，面光源根据遮挡物到受影面距离成正比扩展柔和半影 |
