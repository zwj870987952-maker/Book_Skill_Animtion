# 能力卡: 画幅比例、银幕宽高比与画框心理压迫 (Aspect Ratios & Psychological Framing)

## Rationale (核心原理)
画框（The Frame）从来不是一个中立的容器，它是导演对现实世界的**第一道暴力的戏剧裁剪**。
不同的银幕宽高比（Aspect Ratio）具有截然不同的心理压迫与美学场域属性：
- **1.33:1 (4:3 学院画幅 - Academy Ratio)**:
  垂直高度与水平宽度几乎均等，极度强调人物面部的垂直延伸与封闭感，剥离周围环境干扰，天然制造幽闭、禁锢、压抑与心理内省的窒息感；
- **1.85:1 (16:9 现代经典宽银幕)**:
  最契合人类双眼常规视野的戏剧平衡画幅，兼顾人物躯干表演与适度环境空间；
- **2.39:1 (宽银幕 Cinemascope / Anamorphic)**:
  极端延展的水平全景画幅，允许两个角色在画框两极进行漫长的水平对峙，展现无垠地平线、宏大史诗感与孤独感。
Marcos Mateu-Mestre 告诫：“在动笔画分镜之前，选错画幅就等于让交响乐选错了乐器！”

## Instruction (画幅心理学选用与构图自适应四步规程)

### 1. 三大经典画幅空间场域心智模型
```
  [ 1.33:1 (4:3) 垂直幽闭画框 ] --------> 垂直压迫、人物特写、囚徒牢笼、古典心理剧
  +-----------------+
  |     (头颅)      |
  |     (胸腔)      |
  +-----------------+

  [ 2.39:1 (Cinemascope) 水平超宽画框 ] -> 史诗荒原、超远水平对峙、环境吞噬、公路电影
  +-----------------------------------------------------------+
  | (角色 A 极左) ------------ 巨大水平地平线负空间 ------------ (角色 B 极右) |
  +-----------------------------------------------------------+
```

### 2. 画幅心理学实战四步流
1. **剧情核心冲突维度判定（Dimension of Conflict）**:
   - 冲突是向上挣扎与被天花板压制（垂直冲突）？还是向远方逃亡与荒野对抗（水平冲突）？
2. **选定银幕宽高比（Lock the Aspect Ratio）**:
   - 监狱、精神病院、心理惊悚：果断采用 1.33:1；
   - 西部牛仔对决、星际穿梭、宏大史诗战役：果断锁定 2.39:1；
3. **在 2.39:1 宽银幕中运用多重子框架（Use Sub-Frames in Scope）**:
   - 宽银幕画单人特写容易显得两侧空旷无物，必须利用门框、树干、阴影在超宽画幅内部切割出局部 1:1 的子画框（Sub-Framing）；
4. **压迫边缘裁切（Crop for Claustrophobia）**:
   - 在 1.33:1 画幅中，刻意让角色的头顶或下巴被画框上边缘切断，制造无法呼吸的逼仄感。

## Actionable Example (展现一名宇航员在狭窄救生舱中的绝望)
1. **画幅决策**: 选用 1.33:1 封闭画幅；
2. **画框压迫构图**:
   - 宇航员头盔面罩几乎填满整个画框，头盔反光玻璃与金属边缘紧贴画框四周；
   - 视平线卡在双眼瞳孔处，左侧是狭窄氧气阀门的冰冷机械阴影，右侧是急促闪烁的警报红光；
   - 画框上下边缘极其残忍地截断了头盔顶部与宇航服领口，没有任何留白与透气余地；
3. **结果**: 观众仿佛被一同塞进了这个铁棺材般的救生舱中，心跳与窒息感油然而生。

## Constraints (约束与禁止)
- **严禁忽视画幅比例随意涂画**: 绘制分镜严禁画在没有标准宽高比边框的空白纸上，必须从第一笔起受画框边界约束；
- **严禁在宽银幕中让角色孤立居中而忽略两侧**: 2.39:1 画幅若无视两侧广阔空间，会导致构图空洞松散，必须妥善布局两侧的负空间或次要信息。

## Verification (验收标准)
- **画幅情感契合度**: 画幅比例是否精准放大了该镜头的核心情绪（是封闭压抑还是宏大荒凉）；
- **边缘张力测试**: 角色与物体的排布是否与画框物理边缘产生紧张而有力的几何咬合。
