# 决策规则速查 — 分镜构图圣经：墨水构图 (Framed Ink: Drawing and Composition for Visual Storytellers)

| 能力 | 一句话规则 |
|---|---|
| 视平线高度、仰俯视夹角与镜头心理学 | 以视平线垂直位置与仰角俯角掌控受众心理投射，确立压迫、主导或脆弱等核心情感基调 |
| 黑白纯明度分布、深沉暗调与剪影可读性 | 确立 60-30-10 黑白两极明度结构，依托深黑硬边阴影与纯黑剪影实现 0.1 秒故事瞬间可读性 |
| 对角斜线、尖锐三角形与几何张力构图 | 打破横平竖直呆板网格，运用倾斜对角线与锐角三角形在画面中注入失衡动能与危险悬念 |
| 环境线条引导、视线牵引与黄金焦点流线 | 利用阴影边缘、地表透视反光与角色视线构建连续导流轨道，将瞳孔在 0.1 秒内牵引至核心叙事靶点 |
| 前景压迫、中景叙事与远景空气纵深 | 以前景暗部框架制造代入与压迫感，中景展开角色冲突，远景大气透视制造无垠空间纵深 |
| 画幅比例、银幕宽高比与画框心理压迫 | 驾驭 4:3 幽闭压迫、16:9 经典平衡与 2.39:1 宽银幕宏大对峙，让画框边缘成为强有力的叙事施压者 |
| 分镜头连续视线轨迹守恒与剪辑流线 | 在画格切换间维持受众瞳孔物理落点平滑滑动，严格遵循 180° 动作轴线守恒与视觉动量对撞 |
| 明暗对照法、戏剧光斑与光影情感基调 | 运用极度深沉阴影与锐利切割光斑雕刻形态，顶光审判、底光诡谲与侧光分裂的情感基调控制 |
| 尺度悬殊对比、环境吞噬与角色威严霸气 | 以 5% 渺小个体对抗 95% 浩瀚吞噬环境，或以前景庞然大物衬托远景微小猎物制造绝对支配 |
| 广角透视冲击 vs 长焦空间压缩窒息感 | 广角拉伸纵深距离强化冲撞爆发与孤立疏离，长焦压缩空间让追击者紧贴猎物制造窒息绝望 |
| 留白力量、纯粹极简与负空间引力场 | 以大面积空旷留白释放深沉心理引力，无情剔除视觉杂质，赋予叙事纯粹而锋利的情感重力 |
| 故事板节拍编排、景别交替与动作分镜流水线 | 全景建立、中景推进与特写爆破的戏剧节拍交替，编排具有电影呼吸感的动作故事板流水线 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
