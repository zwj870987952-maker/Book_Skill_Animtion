# 能力卡: 躯干可活动体块与单脚承重对立平衡 (Movable Masses & Contrapposto)

## Rationale (核心原理)
很多 3D 角色在摆姿势（Posing）时，看起来如同僵尸立正，缺乏内在重力对抗的动态平衡感。
Uldis Zarins 明确指出：**人体躯干在结构力学上是由三大互不形变的“刚性可活动体块”（Movable Masses）与两大“弹性铰链”（Flexible Connectors）构成的动力学系统**：
- **三大刚性块面**：头颅（颅骨方盒）、胸廓（胸骨与肋骨蛋形笼）、骨盆（骨性碗盆）；
- **两大弹性铰链**：颈椎（连接头颅与胸廓）与腰椎（连接胸廓与骨盆）。
在经典单脚承重对立平衡（Contrapposto）中，三大体块永远保持**反向倾斜（Counter-Tilt）与反向扭转（Counter-Twist）**，使脊椎形成连续优美的“懒 S（Lazy S）”曲线，以最小的肌能消耗维持身体重心中轴。

## Instruction (三大体块几何与 Contrapposto 动力学矩阵)

### 1. 三大刚性体块三维空间姿态
```
    [ 头颅刚体 Head Mass ]  ==============> 朝向右侧微扬 + 略微向左侧偏斜
              |  (颈椎弹性铰链)
    [ 胸廓刚体 Ribcage Mass ] ===========> 朝向左侧倾斜 (承重侧相反代偿)
              |  (腰椎弹性铰链 / 懒 S 曲线)
    [ 骨盆刚体 Pelvis Mass ] ============> 承重腿侧骨盆向上猛烈拔高倾斜
              |                              |
         (承重腿柱 - 垂直受压)          (放松腿 - 自由弯曲离地)
```

### 2. 单脚承重（Contrapposto）解剖形变矩阵
| 解剖维度 | 承重腿侧 (Weight-Bearing Side) | 非承重腿侧 (Free / Relaxed Side) | 对应软组织与肌肉形变 |
| :--- | :--- | :--- | :--- |
| **骨盆高度** | **高位 (Tilted Up)**: 髂前上棘 (ASIS) 显著上提 $10^\circ \sim 20^\circ$ | **低位 (Tilted Down)**: 骨盆自然顺重力下垂 | 承重侧大转子高高顶出皮下轮廓，臀中肌强力收缩 |
| **胸廓倾角** | **下沉挤压 (Squash)**: 肋弓下缘与骨盆髂嵴极端接近 | **上拉延展 (Stretch)**: 肋弓与髂嵴之间距离大幅拉开 | 承重侧腹壁挤压形成深褶；非承重侧背腹肌线平坦紧绷 |
| **躯干轮廓** | **短促饱满外凸 C 弧**: 肌肉团块堆叠挤压 | **修长平缓 S 弧 / 长直线**: 充满拉伸张力 | 直曲对抗：一侧受压做功外凸，对侧受拉平直导向 |
| **足底受力** | 承担全身 $90\%$ 以上重量，脚掌踩死地面 | 仅脚尖轻触地面维持平衡，膝盖向前内侧弯曲 | 身体重心中轴垂直线精确穿透承重足踝中央 |

## Actionable Example (雕刻古典大卫式 Contrapposto 男子)
1. **定骨盆**:
   - 将模型右侧髂前上棘（ASIS）上提 $15^\circ$，右侧股骨大转子向外上方推起，形成坚实承重支柱；
2. **定胸廓反向倾斜**:
   - 锁定胸骨柄切迹，使整个胸廓向左侧下倾 $12^\circ$；
   - 此时胸中线与骨盆中线形成夹角，右侧肋弓与右髂嵴距离缩短至仅容两指宽；
3. **刻画受压与拉伸肌群**:
   - 在右侧腰腹部雕刻出两道深陷的腹外斜肌水平肉褶（Squash Folds）；
   - 在左侧腰部拉出一道顺滑平整的长弧线，展现腹外斜肌与背阔肌的拉伸紧绷（Stretch）；
4. **定头颅**: 头颅微向右侧转动并微仰，视线注视远方，打破身体的单调对称。

## Constraints (约束与禁止)
- **严禁胸廓骨盆同向平移倾斜 (比萨斜塔病)**: 若骨盆右高左低，胸廓绝不能也画成右高左低，这会导致重心中轴彻底偏出支撑面导致模型倒塌；
- **严禁承重腿膝盖向前软屈**: 承重腿膝关节必须锁定直立或微超伸，绝不可画成发软打颤的半蹲状态；
- **严禁双侧腰褶完全对称**: 必须展现一侧挤压出褶皱、对侧平坦拉伸的绝对非对称性。

## Verification (验收标准)
- **重心中轴垂线校验**: 从胸骨柄切迹拉一根垂直铅垂线，该铅垂线是否精准落在承重足掌中央支撑面内；
- **倾角对抗度**: 骨盆连线与胸廓双乳连线是否具备明显的反向交叉剪刀角（Scissor Angles）。
