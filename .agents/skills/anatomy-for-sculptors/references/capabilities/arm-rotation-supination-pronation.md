# 能力卡: 前臂旋前旋后力学与桡骨交叉形变 (Forearm Supination & Pronation)

## Rationale (核心原理)
在角色绑定与上肢雕刻中，最严重的解剖崩塌是“糖纸扭曲前臂”（The Candy Wrapper Forearm）——手臂在手腕旋转时，前臂像拧糖纸一样对称缩瘪，肌肉完全丧失解剖体积。
Uldis Zarins 揭示了前臂旋转的根本机械运动学原理：
1. **尺骨（Ulna）是不动轴心**：在肘关节处，尺骨鹰嘴被滑车关节锁死，它**不能绕自身轴线自转**，在整个前臂旋转中尺骨后缘位置保持相对固定；
2. **桡骨（Radius）是运动连杆**：桡骨头在肘外侧原地自转，而其远端膨大部（连接手腕）**跨越尺骨前方，绕着尺骨做大弧度公转**；
- **旋后位（Supination - 掌心朝前）**：尺骨与桡骨平行排列；
- **旋前位（Pronation - 掌心朝后）**：桡骨斜跨尺骨，两骨构成**空间 X 形交叉**。附着于桡骨上的肱桡肌与伸肌群整体被拖拽向内前方翻转，重构前臂所有轮廓线。

## Instruction (旋前旋后运动学与肌肉形变矩阵)

### 1. 旋后位 vs 旋前位骨骼空间构型
```
【旋后位 Supination: 掌心朝前 / 两骨平行】
    [ 肱骨外上髁 ]                   [ 肱骨内上髁 ]
          |                               |
     (桡骨头自转)                  (尺骨鹰嘴肘尖锁定)
          |                               |
    [ 桡骨干 Radius ]               [ 尺骨干 Ulna ]
          | (平行下行)                     | (平行下行)
    [ 桡骨茎突 (拇指侧) ]           [ 尺骨茎突 (小指侧) ]

【旋前位 Pronation: 掌心朝后 / 桡骨跨过尺骨 X 交叉】
    [ 肱骨外上髁 ]                   [ 肱骨内上髁 ]
          |                               |
     (桡骨头自转)                  (尺骨鹰嘴肘尖锁定)
          \                             /
           \== [ 空间 X 形交叉点 ] =====/
            \                         /
    [ 尺骨头 (显露于手腕背侧) ]   [ 桡骨茎突 (翻转至内前方) ]
```

### 2. 前臂肌群形变与截面轮廓位移
| 运动状态 | 肱桡肌与腕长伸肌群 (外侧肌脊) | 屈肌群 (内侧前侧) | 手腕截面形态 |
| :--- | :--- | :--- | :--- |
| **旋后位 (Supination)** | 位于前臂**正外侧边缘**，形成由肘外侧向拇指延伸的饱满隆起 | 位于前臂**前内侧**，肌腹饱满下坠，尺骨后缘直接暴露于内侧皮下 | 椭圆形截面：**长轴呈水平横向**（手掌掌面完全朝前） |
| **旋前位 (Pronation)** | 被桡骨牵拉**向手臂前表面翻转**，跨过前臂背侧中轴 | 被压缩向手臂前内侧深层 | 椭圆形截面：**长轴发生 $90^\circ$ 旋转**（手掌掌面朝后/朝下） |

### 3. 旋前圆肌（Pronator Teres）的关键对角线
- 从肱骨内上髁斜向拉向桡骨体外侧中段，它正是驱使桡骨向内翻转的动力马达；在手臂用力旋前时，会在肘前窝形成一条坚韧的对角斜肌腱。

## Actionable Example (雕刻角色俯卧撑支撑地面时的前臂形变)
1. **判定状态**: 手掌压在地面，掌心朝下朝后——判定为**极限旋前位（Pronation）**；
2. **固定尺骨后缘**:
   - 尺骨鹰嘴（肘尖）依然清晰朝向后外侧上方，尺骨皮下骨性后缘从肘尖笔直连向小指侧手腕；
3. **桡骨跨越与肌群位移**:
   - 雕刻肱桡肌（Brachioradialis）：不再将其雕刻在小臂外侧轮廓上，而是将其雕刻为从肘外侧向手腕拇指侧斜跨过前臂中央的粗壮斜向肌肉条；
   - 在手腕小指侧后方，雕刻出高高突出的**尺骨头（Head of Ulna）**骨性圆形隆起；
4. **效果验证**: 前臂展现出极富张力的空间螺旋扭转，在旋转中体积完全守恒，毫无缩瘪。

## Constraints (约束与禁止)
- **严禁双骨整体绕中轴同心圆自转**: 尺骨鹰嘴绝不能随着手腕翻转而发生同轴度自转，尺骨是静止的旋转枢纽；
- **严禁手腕旋前时截面缩成正圆**: 旋前位下手腕依然是扁椭圆形，只是椭圆长轴发生了角度倾斜；
- **严禁旋前位下肱桡肌位置僵死不变**: 必须让肱桡肌伴随桡骨一起翻转位移，这是区分写实解剖与业余模型的试金石。

## Verification (验收标准)
- **尺骨头骨点检查**: 旋前位下，小指侧手腕背表面是否具备清晰圆润的尺骨头骨性突起；
- **肌肉螺旋对角线**: 前臂背面是否存在自外上向内下的清晰对角螺旋肌纹流动。
