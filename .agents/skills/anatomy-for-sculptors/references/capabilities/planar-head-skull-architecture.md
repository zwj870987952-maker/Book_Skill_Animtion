# 能力卡: 头部块面化几何拓扑与颅骨测量标尺 (Planar Head & Skull Architecture)

## Rationale (核心原理)
很多角色模型在进行 3D 头部雕刻时，经常出现“球形头骨”、“面部扁平无折角”或“侧面耳朵位置错乱”等严重问题。
Uldis Zarins 指出：**头部解剖不是一个毫无转折的椭球体，而是由颅骨（Cranium）与面颅（Facial Skeleton）相互咬合构成的三维建筑（Planar Head Architecture）**。
掌握头部块面化的关键在于：
1. **确立三维转折硬边（Planes of the Head）**：额头前平面、侧向颞窝、颧骨弓横梁与下颌底面构成了光影照射下的绝对主平面；
2. **严密的解剖测量标尺（Anatomical Measuring Points）**：利用耳孔（External Auditory Meatus）、外眼角、鼻翼与下颌角之间的几何连线，建立全方位视角的解剖基底。

## Instruction (头部块面化切角与标准比例矩阵)

### 1. 头部三维大平截面（Major Planes）拓扑解构
```
              [ 顶平面 Top Plane (顶骨/矢状缝) ]
                             |
             [ 额头前平面 Frontal Plane ]
            /             |             \
   [颞窝侧面 Temporal] [眉弓骨梁 Superciliary] [颞窝侧面 Temporal]
            \             |             /
             ==== [ 颧骨弓水平桥 Zygomatic Arch ] ====
             /            |             \
       [颊面侧部 Cheek] [中轴鼻骨楔形] [颊面侧部 Cheek]
             \            |             /
             ==== [ 下颌骨马蹄形底面 Mandible ] ====
```
- **额头五大面**:
  - 正中梯形面前平面（Front Plane of Forehead）；
  - 左右两侧以**颞线（Temporal Crest）**为硬转折棱线的颞窝侧平面（Side Planes）；
  - 额头上方以额结节（Frontal Eminence）为界的两个向上过渡的倾斜顶面；
- **颧骨弓横梁（Zygomatic Arch）**:
  - 从颧骨体向后水平延伸直通耳孔前方的骨桥，它标志着**面部正面彻底转向侧面的 $90^\circ$ 空间拐角**；
- **下颌骨底平面（Planes of Mandible）**:
  - 下颌体下缘并非锋利单线，而是包含一个向内下倾斜的下颌底平面（Submandibular Plane），收束于前下方的颏结节三角底面。

### 2. 头部标准三维比例标尺矩阵
| 测量基准轴 | 解剖起止点 | 标准比例关系 | 常见雕刻失真与校准 |
| :--- | :--- | :--- | :--- |
| **高度中分线** | 头顶最高点 (Vertex) 至 下巴颏下点 (Gnathion) | **双眼瞳孔水平线恰好位于全高的 1/2 处** | 错误地把眼睛画在头高 $2/3$ 处，导致颅顶极度萎缩 |
| **三庭垂直均分** | 发际线 $\to$ 眉骨上缘 $\to$ 鼻底点 $\to$ 下巴底 | 1 : 1 : 1 标准等距 | 写实角色必须严守均分；卡通角色则主观破除 |
| **宽度五眼网格** | 左右颧骨弓最宽处（全头宽） | **恰好容纳 5 只眼睛的宽度** | 两眼间距 $\approx 1$ 眼宽；外眼角至耳前 $\approx 1$ 眼宽 |
| **侧面耳孔定位** | 侧视深度中轴线 | **耳孔位于侧面全深度的 1/2 稍偏后位置** | 错误地把耳朵贴在腮帮子后面太靠前，导致颞窝彻底消失 |

## Actionable Example (在 ZBrush 中从球体 Block-out 头部 Planar Head)
1. **压出侧面平截面**:
   - 用 TrimAdaptive 或 Clip 笔刷，直接在球体左右两侧切出两个平行垂直的平坦侧平面，将球体宽度收缩为原宽的 $75\%$；
2. **切出面部前斜面**:
   - 从头顶前缘向下斜切出额头前平面，在眉骨处向内凹陷挖出眼眶大凹槽；
3. **拉出下颌与下巴**:
   - 从耳下点向斜下方拉出下颌角（Angle of Mandible），向前连结成马蹄形下颌底面；
4. **确立颧骨弓梁**:
   - 在眼眶下方拉出水平横跨的颧骨弓，使面颊在此处形成明显的向内收窄斜面；
5. **光影校验**: 顶光打下时，额头、眉弓上缘、鼻梁、颧骨上缘与下巴尖全部受光，眼眶与鼻底整体沉入深硬阴影中。

## Constraints (约束与禁止)
- **严禁把头颅侧面雕成纯球体 (消除颞窝)**: 颞窝（Temporal Fossa）必须内陷为一个平整的侧平面，绝不能让头部侧面鼓起成大肉球；
- **严禁下颌角贴到耳垂正下方**: 下颌角必须在耳垂后下方留有一指宽的缓冲距离，给胸锁乳突肌的附着留出解剖空间；
- **严禁眼睛位置过高**: 眼睛绝对位于全头高的一半，决不能为了“好看”把眼睛盲目上移导致大脑额叶完全消失。

## Verification (验收标准)
- **眼睛中分高度检验**: 测量头顶至眼角距离与眼角至下巴距离，比例是否严格接近 $1:1$；
- **颞线硬朗度**: 额骨侧面与颞窝之间的骨性转折棱线是否在光照下呈现清晰明快的阴影切线。
