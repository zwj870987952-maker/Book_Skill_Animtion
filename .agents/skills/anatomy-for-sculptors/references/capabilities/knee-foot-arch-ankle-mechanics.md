# 能力卡: 膝关节滑车、高低双踝与足弓三点力学 (Knee, Ankle Malleolus & Foot Arches)

## Rationale (核心原理)
在下肢末端雕刻与建模中，膝关节、脚踝与足部是最容易导致角色“站立不稳、关节脱臼、缺乏真实抓地力”的区域。
Uldis Zarins 明确指出了三大下肢末端不可动摇的生物力学铁律：
1. **膝关节滑车机械系统（Knee Pulley System）**：髌骨不是浮动的独立石头，它嵌在股四头肌肌腱与髌韧带构成的滑车系统中；膝盖下方有高韧性的髌下脂肪垫，在屈伸时发生剧烈受压形变；
2. **双踝不对称剪切角（Malleolus Asymmetry）**：**内踝（胫骨远端）高而靠前；外踝（腓骨远端）低而靠后**！两踝连线形成一个强烈的向外下方倾斜的黄金对角斜角；
3. **足底三点拱桥系统（Three-Point Foot Arches）**：脚底不是平底鞋垫，而是由跟骨结节、第一跖骨头和第五跖骨头支撑的三维拱桥，内侧纵弓高耸悬空吸震，外侧纵弓平贴地面承重。

## Instruction (膝踝足生物力学参数与落差矩阵)

              |                                                      \
      [ 胫骨粗隆 Tuberosity ]                                   [ 外踝 (低 Lower) ]
              |                                                         |

### 2. 核心下肢骨点解剖落差矩阵
| 骨性解剖构件 | 空间高度位置 | 前后空间位置 | 力学功能与造型法则 |
| :--- | :--- | :--- | :--- |
| **内踝 (Medial Malleolus)** | **显著偏高 (Higher)** | **偏向靠前 (More Anterior)** | 胫骨远端膨大；圆钝，直接承载身体垂直重力中轴 |
| **外踝 (Lateral Malleolus)** | **显著偏低 (Lower)** | **偏向靠后 (More Posterior)** | 腓骨远端膨大；尖锐狭长，充当踝关节抗外翻翻转侧挡板 |
| **小腿肚内侧头 (Gastrocnemius)** | **位置极低 (Lower)** | 后侧饱满下垂 | 内侧腓肠肌更长、更粗壮，一直延伸至小腿中段下方 |
| **小腿肚外侧头 (Gastrocnemius)** | **位置极高 (Higher)** | 后外侧短小收缩 | 外侧腓肠肌较短，止点高，给下方比目鱼肌留出大面积露出 |

### 3. 足弓三点拱桥系统（Arches of the Foot）
1. **内侧纵弓（Medial Longitudinal Arch）**:
   - 由跟骨、距骨、舟骨、3 块楔骨和 1-3 跖骨构成；
   - **高耸深陷，绝对不接触地面**！形成脚内侧标志性的足窝（Instep Hollow），赋予足部落地跳跃时的弹性阻尼；
2. **外侧纵弓（Lateral Longitudinal Arch）**:
   - 由跟骨、骰骨和 4-5 跖骨构成；
   - **平缓低矮，完全接触地面**，承担站立时的主要垂直重力承重面；
3. **横弓（Transverse Arch）**:
   - 跨越跖骨基底部的半圆拱，使脚背在正面视角呈现向上隆起的斜坡截面。

## Actionable Example (雕刻写实站立脚踝与足部接触面)
1. **画高低双踝倾斜线**:
   - 定位胫骨内踝，画出一个平缓圆钝的骨性隆起；
   - 在外侧向下偏移约 2 厘米、向后偏移约 1.5 厘米的位置，雕刻出锐利狭长的腓骨外踝；
   - 两踝连线呈现清晰的 $15^\circ \sim 20^\circ$ 向外下倾斜对角线；
2. **架设内侧足弓悬空**:
   - 从内踝下方切出深陷内收的足弓凹弧，确保在平视观察地面法线时，脚底内侧边缘与地面之间留有一指宽的明显悬空缝隙；
3. **踩死外侧承重边缘**:
   - 脚外侧轮廓（第五跖骨粗隆与小脚趾边缘）必须完全压平紧贴地面多边形；
4. **大脚趾基座与五趾阶梯**:
   - 第一跖趾关节（大脚趾球部）粗壮饱满压地；其余 4 趾呈弧形向外下方阶梯缩短并微内曲。

## Constraints (约束与禁止)
- **严禁内踝与外踝等高水平对称**: 绝不能画成水平对称的两个骨包！内踝高、外踝低是不可违背的硬性铁律；
- **严禁脚掌平贴地面 (扁平足病)**: 脚内侧必须保留高耸悬空的内侧纵弓，绝不可雕成平坦贴地的鸭蹼状；
- **严禁髌骨在屈膝时悬空分离**: 屈膝时髌骨必须紧随滑车下移贴合在股骨髁之间，绝不能脱轨漂浮。

## Verification (验收标准)
- **双踝倾斜角检测**: 正视模型脚踝，内踝顶点到外踝顶点的连线倾斜角是否落在 $15^\circ \sim 20^\circ$ 范围内；
- **足弓透光检查**: 平视地面时，足底内侧缘与地平面之间是否存在清晰的避震拱桥空间。
