# 候选术语词汇表 (Glossary Candidates) - Force: Character Design

## 核心设计术语表

### 1. Opinion (主观观点)
- **定义**: 画师对被画对象的外貌、性格、社会阶层与心理状态的主观评判与态度。它是从人体速写升华至角色设计的精神引擎。

### 2. Hierarchy (设计层级)
- **定义**: 创作决策的自顶向下金字塔体系。故事与性格第一，力量主线第二，空间包围盒第三，形状语言第四，细节纹理最末。

### 3. Pushing Poses (推挤极限姿态)
- **定义**: 将写实模特原本微弱或含蓄的倾斜、弯曲与扭转动作，沿动力学方向主观放大 120% 至 150%，使其达到戏剧性物理极值的表现手法。

### 4. Amazing Angles (45° 强角施加力)
- **定义**: 当外在施加力与主导推进力形成 $45^\circ$ 左右对角强角时，力量曲线发生最强烈的弹性弯曲与动能反弹。

### 5. Spatial Bounding Box (空间包围盒)
- **定义**: 用于在二维纸面上界定角色体块三维空间容积与透视朝向的几何框架。基于“尺寸即深度”与“位置即深度”两大定律。

### 6. The Law of Thirds (三分法则)
- **定义**: 力量曲线的不对称黄金定位法则。将曲线最高顶点锁定在全长的 1/3 或 2/3 处，打破 50% 几何死板，赋予线条明确的推力加速度。

### 7. Facial Ratios (面部比例重构)
- **定义**: 突破写实人类 1:1:1 均等三庭五眼限制，通过戏剧性缩短或拉伸额头、鼻长与下颌比例，直观呈现角色的智力、年龄与戏剧性格。

### 8. Value Staging (明度舞台化调度)
- **定义**: 利用受控的 3 至 4 阶黑白灰明度阶梯，将最大明度对比投射在核心故事区，统摄画面视觉焦点的构图技法。

### 9. Reportage (现场生活纪实速写)
- **定义**: 在不受控的真实生活场景中，对动态行人和环境进行快速捕捉、提炼核心意图与生活人情味的速写修行法。

### 10. Architecture with Character (角色化建筑)
- **定义**: 将人体解剖的重力感、力量流线与情绪性格投射到无机建筑物和场景空间中的环境设计理念。
