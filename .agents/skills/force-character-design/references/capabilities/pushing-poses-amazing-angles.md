# 能力卡: 极限推挤姿态与 45° 强角施加力 (Pushing Poses & Amazing Angles)

## Rationale (核心原理)
在写实速写中，人体的发力往往是内敛且保守的；但在角色设计中，**如果姿态不被推向物理可信的极限边缘（Pushing Poses to the Edge），角色的独特魅力就无法被观众识别**。
Mike Mattesi 提出了著名的**“神奇角度”（Amazing Angles）力学法则**：
- 当外在施加力（Applied Force）以弱角度（如 $10^\circ \sim 15^\circ$）推挤主导方向力时，产生的反弹曲线是疲软无力的；
- **当施加力以强烈的 $45^\circ$ 对角切入主推进流时，力量线会发生最强烈的弹性弯曲与动能反弹**，产生具有爆炸性动量的戏剧性节奏。

## Instruction (姿态推挤极限与 45° 强角操作规程)

### 1. 姿态推挤三步曲 (The 150% Push Process)
1. **识别原始动态矢量（Original Vector）**:
   - 观察模特或构思草图，找出主要做功的倾斜轴向（例如：向左侧倾斜 $12^\circ$）；
2. **施加主观放大倍率（120% - 150% Amplification）**:
   - 将该倾斜角度强制放大为 $35^\circ \sim 45^\circ$；
   - 承重侧受挤压（Squash）部位压缩 $30\%$，对侧受拉伸（Stretch）部位延长 $40\%$；
3. **重新校准受力平衡（Counter-Balance Check）**:
   - 检查重心投影线是否仍落在双足或支撑面以内，或通过向前迈步形成动态冲量（冲刺态）。

### 2. 核心关节神奇角度应用矩阵
| 关节部位 | 原始写实状态 | 45° 强角推挤状态 | 动力学与戏剧效果 |
| :--- | :--- | :--- | :--- |
| **颈部与头颅** | 头部微倾 $10^\circ$ | 头部向肩峰猛烈折压至 $45^\circ$ | 极大增强偏执、狡诈、威严或绝望感 |
| **胸腔与骨盆** | 轻微的站立对立倾斜 | 骨盆大转子高高顶起，胸腔反向斜切 $45^\circ$ | 塑造极致的动态张力（Contrapposto Extreme） |
| **手臂出拳** | 手臂水平伸直 | 上臂与前臂在肘关节形成 $45^\circ$ 强蓄力锐角 | 力量蓄满如紧绷的弓，出拳动量翻倍 |
| **奔跑起跑蹬地** | 身体前倾 $25^\circ$ | 身体躯干与地面夹角压低至 $40^\circ \sim 45^\circ$ | 呈现离弦之箭般的瞬时加速度冲击力 |

## Actionable Example (将写实击剑手推向极端攻击姿态)
1. **写实原态**: 击剑手微曲膝盖，刺剑前伸，身体微侧；
2. **应用 45° 神奇角度**:
   - 将后腿蹬地角度调整为与地平面呈坚硬的 $45^\circ$ 斜线；
   - 将躯干前倾轴线向下压迫，从后脚跟经由脊椎到持剑右臂贯通为一根笔直如钢矛的 $45^\circ$ 破空长直线；
   - 前膝以 $45^\circ$ 强锐角向前跨出抵住地面，吸收全部下砸动能；
3. **反差效果**: 原本平淡的击剑动作瞬间化为撕裂空气的超音速突刺。

## Constraints (约束与禁止)
- **严禁全幅均等平行倾斜**: 身体各体块切忌朝着同一个方向整体平移倒下（比萨斜塔病），必须有反向倾斜体块维持受力平衡；
- **严禁丧失关节解剖极限**: 夸张必须遵循人体解剖关节转动范围，不能画出脱臼骨折式的怪异畸形；
- **严禁弱化施加力角**: 避免使用 $5^\circ \sim 10^\circ$ 模棱两可的微倾斜，敢于果断推进到 $40^\circ \sim 45^\circ$ 的决绝强角。

## Verification (验收标准)
- **动态冲击力测量**: 姿态倾角是否明显大于写实参考 $30\%$ 以上；
- **张力弧线饱满度**: 受施加力推挤的弧线是否具备犹如拉满战弓的高张力曲率。
