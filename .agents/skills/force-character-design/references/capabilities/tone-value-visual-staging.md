# 能力卡: 明度层次与视觉重心舞台化调度 (Tone & Value Staging)

## Rationale (核心原理)
很多画师在完成线稿后，一进入铺调子阶段就陷入混乱：画面灰蒙蒙一片，或者黑白杂乱碎裂成“碎花布”（The Cluttered Value Trap）。观众的眼睛在画面上漫无目的地游荡，无法捕捉故事核心。
Mike Mattesi 强调：**明度（Tone or Value）不是为了展现繁琐的微观材质，而是为了舞台调度（Visual Staging）与引导观众的注意力流向**。
人眼的视觉生理本能是：**永远被画面中“最强烈的明度反差区域（The Highest Contrast Area）”所捕获**。
通过严格受控的“3 到 4 阶明度系统（3-4 Step Value System）”，画师能够像电影灯光师一样，精准控制哪部分是背景静音区，哪部分是角色的聚光灯主角。

## Instruction (4 阶明度控制矩阵与视觉焦点调度)

### 1. 经典 4 阶明度系统（4-Step Value System）
```
  [ Value 1: 纯白/极浅 (0%-15%) ]   ===>   [ 天空 / 最强高光 / 故事唯一聚光灯 ]
  [ Value 2: 浅灰 (20%-40%) ]      ===>   [ 主体受光面 / 次要环境明部 ]
  [ Value 3: 深灰 (50%-70%) ]      ===>   [ 主体背光暗面 / 服装基底 / 次要遮挡 ]
  [ Value 4: 浓黑 (80%-100%) ]     ===>   [ 闭塞阴影 / 深色斗篷 / 终极反差边缘 ]
```
- **核心法则**: 全画明度严格归纳为这 4 个大色阶之一，严禁在同一区域内涂抹无边界的连续灰色渐变；
- **最高反差锁定点（The Nexus of Contrast）**:
  - 将 Value 1（最纯的白）与 Value 4（最深沉的黑）直接并置在角色最关键的叙事焦点（通常是角色的眼睛、表情或施展致命动作的手部）；
  - 次要部位（如靴子、裤管、后景）的明度反差缩小为 Value 2 与 Value 3 之间的低对比。

### 2. 明度舞台调度方案矩阵 (Staging Scenarios)
| 舞台调度模式 | 角色主体明度 | 背景环境明度 | 视觉焦点处理法则 | 适用戏剧氛围 |
| :--- | :--- | :--- | :--- | :--- |
| **暗底亮人 (Light on Dark)** | Value 1 & Value 2 (高调亮色) | Value 3 & Value 4 (深沉暗夜) | 角色全身剪影瞬间跃出，面部留出极值亮白高光 | 神圣、英雄出场、希望、舞台中心 |
| **亮底暗人 (Dark on Light)** | Value 3 & Value 4 (深重剪影) | Value 1 & Value 2 (高亮逆光) | 极强纯黑剪影可读性，仅在五官侧边勾勒一线 Value 1 轮廓光 | 危机、神秘、反派登场、西部对决 |
| **中灰互锁 (Interlocking Values)** | 角色上亮下暗 / 衣服明暗交错 | 背景与角色明度对角反转 | 亮部压暗底，暗部衬亮底，形成齿轮般紧密空间咬合 | 复杂叙事、群戏穿插、都市纪实 |

## Actionable Example (西部牛仔拔枪决斗的明度调度)
1. **背景设定 (Value 1)**: 白炽烈日暴晒下的荒漠地平线，设定为大面积白与浅灰；
2. **身体基调 (Value 3)**: 牛仔破旧风衣与皮裤归纳为统一沉稳的中深灰色块；
3. **最高反差聚焦点 (Value 1 vs Value 4)**:
   - 在阴影笼罩的帽檐下，画出 Value 4 的死黑阴影，并在阴影中点出 Value 1 的锐利眼神高光；
   - 在右侧大腿枪套处，漆黑油亮的枪柄（Value 4）紧贴着被烈日打亮的金属枪机扳机（Value 1）；
4. **效果**: 观众的第一眼瞬间撞在帽檐下的眼神上，紧接着第二眼在 0.1 秒内滑落至腰间准备拔枪的极度反差处。

## Constraints (约束与禁止)
- **严禁全幅均等反差**: 绝不能面部、肩膀、手部、脚踝每一处都拥有同样强烈的黑白对比，这会导致视觉四分五裂；
- **严禁无层级排线涂黑**: 明度铺设必须先划分几何大色块，切忌用细密毛躁的杂乱线条涂成脏灰；
- **严禁中灰糊墙 (Muddy Middle Gray)**: 避免整张画全部挤在 40% - 60% 的中灰地带，缺少高光与深黑的骨骼。

## Verification (验收标准)
- **黑白缩略图检验 (Thumbnail Squint Test)**: 将画面缩小至邮票大小或眯眼观察，最先跳入视线的区域是否 100% 对应核心叙事点；
- **色阶归纳率**: 全画色阶能否被清晰吸管拾取为不超过 4 个大明度层级。
