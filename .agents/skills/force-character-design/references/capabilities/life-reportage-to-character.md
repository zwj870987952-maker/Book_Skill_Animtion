# 能力卡: 现场生活纪实速写向风格化角色演化 (Life Reportage to Character)

## Rationale (核心原理)
封闭在画室临摹摆拍模特（Studio Pose）的画师，画出的姿态往往充满刻意的表演感与僵硬的人造痕迹。
真正打动人心的角色设计，其生命力根植于**真实世界中的现场生活纪实（Reportage Drawing）**。
在街头、地铁、咖啡馆或菜市场，真实人类在毫不防备的状态下展现出最本真的生理重心倾斜、习惯性微动作（Mannerisms）与生活重量感。
Mike Mattesi 强调：**纪实速写不仅是练习手速，更是一座“从写实观察蜕变至风格化角色”的炼金熔炉**——画师在极短时间内抓取人物的生活重心与情绪神韵，随后剥离琐碎表象，将其主观放大 150%，创造出充满人情味的鲜活角色。

## Instruction (街头纪实观察与角色演化四步工作流)

### 1. 现场纪实速写（Reportage）抓捕三要素
```
  [ 1. 绝对生理重心 (Gravity Center) ] ===> 人是如何把全部体重懈怠地挂在骨架上的？
  [ 2. 标志性生活小动作 (Signature Tick) ] ===> 抖腿、缩脖子、抠指甲、抱胸耸肩、斜眼观察
  [ 3. 服装与身体的生态关系 (Body-Clothes Ecology) ] ===> 被大衣压弯的驼背、踩瘪的旧皮鞋跟
```

### 2. 从纪实草图到角色设计的演变四阶段
| 演变阶段 | 操作动作与思维焦点 | 典型画面形态 |
| :--- | :--- | :--- |
| **Stage 1: 5-30秒现场抓捕 (Capture)** | 不看细节，只用 3 根主力量线抓住人物重心倾斜与微动作神韵 | 极简、粗粝的受力流线与大几何外框 |
| **Stage 2: 注入主观观点 (Opinion)** | 用一句话定义被抓捕者的本质（如“一个被公文包压垮的疲惫企鹅”） | 确立角色的动物隐喻与戏剧身份 |
| **Stage 3: 施加 150% 戏剧夸张 (Push)** | 将其最具特征的身体部位（如驼背、细脖子、肥大肚腩）放大 $150\%$，压缩次要部位 | 写实比例彻底解构，卡通与造型张力爆发 |
| **Stage 4: 整合服装与道具 (Design)** | 将现场看到的磨损雨伞、廉价西装或塑料袋提炼为叙事符号，赋予纯黑剪影可读性 | 具备动画量产标准的角色最终概念图 |

## Actionable Example (将地铁里打瞌睡的白领演化为动画角色)
1. **Stage 1 (现场纪实)**:
   - 地铁座位上一名中年男子，头向左深垂，下巴抵在领带上，双手紧抱膝盖上的公文包，双腿并拢斜缩；
   - 用 10 秒抓取一条由颈后背部拱起至膝盖的巨大 C 曲线；
2. **Stage 2 (主观观点)**:
   - “他是一只在暴风雪中用双翼死死护住最后一颗蛋的落魄企鹅”；
3. **Stage 3 (极限夸张)**:
   - 将背部的拱起弯曲度推大 $140\%$，头颅彻底缩进两肩耸起的倒三角大衣领中；
   - 极度缩小四肢：前臂退化如两根短小的鳍状连杆，双脚缩成紧贴地面的扁平脚掌；
   - 公文包膨胀为身体面积的 $50\%$，仿佛是他整个生命的沉重基石；
4. **Stage 4 (完成设计)**:
   - 提取皱巴巴的廉价西装横向褶皱，配上一副滑落到鼻尖上的圆框眼镜；
   - 一个既滑稽又令人唏嘘的都市动画角色跃然纸上。

## Constraints (约束与禁止)
- **严禁偷拍式死板描摹**: 纪实速写绝不是偷偷拍下一张照片然后照抄排线！必须现场立刻提炼动能与态度；
- **严禁美化修饰生活真实**: 严禁将路人的驼背、肚腩、高低肩或内八字“修正”为学院派标准九头身，角色的魅力恰恰来自不完美；
- **严禁忽略道具互动**: 人物与手机、拐杖、公文包或热咖啡的物理互动是展现性格的关键，绝不能把道具画成浮空背景。

## Verification (验收标准)
- **生活人情味可读性**: 观者是否能在 2 秒内感受到角色的生活境遇与情绪疲惫/兴奋感；
- **真实基因溯源**: 风格化后的角色是否依然保留了现场抓捕的重心与独特微动作基因。
