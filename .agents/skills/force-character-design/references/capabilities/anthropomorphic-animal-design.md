# 能力卡: 动物拟人化与兽性向人性性格重构 (Anthropomorphic Animals)

## Rationale (核心原理)
在现代动画电影与游戏设计中，拟人化动物角色（Anthropomorphic Animals / Furry Characters）占据着巨大的工业比重（如《疯狂动物城》、《功夫熊猫》）。
很多画师在做动物拟人化时，要么直接画一个纯人类身体换上一个动物头（硬插违和感），要么直接保留四足趴着只是穿了一件背心（缺乏拟人化社会属性）。
Mike Mattesi 强调：**卓越的拟人化动物角色，是“真实生物力学特征（Animal Biomechanics）”与“人类心理原型及社会姿态（Human Persona）”的有机熔炼**。
画师必须精准提炼动物在解剖学上的**特征骨性标志（如猫犬的悬空飞节、兔子的长跖骨、熊的宽厚脚掌）**，并将其与人类双足直立站姿、手势语言以及社会阶层完美交融。

## Instruction (生物解剖提炼与拟人化嫁接工程)

### 1. 拟人化三级解剖杂交矩阵
```
  [ 人类社会原型 (Human Persona) ]            [ 动物生物基因 (Animal Core) ]
        (双足直立站姿与骨盆前倾)                     (物种特征骨点与面部解剖)
                  \                                     /
                   \                                   /
                    ====== [ 拟人化熔炼 (Synthesis) ] ======
                                       |
                   [ 保留 70% 人类表情微动态与手势抓握 ]
                   [ 保留 30% 动物飞节弹性、耳尾情绪与吻部力矩 ]
```
| 解剖部位 | 人类化处理 (Human Adaptation) | 动物性保留 (Animal Authenticity) | 工业级结合技巧 |
| :--- | :--- | :--- | :--- |
| **头颅与五官** | 眼睛保留人类眼白（巩膜 Sclera）与眉毛微表情，嘴唇可做人类发音口型 | 保留动物吻部（Snout）深度、胡须垫与标志性齿列 | 眉毛与眼白赋予角色人性灵魂，吻部和耳朵赋予动物本能 |
| **耳朵与尾巴** | 充当角色内心潜意识的“情绪天线”（与面部表情形成同步或反差） | 保留动物耳廓肌肉旋转范围与尾椎多级波浪摆动 | 惊恐时耳朵紧贴头皮，自信时尾巴高高竖立 |
| **手掌与前肢** | 拇指对握（Opposable Thumb），具备人类工具使用与持握能力 | 保留肉垫（Pads）、可伸缩爪残余或指尖毛发质感 | 通常精简为“四指卡通手”，指节肥厚带有动物特征 |
| **下肢与足部** | 骨盆直立旋转，双腿承受垂直重力平衡 | 趾行（悬空飞节）或蹄行（特化鞋靴），保持下肢 Z 字弹性 | 若穿鞋靴，鞋跟必须高高垫起以容纳高悬的飞节 |

### 2. 拟人化角色设计四步法
1. **物种与社会职业匹配（Species-Archetype Pairing）**:
   - 利用物种天然的生物学符号投射角色职业（例如：狐狸—狡诈市井小贩，公牛—固执防暴警察，树懒—效率低下的车管所公务员）；
2. **重塑双足直立骨盆（Bipedal Pelvis Re-alignment）**:
   - 将动物水平骨盆向后下方旋转，形成人类特有的双足承重基座，脊椎呈现轻微 S 形直立；
3. **保留足部下肢类群基因（Leg Mechanics Preservation）**:
   - 若是猫狗狼角色，后腿坚决保留趾行（Digitigrade）的悬空飞节与紧绷跟腱，走动时体现弹簧避震的轻盈步态；
4. **服装穿戴的解剖合身性（Anatomical Costume Tailoring）**:
   - 裤子后侧必须留出尾巴孔；帽子必须设计专门容纳动物耳廓的耳洞或开叉。

## Actionable Example (设计一位老练干练的雪豹私家侦探)
1. **社会原型与物种结合**: “一个身穿破旧风衣、叼着火柴、在雨夜街头独自行走的孤独侦探”；
2. **头部设计**:
   - 保留雪豹扁平宽阔的面部骨骼与黑色斑纹，但在眼睛中加入清晰的人类眼白与下垂眼袋，表现疲惫沧桑；
   - 嘴里斜叼着火柴，一侧嘴角微微下撇；
3. **躯干与站姿**:
   - 采用经典人类双足站姿，单脚承重（Contrapposto），但身体微弓体现猫科动物随时爆发的潜伏感；
   - 粗长毛茸茸的雪豹长尾从风衣后摆自然垂下，尾尖在地面微微卷曲，展现侦探内心的敏锐思索；
4. **腿部力学**:
   - 卷起裤管，露出悬空的飞节与强壮的趾行脚掌，脚掌踩在雨水坑边缘，弹性十足。

## Constraints (约束与禁止)
- **严禁直接抹除动物下肢特征**: 切忌把猫科犬科角色的腿画成毫无飞节的人类肉腿，这会丧失 $50\%$ 的物种辨识度；
- **严禁全黑动物眼球 (缺乏情绪表达)**: 除非刻意营造无理智野兽，拟人化角色必须展现清晰的人类眼白与虹膜，否则观众无法共情其内心戏；
- **严禁尾巴像死绳一样僵直**: 尾巴是脊椎的延伸，必须始终遵循多级骨骼波动（S-Curve wave），绝不能画成一根硬木棍。

## Verification (验收标准)
- **物种可读性**: 即使穿戴全身职业西装，观者是否能在 1 秒内清晰辨识其动物物种；
- **人性戏剧信服度**: 角色的姿态与面部表情是否能精准传达人类社会的复杂心理与职业特质。
