# 能力卡: 角色群戏排版布局与镜头视线引导 (Character Layout & Staging)

## Rationale (核心原理)
单体角色设计完成之后，将其置于场景与群戏（Multi-character Staging）中时，往往会出现“角色互相打架、画幅凌乱松散、缺乏焦点”的镜头调度事故。
在动画分镜与排版（Layout）中，**所有角色的位置、高低落差、视线朝向与身体倾斜，共同构成了引导观众眼球的整体力场（The Collective Force Field）**。
Mike Mattesi 强调：**群戏排版不是把多个画好的独立角色粘贴在同一张纸上，而是通过主从层级（Hierarchy）、空间遮挡（Overlap）与力量对角线流向，编排出一场视觉交响乐**。

## Instruction (群戏排版舞台调度与视线连环闭环)

### 1. 舞台调度三大核心力学法则
```
  [ 角色 A: 施力主导 (Primary Actor) ] ======= (主导视线/动作推力) ======>
                                                                         \
  [ 角色 C: 空间进深锚定 (Depth Anchor) ] <=== (对角线折射) === [ 角色 B: 承受反作用力 (Reactor) ]
```
1. **主从层级（Dominance & Subordination）**:
   - 画面中只能存在一个“第一主角（Primary Driver）”；次要角色必须在尺寸、明度反差与动作幅度上主动降级退让；
2. **力量动能回环（Force Circulatory System）**:
   - 角色 A 的手势或武器指向角色 B，角色 B 的惊恐视线或后仰姿态折射向角色 C，角色 C 的身体倾斜重新将视线导回画面中轴，形成闭环无外泄的视觉循环；
3. **高低与前后交错（Staggering & Overlap）**:
   - 严禁角色头部水平排成一条直线（打靶警官病）；角色头部必须形成犬牙交错的高低对角波浪，且前后角色必须有肢体遮挡以建立深度。

### 2. 经典排版构图原型矩阵
| 排版构图母题 | 角色分布力学 | 视线引导轨迹 | 适用戏剧场景 |
| :--- | :--- | :--- | :--- |
| **金字塔三角构图 (Triangular Staging)** | 主角位于三角形顶端高位，两配角居于底边左右两侧支撑 | 视线由两侧底边迅速沿斜边攀升至主角面部 | 威严统治、团队核心宣誓、神圣揭秘 |
| **对角冲撞构图 (Diagonal Confrontation)** | 冲突双方占据画幅对角线两极，身体朝向对角中心剧烈前倾 | 视线在两极之间高速往复碰撞 | 决斗前夕、紧张谈判、追击拦截 |
| **环形向心包围 (Centripetal Enclosure)** | 多个次要角色呈 C 形弧线环绕，背对观众朝向画面深处的主角 | 视线顺着次要角色的后背与视线一齐冲向圆心 | 审判、众叛亲离、法庭指控、围炉夜话 |

## Actionable Example (三个不同体型劫匪的同框排版)
1. **角色选型**:
   - 劫匪 A（领头矮子，精明狡诈，倒三角）；
   - 劫匪 B（持枪傻大个，方块巨汉，正三角）；
   - 劫匪 C（瘦高望风者，纤细长条，一字形）；
2. **空间错落布局**:
   - 劫匪 B（傻大个）放在中景偏左，体量巨大占画幅 $40\%$，头顶接近画面上边缘；
   - 劫匪 A（矮子头目）放在前景偏右，利用“尺寸即深度”将其放大，双脚踏在画面最底部边缘，手指向正前方镜头；
   - 劫匪 C（瘦高者）放在后景门洞处，全身仅有前景 A 的 $1/4$ 大小，身体向门外倾斜；
3. **动能引导链**:
   - 观者第一眼看到前景矮子 A 的狰狞表情 $\to$ 顺着其指向的手枪看向左侧傻大个 B $\to$ 傻大个 B 低垂的枪口指向后景门洞 $\to$ 看到望风者 C 的警戒姿态。

## Constraints (约束与禁止)
- **严禁全员均等正面站桩**: 绝不能三个角色排成一行并齐齐面对镜头微笑，这会导致镜头语言彻底死掉；
- **严禁视线射向画幅死角**: 边缘角色的视线或动作绝不能直接冲出画框之外，必须有姿态内收将动能反弹回画内；
- **严禁体块并列无遮挡**: 多角色同框时如果所有人各自独立不挨着，画面就会显得散碎；至少两组角色必须有局部的肢体前后重叠。

## Verification (验收标准)
- **视线流向闭环检验**: 追踪观者的视线流动路径，是否能在一个连贯的轨迹内阅读完全部角色且不迷失方向；
- **剪影分离与重叠平衡**: 即使全画涂成黑白剪影，不同角色的身体界限与前后关系是否依然清晰可辨。
