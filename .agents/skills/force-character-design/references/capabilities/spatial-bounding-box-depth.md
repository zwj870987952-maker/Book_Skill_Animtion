# 能力卡: 空间包围盒系统：尺寸与位置决定深度 (Spatial Bounding Box)

## Rationale (核心原理)
二维纸面天生缺乏物理深度（Depth），新手画师极易把角色画成贴在墙上的扁平皮影戏剪纸。
Mike Mattesi 指出：**三维空间感并非依赖繁琐的调子明暗，而是依赖纯粹的几何几何学与两大不可动摇的物理定律**：
1. **尺寸即深度（Size Equals Depth）**：近大远小——两个相同尺度的体块，投影在视网膜上的尺寸比例决定其空间前后距离；
2. **位置即深度（Location Equals Depth）**：在视平线（Eye Level）下方的地平面上，垂直高度越低的对象离观察者越近，垂直高度越高则越远；
结合能够自由旋转的三维**空间包围盒（Spatial Bounding Box）**，创作者可以在几笔之内为角色构建出具备强烈透视缩短（Foreshortening）与破屏冲击力的空间实体。

## Instruction (空间包围盒两大定律与六面体绘制流程)

### 1. 空间深度双生定律工程公式
```
【定律一: 尺寸即深度 (Size = Depth)】
       [ 近景超大尺寸 (Huge) ]                  [ 远景极小尺寸 (Tiny) ]
           +-------------+
           |   (近处拳头)  |                         +----+
           |             |                         | 头 |
           +-------------+                         +----+
           [ 面积 400 cm² ]                       [ 面积 25 cm² ]
                 \                                     /
                  \====== [ 空间纵深深度跨度 ΔZ ] ======/

【定律二: 位置即深度 (Location = Depth) 在视平线下方】
       ---------------- 视平线 (Eye Level / Horizon) ----------------
              (远景脚部触地点: 高位置 High on Page)
                         ^
                         |   垂直屏幕高度差 ΔY
                         v
              (近景脚部触地点: 低位置 Low on Page)
```

### 2. 空间包围盒（Bounding Box）构建四步法
1. **确立地平面视平线（Horizon Line）**:
   - 确定观察者视角（平视、仰视、俯视）；
2. **画出主干体块的六面盒（Six-Sided Volume）**:
   - 用三组平行透视线快速勾画出胸腔与骨盆的空间方盒；
   - 明确标注顶面（Top）、底面（Bottom）、正面（Front）与侧面（Side）；
3. **施加极端尺寸缩减（Extreme Foreshortening）**:
   - 若角色手臂指向镜头：前臂与拳头包围盒放大 $200\% \sim 300\%$，后臂与肩膀包围盒缩小并被前盒大幅重叠遮挡（Overlap）；
4. **通过包裹线（Wrapping Lines）圆化形体**:
   - 在六面体盒内切入带有视平线弧度的横截面圆环，将方盒转化为饱满的肌肉与骨骼。

## Actionable Example (扑向镜头的怪兽爪击透视构图)
1. **第一盒（近景巨爪）**:
   - 在画面下方居中位置，画一个占据画幅 $35\%$ 面积的巨大斜向方盒，底面可见（仰角），利爪刺穿画面边缘；
2. **第二盒（中景胸腔）**:
   - 在巨爪后上方，画一个缩小至画幅 $15\%$ 的胸腔方盒，其左下角被巨爪方盒彻底遮挡；
3. **第三盒（远景头部与后肢）**:
   - 头部包围盒仅占画幅 $8\%$，深陷在两肩方盒之间；后腿脚掌触地点落在画面中上方；
4. **效果验证**: 观者瞬间产生怪兽爪子即将破屏抓碎自己面门的强烈纵深压迫感。

## Constraints (约束与禁止)
- **严禁全身体块尺寸等比例缩放**: 绝不能把近端肢体与远端肢体画成相同大小，否则空间深度立刻塌陷为正交轴测图；
- **严禁反向垂直位置**: 在正常俯视/平视视平线下，近景角色的触地点绝不能画得比远景角色的触地点更高；
- **严禁缺乏体块重叠（No Overlap）**: 肢体前后交界处必须有明确的轮廓线交叠（T-Junction），体现前者对后者的空间遮挡。

## Verification (验收标准)
- **尺寸比率检验**: 最前主体与最后主体的投影面积比是否达到 $3:1$ 以上；
- **盒体朝向闭环**: 身体各体块的空间包围盒顶/底/侧面透视方向是否与视平线逻辑严密统一。
