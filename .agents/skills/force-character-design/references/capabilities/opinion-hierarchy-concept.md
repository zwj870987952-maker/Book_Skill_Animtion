# 能力卡: 主观观点与金字塔层级核心设计哲学 (Opinion & Hierarchy)

## Rationale (核心原理)
很多画师能够精准测量人体解剖比例，但画出的角色却千人一面、缺乏灵魂，本质病因在于**“照相机综合征”（The Camera Syndrome）——机械客观地抄录外在表象，而没有在纸面上建立明确的主观观点（Opinion）**。
Mike Mattesi 强调：**角色设计是画师对被画对象的主观评判、态度与故事提炼**。
为了实现具有强烈吸引力（Appeal）的角色，创作者必须：
1. **克服恐惧（Fear）并拥抱风险（Risk）**：敢于打破写实安全区，承担推向极限时可能“画坏”的风险；
2. **遵循金字塔层级法则（The Hierarchy Pyramid）**：故事内核与观点统领一切，从宏观到微观自顶向下推进，绝不在低层级细节上浪费时间。

## Instruction (观点提炼与金字塔层级工作流)

### 1. 观点提炼（Opinion Formation）公式
动笔前必须用一句话或一个强力隐喻定义该角色：
$$\text{Opinion} = \text{生物/机械原型隐喻} + \text{核心情绪动能} + \text{主导戏剧冲突}$$
- 例如：“这位醉汉像一袋被雨水浸透、随时滑落坍塌的湿面粉袋”；
- 例如：“这位女刺客是一枚紧绷在弓弦上、散发寒芒的黑曜石箭头”。

### 2. 金字塔设计层级矩阵 (Hierarchy Matrix)
```
          /\
         /  \     [ Tier 1: 故事与核心观点 (Story & Opinion) ]
        /    \    [ Tier 2: 主导力量流线 (Primary Force & Pose Push) ]
       /      \   [ Tier 3: 空间包围盒进深 (Spatial Bounding Box) ]
      /        \  [ Tier 4: 大几何形状与三分法 (Shapes & Triangles) ]
     /__________\ [ Tier 5: 明度、色彩与表面细节 (Tone, Value & Texture) ]
```
| 层级代码 | 设计层级 | 关注焦点与决策输出 | 常见误区与违例 |
| :--- | :--- | :--- | :--- |
| **Tier 1** | **故事与主观观点** | 角色身份、社会阶层、心理动机、核心隐喻 | 毫无态度，被动抄袭模特五官 |
| **Tier 2** | **主导力量流线** | 一笔贯通全身的动态动能主线，姿态推向极限边缘 | 肢体散架，局部拼接，缺乏全身贯通律动 |
| **Tier 3** | **空间包围盒** | 尺寸即深度、位置即深度，三维进深与透视压迫 | 平面扁平，肢体无前后遮挡与尺寸衰减 |
| **Tier 4** | **大几何形状** | 直曲对抗、动能三角形、三分法则、面部比例重构 | 充气香肠对称，50% 几何均分死板 |
| **Tier 5** | **明度色彩与细节** | 3-4 阶黑白灰明度，色彩心理学符号，服装道具褶皱 | 一上来就画扣子和睫毛，明度碎花布杂乱 |

## Actionable Example (将一位迟钝的守门大叔设计为角色)
1. **建立观点 (Tier 1)**: “他是一块长了青苔的花岗岩墓碑，沉重、固执、永远不可撼动”；
2. **推挤力量 (Tier 2)**: 将大叔原本微弯的腰脊向下压扁 $140\%$，双脚外八字死死钉在地面，形成向下的重力砸落箭头；
3. **空间盒进深 (Tier 3)**: 将前脚画在画面最底部边缘，并比后脚大 $2.5$ 倍，形成强烈的前后空间跨度；
4. **大形状构建 (Tier 4)**: 躯干采用坚固的方形包围盒，下巴拉长至占面部 $55\%$，额头压缩为一条扁平折线；
5. **明度与细节 (Tier 5)**: 全身以深灰和黑为主，仅在金属门禁卡上留出一抹高光白，强化守门属性。

## Constraints (约束与禁止)
- **严禁跳级设计**: 在 Tier 1 和 Tier 2 未确立前，绝对禁止绘制 Tier 5 的衣褶纹理、纽扣、毛发或渐变光影；
- **严禁无态度安全临摹**: 绝对禁止毫无夸张地“平移”模特的客观生理结构；
- **严禁多观点互搏**: 同一个角色全身必须服从同一个主导隐喻，切忌上半身像猎豹、下半身像乌龟的无序乱炖。

## Verification (验收标准)
- **一句话观点检验**: 观者能否在 3 秒内说出该角色的性格与动物/物体隐喻；
- **层级穿透自查**: 遮蔽所有细节后，纯力量流线与大形状是否依然完好支撑角色的核心戏剧冲突。
