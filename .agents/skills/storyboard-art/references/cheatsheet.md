# 决策规则速查 — 开拍之前：故事板的艺术 (The Art of the Storyboard)

| 能力 | 一句话规则 |
|---|---|
| 动作大戏分镜拆解与多面板连续动态编排（蓄力-击打-反应三步曲） | 编排准备势（Anticipation）、打击破坏高潮（Impact Frame）与受击反应缓冲（Follow-through）的动量隐形剪辑。 |
| 动态故事板 Animatic、节拍器与前期预览流水线（时间线节奏排障） | 将静态面板导入非线性编辑时间线，装配导轨对白与节拍器，在实拍前就地消灭叙事拖沓与节奏病灶。 |
| 标准画框宽高比与构图画幅几何学（1.33:1, 1.85:1, 2.39:1 与安全框） | 解析学院画幅、宽银幕与变形宽银幕画框张力，确立 90% 动作安全框与 80% 字幕安全框工业标准。 |
| 摄影机运动符号学与三维箭头标注规范（Pan, Tilt, Dolly, Zoom, Crane, Track） | 统一摄影机空心粗箭头/框式引导线符号系统，彻底消除与角色位移箭头的工业沟通歧义。 |
| 15秒/30秒商业广告故事板极限压缩叙事（黄金钩子与心智植入） | 执行 3秒 Hook、5秒痛点、14秒产品方案与 8秒品牌定格的严格商业广告分镜黄金时间结构。 |
| 三分法则、黄金螺旋与视觉流线视线引导（构图焦点与负空间） | 应用九宫格交叉点、斜角引导线、视线呼吸留白（Looking Room）与跨面板视觉动能流线平衡。 |
| 180°动作轴线守恒与屏幕方向连续性（追逐同向、对峙对冲与合法过轴） | 锁定假想轴线同侧半圆机位，保持屏幕运动矢量守恒，杜绝无意识跳轴与方向翻转灾难。 |
| 戏剧性明暗调、黑白灰阶与剪影可读性（三阶明暗极速传达） | 提炼白、50%灰、黑三阶极简明暗，应用伦勃朗三角光、高反差低调光与纯黑纯白剪影瞬间可读性。 |
| 一/二/三点透视网格与广角长焦光学空间压缩（视平线与焦距情绪） | 建立视平线与摄影机高度的绝对等价关系，计算广角纵深拉伸与长焦景深压缩的光学空间情绪。 |
| 七级景别标尺与镜头心理学（ELS 至 ECU 人体黄金裁切） | 量化从大远景至大特写的人体解剖非关节裁切法则、环境空间建立与情感心理距离压缩。 |
| 镜头转场与光学剪辑语法（硬切、叠化、淡入淡出、匹配剪辑） | 解析硬切、叠化（时间流逝）、淡黑（篇章终结）、划变与形体/动量匹配剪辑（Match Cut）的分镜表达。 |
| 主体位移、出入画与屏幕矢量指示规范（E.F., X.F. 与多面板轨迹） | 规范角色动作实心细箭头、虚线运动轨迹、跨画框位移以及画外入画（E.F.）与出画（X.F.）技术语法。 |
