# 一/二/三点透视网格与广角长焦光学空间压缩（视平线与焦距情绪）

## 1. 原理与透视光学几何模型

透视不仅是美术造型工具，更是电影与动画导演控制**空间权力关系、心理支配感与真实三维纵深**的核心武器。在分镜故事板的工业实践中，透视系统遵循两大基础物理铁律：

### 1.1 视平线与机位高度等价铁律（Horizon Line Equivalence Axiom）
在地球重力平原环境中，画面中的**视平线（Horizon Line / Eye Level）在几何上恒定等于摄影机光学镜头中心所在的垂直离地高度**！
- 无论场景多么复杂，所有站在同一水平地面的相同身高成年人，其**双眼所在的水平连线在画面中必然与视平线完全重合**（若机位处于正常人眼高度 1.6-1.7 米）；
- **低机位（Low Angle）**：机位压低至膝盖（视平线在画面下部 10%），角色脚底与地平线重合，角色身躯向上拔地而起刺入画框顶部，赋予无与伦比的威严、压迫与霸权；
- **高机位（High Angle）**：机位升至天花板（视平线在画面上部 90% 甚至移出画外），角色被俯视压制在地面网格中，赋予渺小、脆弱、被围困或任人宰割的无助感。

## 2. 三大透视网格体系与戏剧语境

### 透视网格系统分类与应用规范

| 透视类型 | 灭点数量 | 网格构造特征 | 视听语言应用场景 | 心理学倾向 |
| :--- | :--- | :--- | :--- | :--- |
| **一点透视 (1-Point)** | 1 个正中灭点 | 所有纵深线向画框中央灭点强力收缩；水平线与垂直线保持平行 | 笔直公路、幽深长廊、隧道、库布里克式对称走廊 | 宿命感、无法逃脱的通道、严苛秩序、深渊吸入 |
| **两点透视 (2-Point)** | 2 个水平灭点 | 视平线上分布左、右两个灭点；垂直线保持绝对垂直 | 建筑物外转角、室内房间对角线拍摄、城市街角对峙 | 真实三维体块感、自然客观视角、空间体积饱满 |
| **三点透视 (3-Point)** | 3 个立体灭点 | 左右两个灭点 + 天空顶端（仰视）或地面深处（俯视）第三灭点 | 仰拍摩天大楼、俯瞰万丈悬崖、战神巨神兵登场 | 极端失衡、眩晕跌落感、神明上帝俯视、窒息压迫 |

## 3. 光学焦距畸变与空间情绪压缩

- **广角镜头（Wide-Angle Lens / 16mm - 24mm）**：
  - *视场角（FOV）*：宽阔（$> 84^{\circ}$）；
  - *几何物理*：极度拉大前后景物体之间的表观纵深距离。靠近镜头的物体巨大无比，远离镜头的物体急剧缩小；
  - *戏剧隐喻*：速度感倍增（角色向镜头跑两步仿佛跨越千米），空间张力扭曲，狂乱、荒诞、压迫。
- **长焦镜头（Telephoto Lens / 85mm - 200mm）**：
  - *视场角（FOV）*：极其狭窄（$< 28^{\circ}$）；
  - *几何物理*：将前景、中景与数公里外的远景**强烈压缩在同一个二维平面上**，前后景物体比例几乎相同，景深极浅；
  - *戏剧隐喻*：幽闭恐惧、空间拥堵、角色拼命向前奔跑却仿佛在跑步机上原地踏步（慢动作停滞感），冷酷窥探。

## 4. 工业级执行步骤与落地流水线

1. **第 1 步：视平线一键基准定位（Horizon Anchor Line）**
   - 在空白面板画框内，根据镜头情绪首先拉出一条贯穿左右的横向水平基准线（Horizon Line）；
   - 标注摄影机高度：如 `Camera Height: 0.3m (Ground Level)` 或 `Camera Height: 3.5m (High Angle)`。
2. **第 2 步：放射状透视导向网格绘制（Vanishing Grid Sketch）**
   - 确定灭点（Vanishing Point - VP）坐标；
   - 用浅灰细线画出 6-8 条地面与墙面的放射引导线，作为地面网格、瓷砖缝或天花板管道的透视轨道。
3. **第 3 步：沿透视网格校准人物多尺度比例（Character Scale Matching）**
   - 沿地平线高度排列多个角色；
   - 遵循透视法则：所有站在同一平面的角色，其头颈与视平线的相对交界高度保持几何守恒，距离镜头近的角色放大，距离镜头远的角色缩小。

## 5. 典型案例与对比

- **走廊奔跑戏：24mm 广角 vs 135mm 长焦分镜对比**：
  - **设计 A（24mm 广角一点透视）**：走廊尽头的门看起来在千里之外，主角向镜头夺命狂奔，脚步声急促，身体在两秒内从一个微小的黑点暴涨为填满画框的巨大喘息面孔，带来极限的逃生冲刺速度感；
  - **设计 B（135mm 长焦浅景深）**：走廊尽头的门仿佛就贴在主角身后半米处，走廊两侧墙壁被压成扁平薄片。主角疯狂迈步挥臂，但在画框中的体量几乎没有任何放大，呈现出噩梦中拼尽全力却无法逃离原地的绝望心理窒息。

## 6. 常见反模式与纠偏排障

- **反模式 1：游离的双重视平线（Dual Horizon Line Clashing）**
  - *现象*：在一个双人镜头中，左边角色的地面透视线指向画面顶端，右边角色的透视线指向画面底部。
  - *纠偏*：统一锁定全画唯一的视平线高度，严禁左右角色各用各的灭点。
- **反模式 2：长焦画成鱼眼（Telephoto with Fisheye Lines）**
  - *现象*：镜头说明写着 `Lens: 100mm Telephoto`，但画师把角色的拳头画得比头还大三倍，四周线条弯曲。
  - *纠偏*：长焦镜头下垂直线必须笔直平行，前后景物体尺寸比例严格按近距离弱衰减绘制。

## 7. 质量验收硬门

- [ ] 视平线高度在面板中明确锚定，且完全等价于标注的摄影机物理高度。
- [ ] 透视网格（一点/两点/三点）灭点布局精准，地面与建筑结构收敛线逻辑严密。
- [ ] 广角大透视与长焦空间压缩特征符合标注镜头毫米数，无焦距光学矛盾。
- [ ] 场景中多人物的高度比例严格符合透视地面网格缩放比例。
