# 主体位移、出入画与屏幕矢量指示规范（E.F., X.F. 与多面板轨迹）

## 1. 原理与场面调度几何

在电影与动画的静态分镜蓝图中，角色不仅在画框内表演，更在连续的摄影机视界内外穿梭。好莱坞工业标准将角色的运动定义为**屏幕运动矢量（Screen Motion Vectors）**。为了使导演、副导演、特技动作指导（Stunt Coordinator）以及动画绑定与布局（Layout）团队准确理解演员的物理走位（Blocking），必须建立一套无歧义的主体动作箭头与出入画语法：

1. **细实心箭头（Solid Thin Arrows）**：
   - 标注在画框内部，紧贴角色的运动肢体（如出拳的手臂、迈步的脚尖）或道具的弹道轨迹；表示角色的直接运动指向。
2. **虚线尾迹箭头（Dashed Motion Trails）**：
   - 表现角色或物体在三维空间中的复杂曲线运动、漂移或旋转飞行轨迹（如回旋镖、翻滚的特技演员）。
3. **出入画语法（Enter Frame & Exit Frame）**：
   - 电影画框是有物理边界的，演员穿过边界是连接不同时空镜头的最自然剪辑切点。
   - **入画（Enter Frame - 简写 E.F.）**：角色原本在画外，随着动作跨越画框物理边缘进入视界；
   - **出画（Exit Frame - 简写 X.F.）**：角色完成动作后，身体完全脱离画框物理边缘进入画外空间。

## 2. 核心量化指标与出入画标准代码

### 角色动作与轨迹技术标注规范表

| 动作行为 | 工业标准缩写 | 画面表现手法 | 箭头标注规范 | 下一镜头衔接要求 |
| :--- | :--- | :--- | :--- | :--- |
| **从画左入画** | **E.F. Left** | 画框左边缘画出角色迈入的前半身或手臂 | 框内细实心箭头自左边框指向画面纵深或画右 | 前一镜头角色应从画右出画，或为空镜建立 |
| **从画右出画** | **X.F. Right** | 角色背影或后脚残影刚刚越过右边框 | 细实心箭头穿透画框右边缘指向框外 | 下一镜头角色必须从画左入画（保持同向运动） |
| **向镜头冲来** | **Moves toward Camera** | 角色在画面前景急剧放大，形成透视压迫 | 从远景角色脚底指向画框正下方的纵深透视实心大箭头 | 角色可在接近镜头时完全挡黑镜头（天然转场） |
| **远离镜头向深处** | **Moves away from Camera** | 角色背影在画面灭点处逐渐缩小 | 指向透视灭点的收敛细箭头，标注 `Jack runs to horizon` | 传达离去、背弃、孤独消失 |
| **翻滚 / 弧线位移** | **Arc Move / Roll** | 角色受力翻滚或弧线穿插障碍物 | 沿地面透视网格绘制带弧度的虚线曲线带箭头 | 标明旋转周数与最终倒地朝向 |

## 3. 屏幕运动矢量与受众视线动能闭环

- **动能守恒公式**：
  $$\vec{V}_{\text{exit}}(\text{Panel } N) \equiv \vec{V}_{\text{enter}}(\text{Panel } N+1)$$
  - 若角色在第 $N$ 个面板中以高速 $\vec{V}$ 从画右飞出（Exit Frame Right）；
  - 则在第 $N+1$ 个面板中，受众的大脑会在画左边缘预期一个同向的进入动能（Enter Frame Left）；
  - 若画师在第 $N+1$ 个面板中让角色从画右慢悠悠走进来，受众的视线动能将被硬生生截断，造成强烈的视觉“急刹车”出戏感。

## 4. 工业级执行步骤与落地流水线

1. **第 1 步：角色起止坐标点标记（Blocking Origin & Destination）**
   - 在面板草图上，用极简的火柴人或圆圈标记角色动作起点（Position 1）与终点（Position 2）；
   - 用平滑细实心箭头连接两者，标明走位路径。
2. **第 2 步：出入画代码严格标注**
   - 凡是角色进入画框的面板，在左下角技术栏明确书写：`Jack E.F. from Right, running towards camera`；
   - 凡是角色离开画框的面板，明确书写：`Jack X.F. to Left. HOLD ON EMPTY ROOM FOR 1 SEC`（标明是否留空镜）。
3. **第 3 步：跨面板多重轨迹一致性复核**
   - 将整场追逐戏的 10-20 个面板在白板上一字排开；
   - 顺着箭头方向快速扫视，确保所有实心动作箭头的总矢量流动是一致的波浪线，没有突兀的逆向对冲箭头。

## 5. 典型案例与对比

- **特工潜入大楼多面板出入画衔接**：
  - **Panel 1（LS / 外景）**：特工从楼顶飞索滑降，以极高速度从画右上角斜切向画左下角，实心箭头穿透左边框，标注 `X.F. Bottom-Left`；
  - **Panel 2（MS / 窗内内景）**：玻璃碎裂，特工破窗而入，前半身从画右边缘瞬间撞入，实心箭头指向画左地面，标注 `E.F. Right, crash-lands on floor`；
  - 两个面板的出画与入画形成完美的斜向动能对角线连接，受众在 0.2 秒内完全理解特工破窗的物理轨迹。

## 6. 常见反模式与纠偏排障

- **反模式 1：瞬间移动凭空出现（Teleporting Character Trap）**
  - *现象*：前一个镜头房间里空无一人，后一个镜头突然一个角色端着咖啡坐在沙发上，既无入画镜头，也无转场交代。
  - *纠偏*：补画一个角色推门走入（E.F.）的面板，或者前置一个空镜头叠化（Dissolve）代表时间流逝。
- **反模式 2：逆向走位撞墙（Reversed Vector Collision）**
  - *现象*：前一个镜头角色向画右奔跑并出画，下一个镜头却从画右走进来继续向左跑，在视觉上看起来角色像在折返跑。
  - *纠偏*：将第二个面板镜像翻转，使角色从画左进入继续向画右跑，保持屏幕方向绝对一致。

## 7. 质量验收硬门

- [ ] 框内主体位移箭头一律采用细实心箭头或虚线轨迹，与摄影机双线空心箭头严格区隔。
- [ ] 凡涉及画面边界穿越的镜头，明确标注 E.F.（入画）与 X.F.（出画）代码与方位。
- [ ] 连续面板之间保持屏幕运动矢量守恒，跨切点动量对齐无突兀逆向。
- [ ] 动作终点（Position 2）有清晰的落地姿势与重心描摹，指导演员与动画师摆 Pose。
