# 决策规则速查 — 动画的时间掌握

| 能力 | 一句话规则 |
|---|---|
| 动画时空双轴与单双格决策法则 | 按 24fps 换算总帧数，中慢速优先双格防抖，高速与运镜强制单格 |
| 慢进慢出与非线性空间切分法则 | 利用对半切分法则在两端极值密排中间画，构建平滑 S 曲线 |
| 动作预感时空配比与蓄力机制 | 反向蓄力时间为主动作的 2.0-3.0 倍，反向位移占比 15%-30% |
| 多级关节鞭梢时序与交搭延迟 | 自主动力源向末梢逐级向后推移 1-2 帧延迟，形成 S 型拖拽弧线 |
| 质量、重力与落体碰撞计算表 | 下落遵循二次方间距（1:3:5:7:9），重物落地 0 反弹并强制 Hold 12-20 帧 |
| 人类步态时序与情绪步频律表 | 标准走步单步 12 帧，奔跑单步 6 帧带全腾空相，严密对齐 Contact/Down/Passing/Up |
| 四足动物步态时序与脊椎律表 | 走步按左后-左前-右后-右前三角轮转，飞奔由脊椎伸缩弹簧驱动带腾空相 |
| 戏剧停顿与受惊受击反应时钟 | 受击变形 1-2 帧内极速爆发，微震 3 帧后必须绝对静止定格 8-16 帧供观众消化 |
| 视听对齐提前量与对白口型同步 | 闭唇音提前 2 帧闭合，元音峰值提前 1 帧到达，身体重音动作提前 2-3 帧触底 |
| 摄影机平移摇移与防频闪控制 | 摄影机移动强制全层级单格拍摄，避开竖向线条共振速度带，脚步与背景位移绝对锁定 |
| 极速运动跳帧排障与残影补偿 | 少于 4 帧大位移严禁画写实中间画，采用 Smear 扇形变形张或速度线桥接起止点 |
| 简谐阻尼振荡等时性与摆动物体法则 | 振幅指数衰减但往复周期帧数严格恒定，两端正弦极度慢进慢出 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
