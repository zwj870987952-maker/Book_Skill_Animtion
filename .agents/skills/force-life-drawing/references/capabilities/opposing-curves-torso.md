# 能力卡: 躯干对抗曲线与胸腔骨盆反向扭转 (Torso Counter-Torque)

## Rationale (核心原理)
人体全身的动力学引擎是**躯干（Torso）**，而躯干由两大最沉重且坚硬的骨骼体块主导：**胸腔（Ribcage）**与**骨盆（Pelvis）**。
初学者在速写躯干时，最常犯的错误是将躯干画成一个平行的圆柱体或长方形积木，胸腔和骨盆朝向完全一致。
Mattesi 指出：在真实人类生命动态中，胸腔和骨盆**永远处于对抗状态（Opposition / Counter-Torque & Counter-Tilt）**：
1. **反向倾斜 (Counter-Tilt)**：当胸腔向左倾斜时，为了避免身体摔倒，骨盆必须向右反向倾斜维持重心投影；这导致躯干一侧发生剧烈的**挤压（Squash）**，另一侧发生剧烈的**拉伸（Stretch）**；
2. **反向扭转 (Counter-Twist)**：当胸腔沿纵轴向顺时针扭转时，骨盆必定产生逆时针的反向力矩对抗。
抓住躯干的对抗曲线，就抓住了整个人体姿态的动力学生命线。

## Instruction (躯干对抗结构绘制规程)

### 1. 楔形对立模型 (The Opposing Wedges)
- 将胸腔与骨盆概括为两个卵形球体或带有透视厚度的方块体；
- 在冠状面上，绘制两个体块的倾斜中轴线：
  $$\theta_{\text{ribcage}} \times \theta_{\text{pelvis}} < 0$$
  两轴线向一侧聚拢，向另一侧发散，形成鲜明的楔形夹角；
- **挤压侧 (Squash Side)**: 两体块边缘相互挤压靠近，肌肉软组织受压膨胀隆起，形成深邃的肉褶（Flesh Creases）；
- **拉伸侧 (Stretch Side)**: 两体块边缘被大幅拉开，表皮紧绷，形成刚劲有力的平滑长直线。

```
     [ 躯干反向倾斜与挤压拉伸模型 ]
     
           /===========\  <- 胸腔上缘向左倾斜 (Tilt Left)
          |   (胸腔)    |
           \___________/
             \       /
   (挤压侧:   )     /     (拉伸侧: 骨骼拉长，表皮紧绷呈大直线!)
   肉褶堆叠) (     /
             /     \
          .-----------.
         |    (骨盆)   |  <- 骨盆上缘反向向右倾斜 (Tilt Right)
          \___________/
```

### 2. 空间三维反向扭矩 (3D Counter-Torque)
- **正面中线（Center Front Line）扭曲**: 追踪胸骨柄到耻骨联合的矢状中线，在扭转时呈现强烈的立体 S 弯；
- **前后叠压（Overlapping Shapes）**: 扭向前方的一侧肋骨下缘或骨盆髂嵴，必须明确压在后方体块之上，交代空间先后次序。

## Actionable Example (扭身俯身搏击姿态绘制)
- **胸腔状态**: 上半身向前倾伏并向左侧猛烈扭转，左侧胸大肌深陷，右侧背阔肌拉展；
- **骨盆状态**: 下半身向右侧反拧，承重右髋高高顶起，左髋后沉；
- **落笔执行**:
  1. 第 1 笔：从右侧腋下经肋骨到骨盆拉伸侧，画一条长达 40 厘米的强力直线（Stretch Line）；
  2. 第 2 笔：在左侧腰部画出 2 道紧凑短促的半圆挤压弧线（Squash Creases）；
  3. 第 3 笔：画出跨越胸腔下缘与骨盆上缘的环绕线，确立空间立体对抗。

## Constraints (约束与禁止)
- **严禁平行方盒子**: 严禁将胸腔与骨盆画成相互平行的直筒积木；
- **严禁双侧同时拉伸或同时挤压**: 除非极度罕见的正中对称后仰或正中深蹲，人体躯干必定是一侧 Squash、一侧 Stretch；
- **体积守恒律**: 挤压侧肉块向外横向隆起膨胀的体量，必须在视觉上补偿拉伸侧变薄变细的体量。

## Verification (验收标准)
- **楔形夹角检验**: 在草图上用红笔标出胸骨底缘连线与骨盆髂棘连线，两条直线必须相交成明确锐角，严禁保持平行；
- **扭力感测试**: 观察画作，观众能够强烈感受到模特体内如同拧干的毛巾一般积蓄着巨大的扭力潜能。
