# 能力卡: 动作重叠、多级滞后拖尾与松弛组织运动 (Overlapping Action & Drag)

## Rationale (核心原理)
如果所有身体部件在同一时间启动并在同一时间停止，动画就会呈现机械、生硬的“发条玩偶”质感（Twin-Framing）。
在真实世界中，运动永远是**重叠交错（Overlapping Action）**的：
一个动作在另一个动作尚未结束时就已经悄然启动；同时，主躯干启动时，与其相连的松弛组织（肚腩、双颊、乳房、耳朵）和轻软附属物（长发、裙摆、领带、尾巴）由于惯性与空气阻力，会产生明显的**滞后拖尾（Drag）**；而当主躯干刹车停止时，这些附属物又会冲过头发生**跟随运动（Follow-Through）**。

## Instruction (动作重叠与拖尾编排规程)

### 1. 刚性同步 vs. 多级重叠滞后拖尾心智模型
```
  [ 错误: 全身体块同帧起止 (机械人偶) ]
  帧 1: 全身静止 -> 帧 5: 躯干/头发/手臂同时启动 -> 帧 15: 躯干/头发/手臂同时刹车停死

  [ 迪士尼与大师工程: 多级参差重叠与滞后拖尾 ]
  骨盆重心:    [帧 1 启动] =======================> [帧 12 刹车制动]
  双臂肘关节:       [延迟 2 帧启动] ================> [帧 14 超量过冲回弹]
  马尾长发:             [延迟 4 帧向后拖尾 Drag] ======> [帧 16 冲过头后正弦摆动至帧 22]
```

### 2. 拖尾与跟随实战四步流
1. **确立主动力源与被动附着物（Identify Active vs. Passive Elements）**:
   - 主动源: 骨盆、脊椎、大腿（自主肌肉做功）；
   - 被动源: 头发、披风、松弛下巴、衣服下摆、动物尾巴（受惯性支配）；
2. **绘制运动矢量反向拖尾（Apply Drag）**:
   - 当角色向右加速跑时，被动附着物向左剧烈拉平贴紧身体；
3. **动作交错衔接（Overlap Phrases）**:
   - 在角色跑完第一步脚还没完全站稳时，右手就已经开始拔剑，打破动作段落的界限；
4. **刹车跟随与正弦衰减（Follow-Through & Settle）**:
   - 角色急停后，被动附着物向前甩出，并在 6-12 帧内进行摆钟式的正弦衰减振荡。

## Actionable Example (调校一个戴着长耳帽的女孩转身跑开)
1. **Frame 1-3**: 女孩骨盆与双脚先向右转身启动，但**头部与帽耳由于惯性仍然保持朝向原方向**（滞后 2 帧）；
2. **Frame 4-8**: 身体高速向右奔跑，长长的长耳帽被风阻完全拉扯向左侧水平展开（Drag）；
3. **Frame 9-11**: 女孩急停转回，双脚站定；
4. **Frame 12-14**: 女孩身体已停止，但长耳帽由于巨大动量冲向前方面前（Follow-Through）；
5. **Frame 15-22**: 帽耳在空中回弹摆动 3 个波形后，贴服垂落在肩头。

## Constraints (约束与禁止)
- **严禁全身体块同帧静止**: 画面中必须始终有部分次级元素在运动或呼吸，消除机械冰冻感；
- **严禁被动附着物自主发力**: 披风和头发不能凭空乱舞，必须严格受角色主躯干加速度与环境风力的矢量驱动。

## Verification (验收标准)
- **时间交错感**: 摄影表上各通道（主躯干 vs 头部 vs 次级配件）的关键帧位置是否相互错开 2-4 帧；
- **有机柔软度**: 次级运动是否呈现水流或绸缎般的流畅波形，无生硬折叠。
