# 能力卡: 高速奔跑残影、多重肢体与飞轮腿涂抹 (Smears, Multiples & Whirlwind Runs)

## Rationale (核心原理)
在动画制作中，当角色以极快速度移动（如 1 帧内跨越大半个屏幕，或在 2 帧内挥出数十记重拳）时，传统的写实单帧插值会遇到严重的生理瓶颈：
人眼的视觉暂留机制无法连接相距过远的两个清晰图像，导致画面产生刺眼的**频闪跳帧（Strobe Effect）与动作断裂感**。
经典动画大师与理查德·威廉姆斯发明了极其高级的视觉特效魔法：
1. **残影涂抹画（Smear Drawings）**: 将角色的形体沿着运动矢量方向剧烈拉伸为模糊的干刷长条（Dry-brush smear）；
2. **多重肢体画（Multiples）**: 在单张画稿中画出 3 到 5 条重叠的手臂或腿部，模拟相机长曝光残影；
3. **飞轮腿（Whirlwind / Wheel Legs）**: 将角色的双腿抽象化为高速旋转的圆形风火轮或环状残影烟雾，传递无穷爆发力。

## Instruction (残影与多重肢体制作规程)

### 1. 频闪跳帧 vs. 残影涂抹心智模型
```
  [ 传统写实跳帧缺陷 (视网膜频闪断裂) ]
  帧 1 (左侧清晰人影) --------------------------> 帧 2 (右侧清晰人影)
  观者感知: 两个独立的人影在屏幕两端同时闪烁，大脑无法合成连续位移。

  [ 大师级残影涂抹工程 (平滑过渡与超光速动感) ]
  帧 1 (左侧蓄力) -> 帧 2 [ 沿位移矢量拉伸为占据两点的半透明长残影 ] -> 帧 3 (右侧到位过冲)
  观者感知: 角色如同一道闪电般撕裂空气高速穿梭！
```

### 2. 残影与多重肢体实战四步流
1. **频闪阈值判定（Strobe Threshold）**:
   - 若两帧之间核心主体的位移超过其自身体宽的 50%，且耗时仅为 1 帧，必须激活 Smear 涂抹规程；
2. **沿运动矢量拉伸残影（The Smear Envelope）**:
   - 将角色头部、五官和四肢沿运动轨迹拉长为水滴形或胶囊状长条，前端保持结构轮廓，尾端虚化拉伸；
3. **多重肢体排布（Multiples Layout）**:
   - 在击拳极值帧中，画出 3-4 条不同姿态的手臂，主手臂实线描绘，次级手臂采用淡线或半透明残影；
4. **1 帧存活法则（The Single Frame Rule）**:
   - 极端的残影涂抹画（Smear）与多重肢体画（Multiples）通常**只允许存活 1 帧**！第 2 帧必须迅速收缩恢复正常的严谨结构，否则画面会显得崩坏变形。

## Actionable Example (调校一个角色极速逃跑的“飞轮腿”狂奔)
1. **起跑蓄力（Frames 1-4）**: 角色身体向后大幅度压缩下沉，双眼惊恐瞪圆；
2. **飞轮爆发（Frames 5-10）**:
   - 身体剧烈前倾 45°，双臂向后平飞展直如机翼；
   - 骨盆下方不再画具体的骨骼腿部，而是画成一个由 3-4 道同心旋转红黄运动线构成的“椭圆飞轮风火轮”，外围环绕一圈白色干刷烟雾烟尘圈；
3. **闪电弹射（Frame 11，单帧 Smear）**:
   - 角色整个人在 1 帧内被拉长为横跨屏幕 80% 的一条长箭状残影；
4. **脱离画面（Frame 12）**: 角色完全离开屏幕，原处留下 3 帧逐渐消散的旋转尘土旋涡。

## Constraints (约束与禁止)
- **严禁残影停滞多帧**: 极度变形的 Smear 画稿若连续停留 2 帧以上，观众会明确看出生硬的画面崩坏畸变，必须严格执行 1 帧法则；
- **严禁违背运动矢量**: 残影的拉伸方向必须严格与空间位移速度矢量对齐，严禁横向错位拉伸。

## Verification (验收标准)
- **播放流动性**: 以 24fps 正常速度播放时，高速动作无任何频闪跳帧，呈现丝滑如激光般的高速飞跃感；
- **单帧定格辨识**: 暂停画面时能清晰辨认残影的起止端点与力量流线。
