# 决策规则速查 — 动画师生存手册 (The Animator's Survival Kit)

| 能力 | 一句话规则 |
|---|---|
| 时空双轴标尺与原画轨目表设计 | 严格区分耗费物理帧数（时间）与帧间位移距离分布（空间），以轨目表掌控慢入慢出与偏心动力学 |
| 关键帧、极值帧与过渡原画层级工程 | 以关键帧立意、极值帧定空间边界、过渡原画 (Breakdown) 决定运动弧线与优先倾向的四级分级工程 |
| 人类标准行走四大黄金关键帧与步频标尺 | 以接触、下沉、越过、最高四大黄金姿态构建行走循环，重心中轴正弦波起伏与骨盆胸廓反向倾斜代偿 |
| 奔跑、腾空滞空与跳跃受力全周期 | 以双脚完全离地腾空期为分水岭编排奔跑循环，下蹲蓄力、蹬地推离、滞空悬停与撞击受压跳跃全周期 |
| 重量感传递、重力沉降与多级阻尼缓冲 | 依据质量与刚性分配自由落体加速度与触地挤压幅度，重心中轴超量下沉与多级肉体组织阻尼振荡 |
| 动作预感反冲与超量阻尼振荡 | 在剧烈动作前施加反向预备蓄力 (Anticipation)，急停时让肢体冲过目标 10%-20% 并阻尼回弹稳定 |
| 弧线运动轨迹与多级柔性鞭打动力学 | 消除生硬折线中割，沿圆滑弧线轨迹滑行，多级串联关节正弦波反转实现末端加速鞭打释能 |
| 动作重叠、多级滞后拖尾与松弛组织运动 | 骨盆重心主动力源先行，头发、服饰、松弛皮肤与尾巴反向滞后拖尾并在急停时超量跟随摆动 |
| 对白口型视素同步、2-4帧超前量与身体重音 | 关键视素嘴型比声学音频波形提前 2-4 帧开启就位，精简弱读音节，身体动作重音与台词爆破点同频共振 |
| 潜行、跛足与个性化行走步态演化 | 变异接触位脚尖触地、调整下沉最高位落差并施加非对称时间分配，演化潜行、阔步与跛行个性步态 |
| 高速奔跑残影、多重肢体与飞轮腿涂抹 | 以单帧存活干刷涂抹 (Smear)、多重肢体 (Multiples) 与同心圆飞轮腿化解超高速位移视觉频闪跳帧 |
| 五指翻页法、中间画排障与动画工程自检 | 运用五指翻页法高速搓动对比极值与过渡帧，排查穿模抖动、容积漂移、关节糖纸扭曲与弧线断裂 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
