# 能力卡: 姿态速写与生命力捕捉 (Gesture Drawing & Vital Force)

## Rationale (核心原理)
在传统美术教学中，画师常被训练去精确测量肌肉与骨骼长短，结果画出的线条僵死死板，宛如医学解剖室里的无生命切片（The Cadaver Drawing）。
迪士尼传奇动画导师 Walt Stanchfield 提出了震耳发聋的黄金箴言：
> **“Don’t draw what it is, draw what it is doing!”（不要画形体是什么，要画形体在做什么！）**

人体是一台在大地重力与情绪冲动中做功的生命引擎。骨骼与肌肉仅仅是执行物理做功的工具，而**姿态（Gesture）则是发号施令的灵魂**。
姿态速写（Gesture Drawing）要求画师从动笔的第 1 秒起，完全超越解剖细节，一笔抓取贯穿角色全身的动作动量、情感欲望与重力流动。

## Instruction (姿态速写捕捉四步规程与意图提炼)

### 1. 姿态优先于解剖（Gesture vs. Anatomy）心智模型
```
  [ 传统写实错误: 局部解剖拼接 ]              [ 迪士尼大师哲学: 姿态驱动全身 ]
      (头颅球体)                                    (灵魂冲动 / 动作意图 The Doing)
          |                                                       |
      (颈部圆柱)                                                  v
          |                                      ==== [ 贯穿全身的主导动力线 ] ====
      (胸肌拼图)                                /                 |                 \
          |                                (头部向前探)       (脊背如弓绷紧)      (后足蹬地反冲)
      (手臂/腿部碎片)                                \                 |                 /
  [僵死、呆滞、散架、缺乏动能]                       ====== [ 全身体块顺应动力线排列 ] ======
```

### 2. 姿态速写实战四步流
1. **意图提炼（Identify the Doing - 0至5秒）**:
   - 观察模特或构思动画动作，用动词定义姿态：“他在向前猛扑”、“她在承受万钧重压下疲惫叹息”；
2. **第一笔主导动力线（The Driving Line of Action - 5至10秒）**:
   - 笔尖不离纸面，划出一根由受力足部穿透骨盆与脊椎、直达头顶或施力手掌的流畅长线；
   - 这根线条必须体现出重力的下沉与动能的穿透；
3. **三大体块空间反向倾斜（Head, Ribcage, Pelvis - 10至20秒）**:
   - 在主线上迅速架设头、胸、盆三大椭圆体块，使其保持反向倾斜（Counter-Tilt）与扭转对抗；
4. **四肢直曲导向（Limbs as Force Flow - 20至30秒）**:
   - 用直线对抗曲线勾勒四肢，严禁描摹肌肉轮廓，只画力量从躯干向地面的插销支撑。

## Actionable Example (捕捉一名冲锋摔角手的 30 秒姿态速写)
1. **第 0-5 秒（意图）**: “一头低头冲撞的野牛，重心全压在前方”；
2. **第 5-10 秒（主导线）**: 笔尖从后腿脚趾蹬地点起跑，一笔贯通大腿、如铁轨般压低穿过前倾的背脊，猛烈撞入低沉的前额；
3. **第 10-20 秒（体块定位）**:
   - 胸廓呈巨大前倾椭圆，深陷在两腿之间；骨盆紧缩在后方；
   - 头部沉在两肩之间，面朝地面；
4. **第 20-30 秒（支撑与张力）**:
   - 前腿一笔直线重重插向地面承托冲击，后腿向后拉出一根紧绷的推进直线；
5. **结果**: 全画不到 10 根线条，但充斥着数吨前冲撞击的动能压迫感。

## Constraints (约束与禁止)
- **严禁从五官眼睛或手部局部开始画起**: 必须由全局中轴动力线启动，切忌一上来就扣局部五官导致整体散架；
- **严禁画死板垂直线**: 自然界活着的人体极少有绝对垂直水平线，线条必须始终充满动态倾角与张力；
- **严禁毛糙试探性排线（Chicken Scratching）**: 运笔必须自信果断，用整条手臂和大臂带动笔尖滑行。

## Verification (验收标准)
- **纯动态可读性**: 仅凭 10 秒内勾勒的 3 根主姿态线，观者是否能瞬间读出角色的动作与情感动机；
- **生命力动量自查**: 线条是否呈现连贯不间断的流动感，有无在关节处生硬折断。
