# 能力卡: 趾行动物猫科犬科力量引擎 (Digitigrade Feline & Canine Spine)

## Rationale (核心原理)
猫科（狮、虎、豹、猎豹、猫）与犬科（狼、狐狸、猎犬）是陆地上最完美的捕食者与冲刺机器。
它们的运动力学核心由两大引擎协同驱动：
1. **足部趾行减震与蓄能弹簧（Suspended Hock & Spring）**：脚后跟（飞节）高高悬挂在半空，脚掌（跖骨）倾斜，与高弹性的跟腱共同构成天然阻尼减震器和起跳弹簧；
2. **极度柔韧的弓形脊椎波浪（Spine Wave Engine）**：腰椎拥有惊人的屈伸跨度，在奔跑时脊椎像一把折叠战弓，在极限拱起（极端收缩）与极限延展（极端拉伸）之间往复振荡，为后腿每一次蹬地增加额外的爆发力矩。

## Instruction (猫犬解剖力学对比与脊椎波浪)

### 1. 猫科 vs 犬科解剖力学差异矩阵
| 特征维度 | 猫科动物 (Feline - 狮/虎/豹/猫) | 犬科动物 (Canine - 狼/狗/狐) |
| :--- | :--- | :--- |
| **锁骨与前肢旋转** | 保留游离细小锁骨残余，前爪可自由内旋外旋，善于扑抓、抱摔猎物 | 锁骨完全退化，前肢仅能在单一前后垂直平面摆动，专精长跑耐力 |
| **脊椎柔韧度** | **极致柔韧**：脊椎如水流波浪，可大幅度扭转、折叠与侧向弯曲 | **中度柔韧**：脊椎刚性较高，更倾向于直线稳定巡航奔跑 |
| **飞节与肌腱** | 飞节低矮粗壮度适中，爆发跳跃力强，脚爪可完全收缩（猎豹除外） | 飞节位置较高，跟腱致密坚韧，爪子不可收缩，充当天然防滑钉鞋 |
| **头部与吻部** | 吻部短而强壮，咬合力矩集中，下颚开合角极大（适合短促锁喉） | 吻部长且狭窄，适合高速追逐中连续撕咬与长距离换气散热 |

### 2. 脊椎波浪运动学（奔跑周期）
```
【阶段 A: 极端弯曲 (Flexion)】              【阶段 B: 极端伸展 (Extension)】
        (拱起的背部弧线)                            (下凹并伸长的弓弦)
           ^  ^  ^                                    \___________/
        /           \                                /             \
   (胸部)           (骨盆)                       (胸部前探)         (骨盆后甩)
    /                   \                            /                 \
(前腿后摆)            (后腿前收插入前腿之间)       (前腿全力向前探)     (后腿全力向后蹬出)
```
- **压缩态 (Coiled Spring)**: 后腿完全越过前腿外侧向前探出，后脚掌触地点甚至位于前脚印的前方！脊椎向上弓起成弧形，储存全部弹性势能；
- **释放态 (Released Arrow)**: 后腿向后蹬出直线，脊椎瞬间下拉展平并反向微曲，将胸腔与头颅如箭矢般弹射向前。

## Actionable Example (猎豹极速冲刺骨架力量线)
1. **第一步（力量波浪线）**:
   - 抓取一根贯穿猎豹全身的主动力线：从下巴出发，掠过喉咙，压入低俯的胸部，猛烈翻上腰椎的巨大拱弧，再顺着骨盆俯冲而下直通尾巴尖端；
2. **第二步（悬空飞节弹簧）**:
   - 绘制后肢时，股骨与小腿形成一个巨大的锐角 $\mathrm{Z}$ 字连杆；
   - 飞节（Hock）尖锐地悬在半空，与地面保持倾斜 $30^\circ$ 的长跖骨连线，脚趾肉垫深深扣入地面；
3. **第三步（肩膀与躯干对抗）**:
   - 绘制肩胛骨：高耸突起于背线之上，前腿像撑杆跳的撑杆一样向前抓地。

## Constraints (约束与禁止)
- **严禁画死猫科脊椎**: 绝不能把猫科动物画成刚性木盒！即使在静止卧姿，其脊椎也始终流淌着 S 形或 C 形的潜伏力量流；
- **严禁省略后腿 Z 字连杆**: 趾行动物必须具备“大腿向前、小腿向后、跖骨向前、趾尖抓地”的多级折叠避震结构；
- **严禁将猫爪画成犬爪**: 猫科动物具有伸缩爪与前臂旋转能力，腕关节具备人类手腕般抓握的角度变化。

## Verification (验收标准)
- **飞节悬空度检查**: 确认脚后跟是否明确悬空在距地面适当高度，且后腿表现出弹簧储能蓄势感；
- **动态弯曲度检查**: 冲刺或扑击姿势下，腰椎的弓曲幅度是否能合理解释身体的位移速度。
