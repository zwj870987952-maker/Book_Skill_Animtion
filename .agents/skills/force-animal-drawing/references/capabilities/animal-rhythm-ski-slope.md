# 能力卡: 动物全身力量过山车流线 (Animal Rhythm & Ski Slope)

## Rationale (核心原理)
绘制四足动物最容易出现的问题是“拼装玩具效应”——头、颈、胸、腰、四肢每个部位单独看都画得逼真，但拼在一起却像死气沉沉的标本，缺乏整体动力学生命感。
Mike Mattesi 指出：**动物是一个不可分割的能量流动系统（Force Rhythm）**。
就像过山车（Roller Coaster）顺着起伏轨道高速俯冲并被惯性抛射一样，动物的推进能量从后肢蹄爪蹬地爆发，像一条连绵不绝的“滑雪跳台”（Ski Slope），经由骨盆贯穿脊椎、俯冲滑入胸腹底部、再借由前肢支撑反弹冲出头颅与吻部。
如果不能在第一笔画出这根贯穿全身的节奏动力主线，后续所有细节刻画都将毫无意义。

## Instruction (力量过山车滑雪跳台五步闭环)

### 1. 动物全身力量过山车流线拓扑
```
    (3. 脊椎波峰 Spine Crest)
            /\
          /    \   (4. 俯冲滑雪跳台 Ski Slope)
        /        \
  (2. 骨盆推力)     \ ====> [ 胸腔核心 Chest Core ] ===== (5. 头部向前弹射)
      ^                               \                    /
     / (蹬地反冲)                       \ (前肢承托反冲)    /
 (1. 后肢蹬地)                        [ 前肢触地接地点 Ground ]
```
1. **第一冲量（地面到骨盆）**:
   - 后爪/后蹄蹬地产生反作用力，沿飞节、大腿向斜上方急剧传导，撞击骨盆；
2. **第二传导（脊椎波浪）**:
   - 能量灌入骨盆后，顺着腰椎背线向前方奔涌，形成过山车的第一个抛物线顶点；
3. **第三俯冲（滑雪跳台 Ski Slope）**:
   - 力量掠过背部波峰后，并不直接撞向头部，而是顺着肋骨向斜下方“俯冲滑落”，深入前胸腔与两前腿之间的重力核心；
4. **第四缓冲与借力（前胸到肩胛）**:
   - 俯冲的力量受到前腿着地阻尼缓冲，像滑雪运动员冲下跳台后在弧形末端蓄势起跳；
5. **第五飞跃（头颅与视线）**:
   - 力量由胸底猛烈反弹，顺着颈部下沿或上沿向前上方猛冲，通过下颌、鼻吻部或犄角射向空间前方。

### 2. 不同动物的滑雪跳台形态变异
- **猫科掠食者 (如虎/豹)**:
  - 极长的低矮滑雪跳台：背部波峰平滑，胸部极深且靠近地面，力量在胸底蓄满压缩后，头部水平向前方低伏贴地冲刺；
- **蹄类飞奔者 (如瞪羚/鹿)**:
  - 陡峭的高抛滑雪跳台：骨盆弹跳极高，背部到前胸落差大，头部在长颈支撑下高高扬起，流线呈现大起大落的波浪跳跃；
- **厚皮重装动物 (如犀牛/野牛)**:
  - 沉重巨石滑雪道：能量由巨大的肩背隆肉直接向下沉降压入前肢，流线粗重、顿挫、向下深扎。

## Actionable Example (奔跑猎豹的节奏流线一笔抓取)
1. **起笔 (0-2秒)**:
   - 笔尖从后脚爪蹬地点启动，一笔划过飞节，裹挟大腿后侧弧线翻上骨盆；
2. **运笔 (2-4秒)**:
   - 顺着背线拱起的腰椎向上滑行，到达最高点后，迅速下压——像滑雪跳台一样斜向划过胸廓底部；
3. **弹射收笔 (4-6秒)**:
   - 从胸底一记上扬挑出，顺着喉咙直抵下巴与豹吻，形成极具冲刺动量的前掠箭头；
4. **补充支撑**:
   - 在跳台最低点下方迅速点出向前伸直的前腿与肩胛骨，形成完美的接地受力支撑。

## Constraints (约束与禁止)
- **严禁片段化接骨**: 绝对不要先画一个孤立的头，再接一个脖子，再接胸腔！必须先由贯通的过山车力量流线串联全身；
- **严禁力量断崖中断**: 力量流线在颈肩交界处绝不能出现断裂或直角拐弯，必须保持平滑的切线过渡；
- **严禁忽视重力下沉**: 滑雪跳台必须滑入胸腔底部承托区，如果力量线只漂浮在动物背皮表面，画面就会失去数英里的重量冲量。

## Verification (验收标准)
- **一眼贯通度**: 即使隐去所有的毛皮、五官与斑纹，单凭这一条主力量流线，能否让观者立刻读出动物的奔跑方向与冲刺速度；
- **动量守恒感**: 曲线的曲率过渡是否自然连续，没有生硬折断。
