# animatic-timing-and-audio-sync

故事板动态预演与声画卡点（Animatic 节奏调校、画幅对白时序、音效先入 L-Cut / J-Cut）。

## 核心法则与视听机制

### 1. 动态故事板（Animatic / Story Reel）在动画工业中的核心枢纽地位
在好莱坞与现代动画电影工业中，动态故事板（Animatic）是决定项目生死的“第一部完整电影剪辑版”：
- **概念定义**：将数百张甚至上千张静态分镜图按严格的真实电影时间轴编排，配齐粗剪对白（Scratch Voice）、临时音效（Temp SFX）与参考配乐（Temp Score），辅以镜头的简单二维推拉摇移（2D Camera Pan & Zoom）；
- **低成本试错法则**：动画长片的制作成本高达每秒上千美元。任何节奏拖沓、包袱不响、逻辑不通的剧情硬伤，必须在 Animatic 阶段彻底修改完毕！绝对禁止在三维动画或正式绘制原画阶段才去修改剧本结构。

### 2. 对白波形（Audio Waveform）与画幅切点卡点
- **对白提前量（Dialogue Pre-lap / L-Cut）**：
  - 角色 B 的对白声音，在画面切到 B 之前 8-16 帧就已经在角色 A 的画面上提前响起；
  - 观众在听到声音的瞬间，视线自然被引向即将发言的角色，随后镜头切入 B，行云流水；
- **倾听者反应卡点（Reaction Cut on Punchline）**：
  - 在喜剧或重大剧情揭晓时，关键包袱台词（Punchline）往往不把镜头留给说话者，而是在对白说到一半时切到倾听者的目瞪口呆，喜剧效果成倍放大。

### 3. 画幅停留时间（Screen Duration）的认知心理学计算
静态分镜在动态预演中到底该停几秒？必须根据画面信息量进行严格时间测算：
1. **简单特写（Simple CU）**：画面仅有角色的一张脸和一个简单表情，停留 12 到 24 帧（0.5 - 1.0 秒）即可完全被观众大脑读取；
2. **复杂全景/群戏（Complex ELS/FS）**：画面包含宏大城市地标、复杂道具与 5 个以上角色走位，观众视线需要扫描遍览全图，必须保留 48 到 72 帧（2.0 - 3.0 秒）；
3. **文字与关键线索（On-screen Text）**：画面出现的报纸头条、手机短信，停留时间必须保证“默读该文字两遍”所需的时间（通常不少于 36-48 帧）。

## 动态故事板时间轴剪辑工程对照

```
[Animatic 时间轴分轨规范]
V1 视频轨:  主分镜画稿 (Storyboard Panels，带 2D Transform 关键帧做推拉摇移)
V2 视频轨:  字幕轨 / 动作说明 (Action Notes & Dialogue Subtitles)
A1 音频轨:  角色对白干音 (Scratch Dialogue，波形精准对齐唇部开合)
A2 音频轨:  环境氛围底噪 (Ambience: 风声、雨声、室内空气感)
A3 音频轨:  关键动作点音效 (Foley / SFX: 脚步、关门、开枪、拳击)
A4 音频轨:  情绪参考音乐 (Temp Score，卡点对齐重拍与乐句起伏)
```

## 工业实操排障与反模式

- **禁忌 1：静止幻灯片感（Slide Presentation Syndrome）**：
  - *表现*：画稿在时间轴上像 PPT 幻灯片一样一张张机械硬切换，画面毫无镜头运动。
  - *修正*：在动态预演软件中（Premiere / Storyboard Pro / DaVinci），善用图层分离，对分镜画稿施加微弱的慢速跟推、左右横摇，以及前景与背景的视差分层移动。
- **禁忌 2：声画完全同步切块（Synchronized Slicing）**：
  - *表现*：画稿切换点与对白音频剪辑点 100% 刀刀对齐，声画同起同止，产生极强的打嗝式机械顿挫。
  - *修正*：彻底打散音频与视频的剪辑点，全面引入 J-Cut 与 L-Cut，让声音跨越画面边界流淌。
