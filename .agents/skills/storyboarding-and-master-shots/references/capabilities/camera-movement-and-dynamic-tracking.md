# camera-movement-and-dynamic-tracking

摄影机运动动力学（推拉摇移升降跟、手持呼吸感、视差运动分层）。

## 核心法则与视听机制

### 1. 摄影机运动的六大基本物理形态
摄影机运动是电影将三维真实空间注入时间维度的核心语法：
1. **推镜头（Dolly In / Push In）**：
   - 摄影机物理沿 Z 轴向被摄主体靠近；
   - 心理效应：逐渐剥离周围干扰环境，强制观众与角色的心理焦点高度重合；常用于顿悟（Epiphany）、恐惧加剧或下定决心的戏剧瞬间；
   - *注意区分推进（Dolly In）与变焦放大（Zoom In）*：推进伴随强烈的背景透视视差，变焦则是扁平的画面放大。
2. **拉镜头（Dolly Out / Pull Out）**：
   - 摄影机物理远离被摄主体，向后退入广袤空间；
   - 心理效应：展现个体的孤独无援、在宏大世界中的微弱渺小，或在场景结束时提供超然冷峻的客观总结。
3. **摇镜头（Pan 水平 / Tilt 垂直）**：
   - 摄影机固定在原点做角度旋转；
   - 水平摇（Pan）：连接两个存在因果关系的被摄体（如从持枪者摇向中弹者）；
   - 垂直摇（Tilt）：从脚底摇向面部表现打量、崇敬或压迫。
4. **横移追踪镜头（Tracking / Trucking Shot）**：
   - 摄影机架设在平行轨道或手持稳定器上，与角色保持同步侧向或迎面移动；
   - 视差运动（Parallax）：前景树木以极快速度向后掠过，中景角色保持稳定，背景远山缓慢漂移，创造极强烈的空间三维纵深感。
5. **升降镜头（Boom / Jib / Crane Shot）**：
   - 垂直跨越垂直维度的机位运动；
   - 从俯视地面缓缓升起越过屋顶揭示地平线大军，展现史诗级的空间豁然开朗。
6. **眩晕变焦（Vertigo Shot / Dolly Zoom / Trombone Shot）**：
   - 摄影机物理向前推进的同时光学变焦拉远（或反之）；
   - 角色在画面中的尺寸严格保持不变，而背景空间在一瞬间被极度拉伸或剧烈压扁，制造极度震撼的心理畸变、恐惧与现实坍塌感。

### 2. 摄影机运动动机律（The Law of Motivated Camera Movement）
- **工业铁律**：好的摄影机运动永远是**有动机的（Motivated）**，绝对禁止为了炫技而发生无端机位游走！
- 镜头运动的三大正统动机来源：
  1. **跟随角色物理位移（Follow Action）**：角色站起走向窗前，镜头顺势平移跟随；
  2. **视线与注意力转移（Attention Shift）**：角色猛然转头看向门口，镜头快速轻摇（Whip Pan）切向门口把手；
  3. **情绪与心理压迫（Psychological Pacing）**：角色内心经历极度煎熬，镜头以不可察觉的微速（Creep In）极其缓慢地向其眼神逼近。

### 3. 手持呼吸感与纪录片质感（Handheld Dynamics）
- 在现代动作片、战争片（如《拯救大兵瑞恩》《谍影重重》）中，三脚架的绝对死板被抛弃，引入手持摄影（Handheld Camera）；
- **呼吸感频率**：正常站立时带有 1-2Hz 的微弱身体呼吸颠簸，强化现场目击者的真实在场感；
- 爆炸与剧烈冲突时加入不规则加速度镜头震颤（Camera Shake），但必须在关键动作点（如拳头命中）设置瞬间的瞬态冲击对齐。

## 经典运镜分镜画稿标注规范

在分镜头绘制中，必须采用标准符号标注运镜方向：

```
[分镜运镜符号标准]
- Dolly In (推镜):  框内角向内指的四个对角箭头 (↙ ↘ ↖ ↗)，或在边框外标注 "DOLLY IN"
- Dolly Out (拉镜): 框内角向外辐射的四个箭头 (↗ ↖ ↘ ↙)，或标注 "DOLLY OUT"
- Pan (水平摇):     宽横向实线箭头 (────► PAN RIGHT)
- Tilt (垂直摇):    垂直纵向实线箭头 (▲ TILT UP / ▼ TILT DOWN)
- Tracking (移镜):  贯穿两幅画面底部的水平双实线导轨箭头
- Zoom (变焦):      使用虚线箭头，明确标注 "ZOOM IN" 或 "ZOOM OUT"
```

## 工业实操排障与反模式

- **禁忌 1：机械均速线性运镜（Mechanical Linear Tracking）**：
  - *原因*：在三维中摄影机关键帧切线使用 Linear，机位启动瞬间猛地一震，停下瞬间猛地一撞。
  - *修正*：所有推拉摇移必须严格遵守慢入慢出（Ease In / Ease Out），启动平稳加速，停止平稳减速。
- **禁忌 2：无动机抽搐变焦（Unmotivated MTV Crash Zoom）**：
  - *表现*：角色正在说一句平淡台词，镜头突然连续抽搐变焦放大三次。
  - *修正*：除非是特定伪纪录片喜剧风格（如《办公室》），戏剧镜头必须保持沉稳克制。
