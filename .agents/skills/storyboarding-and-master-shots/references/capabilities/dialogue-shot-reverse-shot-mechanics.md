# dialogue-shot-reverse-shot-mechanics

对话场面正反打与视线接戏（过肩镜头 OTS、外侧反打、目线视线高度匹配）。

## 核心法则与视听机制

### 1. 正反打机位两大核心阵营：外侧 vs 内侧
在拍摄两人对话时，机位存在两种本质不同的视听质感：
1. **外侧正反打（External Reverse / Over-the-Shoulder OTS）**：
   - 摄影机位于两人视线轴线外侧，前景保留对方的肩膀或后脑勺；
   - 视听属性：**空间感与连通性**。观众时刻被提醒“这是两人之间的互动”，两人被锁定在同一个物理空间内；
2. **内侧正反打（Internal Reverse / Clean Single）**：
   - 摄影机移入两人视线之间更靠近中心的位置，画面中完全没有任何对方角色的身体部件；
   - 视听属性：**心理隔离与纯粹情绪**。被摄者仿佛直接直视观众心灵，常用于角色吐露真心、背叛告白或致命审讯。

### 2. 摄影机垂直高度与视线高度匹配（Eyeline Height Match）
- **平视法则（Eye-Level Rule）**：
  - 在平等的对话中，摄影机的高度必须严格调整至演员眼睛的绝对水平线（Eye Level）；
  - 许多业余摄影师图省事将三脚架固定在 1.7 米高度，导致拍坐着的演员变成俯拍、拍高个子变成仰拍，无意中改变了角色的权力关系；
- **倾角带来的潜台词权力力场（Power Dynamics）**：
  - **微仰拍（Low Angle, 10°~15° 向上仰视）**：赋予角色掌控力、权威、压迫感与神圣感；
  - **微俯拍（High Angle, 10°~15° 向下俯视）**：赋予角色弱小、被动、羞愧或孤立无援感。

### 3. 目线交错角（Eyeline Convergence Angle）
- 演员视线与摄影机镜头光轴之间的夹角，决定了亲密度与压迫感：
  - **大夹角（30°~45°）**：角色看着离镜头很远的画外空间，客观平实，没有侵略性；
  - **极小夹角（5°~10°）**：角色几乎正对镜头说话，视线紧贴镜头边缘，带给观众如同面对面被拷问般的强烈侵入感；
  - **直视镜头（0° / Breaking the 4th Wall）**：打破第四面墙，强行与银幕外观众对话。

## 工业实操排障与反模式

- **禁忌 1：视线高低差反转（Mismatched Height Eyelines）**：
  - *表现*：大人坐着、小孩站着，拍大人时大人向下看，但切到小孩特写时小孩居然也向下看。
  - *修正*：无论景别如何切，若角色 A 向上看（Look Up），反打镜头中角色 B 必须严格向下看（Look Down），角度必须互补。
- **禁忌 2：正反打焦距严重失衡（Asymmetrical Lens Pair）**：
  - *表现*：拍男主角时用 85mm 长焦（脸型修长背景奶油虚化），拍女主角时却用了 28mm 广角（脸被拉扁且能看清整个房间乱象）。
  - *修正*：正反打机位对必须保持焦距与物理景深完全对称，除非导演有特殊讽刺或心理扭曲意图。
