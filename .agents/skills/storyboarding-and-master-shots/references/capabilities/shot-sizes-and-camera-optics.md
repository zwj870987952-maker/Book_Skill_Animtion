# shot-sizes-and-camera-optics

景别体系与光学焦距（极远景至大特写、广角畸变与长焦压缩空间、画幅宽高比构图）。

## 核心法则与视听机制

### 1. 景别-心理距离标尺（Shot-Size Psychological Distance Scale）
景别本质上是导演强制观众与被摄主体建立的“心理社交距离”：
1. **极远景（ELS / Extreme Long Shot）**：
   - 人物在画面中仅占几像素或极小剪影，广袤的大自然、星空或废墟占据画面 90% 以上；
   - 叙事功能：确立宏观地理世界观、表现个体的微不足道、宿命孤独或天地苍凉。
2. **远景/全景（LS/FS / Long & Full Shot）**：
   - 角色从脚底到头顶完整容纳在画框之内（“顶天立地”）；
   - 叙事功能：确立角色在物理空间中的站位、行进方向以及与周围环境道具的互动关系。
3. **中景（MS / Medium Shot，腰部以上）**：
   - 经典社交距离（约 1.5 - 2 米），清晰呈现手势、面部朝向与服装细节；
   - 叙事功能：日常叙事与对话的主干承载者，既有情感线索又保留空间语境。
4. **特写（CU / Close-up，肩部/锁骨以上）**：
   - 私密距离（小于 0.5 米），面部占据画面主体；
   - 叙事功能：直接穿透角色的心理防线，捕捉眼球转动、瞳孔收缩、嘴角抽搐等微表情，观众在此处产生强烈的情感共鸣。
5. **大特写（ECU / Extreme Close-up）**：
   - 仅截取眼睛、嘴唇、扣扳机的手指或滴血的刀尖；
   - 叙事功能：极致的戏剧压迫感，剥夺环境信息，强迫观众将全部注意力聚焦于致命细节。

### 2. 光学焦距与透视几何转换
焦距的选择直接改写了三维空间的透视关系（Perspective）：
- **广角镜头（Wide Angle: 14mm - 28mm）**：
  - **透视拉伸（Perspective Exaggeration）**：前景离镜头近的物体被极度放大，背景被推向极其遥远的深处；
  - **动态加剧**：物体迎面走向镜头时，在画面中的尺寸以几何级数暴涨，制造强烈的速度感与冲击力；
  - **边缘桶形畸变（Barrel Distortion）**：边缘线条向外弯曲，常用于制造荒谬、怪诞、压迫或幽闭恐惧。
- **标准镜头（Normal: 35mm - 50mm）**：
  - 最接近人眼的自然透视，透视比例平实客观，不带有明显的主观光学修饰。
- **长焦镜头（Telephoto: 85mm - 200mm+）**：
  - **空间压缩（Spatial Compression）**：将前景与远景压扁在同一个平面上，原本相隔数公里的背景山峦仿佛紧贴在角色脑后；
  - **浅景深分离（Bokeh Isolation）**：前景锐利清晰，背景极度虚化，将角色从杂乱的环境中彻底剥离出来，强化心理孤立感。

### 3. 画幅宽高比（Aspect Ratio）构图几何
- **16:9（1.78:1）/ 1.85:1（经典影视与动画）**：兼顾水平与垂直空间，适合人物站立、动作奔跑与垂直跳跃；
- **2.39:1（宽银幕宽幅 CinemaScope）**：极端的水平横向延展，适合广袤地平线、群戏对峙；但在单人特写时必须利用过肩或前景道具填补两侧空隙，避免空洞。

## 经典分镜参数标尺与机位选择表

| 景别代号 | 人体截取基准线 | 最佳焦距推荐 | 核心叙事功能与心理效应 |
| :--- | :--- | :--- | :--- |
| ELS (极远景) | 微小点状（< 1/10 画面高度） | 18mm ~ 24mm | 世界观建立、天地苍凉、个体渺小 |
| FS (全景) | 脚底贴底、头顶留空（顶天立地） | 28mm ~ 35mm | 肢体动作、打斗招式、环境交互 |
| MLS (中远景) | 膝盖以上（牛仔景 Cowboy Shot）| 35mm ~ 50mm | 展现腰间配枪、拔刀动作与威慑走位 |
| MS (中景) | 腰部以上 | 50mm | 日常社交对白、手势动作 |
| MCU (中特写)| 胸部以上 | 50mm ~ 85mm | 专注交谈、情绪升温 |
| CU (特写) | 锁骨 / 肩部以上 | 85mm ~ 105mm | 心理共鸣、眼神流转、内心冲突 |
| ECU (大特写)| 眼睛 / 嘴唇 / 道具局部 | 100mm 微距 (Macro) | 致命线索、情绪爆发奇点、压迫感 |

## 工业实操排障与反模式

- **禁忌 1：无意义平庸景别堆叠（Tired Medium Coverage）**：
  - *表现*：整场戏无论对白、冲突还是告白，所有镜头全部采用千篇一律的 50mm 中景。
  - *修正*：严格根据戏剧高潮梯次推进景别：建立环境（LS）→ 讨论（MS）→ 冲突爆发（CU）→ 致命揭示（ECU）。
- **禁忌 2：广角人脸贴面畸变（Clown Nose Wide Angle）**：
  - *表现*：在拍摄严肃煽情的女主角特写时，使用 18mm 广角镜头凑近拍摄，导致演员鼻子被极度放大形变如小丑。
  - *修正*：肖像与情感特写严格选用 85mm-105mm 中长焦镜头，保持面部比例优雅自然。
