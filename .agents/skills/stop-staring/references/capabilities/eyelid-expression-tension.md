# 能力卡: 上下眼睑情绪张力与注视感知 (Eyelid Tension & Perception)

## Rationale (核心原理)
在面部解剖中，眼睛常被称为“心灵的窗户”，但真正决定眼睛情绪色彩的不是眼球本身，而是包裹眼球的**上眼睑与下眼睑**。
许多动画师误以为眼睑只有“睁开”和“闭上（眨眼）”两种状态，导致角色眼神要么呆滞如死鱼，要么虚假空洞。
Jason Osipa 揭示了眼睑表达的底层工程法则：
- **上眼睑（Upper Lid）**：由提上睑肌驱动，主导**生理清醒度、警觉程度与震惊感**；
- **下眼睑（Lower Lid）**：由眼轮匝肌下部纤维驱动，主导**内在心理张力、狐疑、忍耐度与真笑挤压（Squint）**。
通过解耦上下眼睑，动画师能够精准调配出人类极其微妙复杂的眼神微表情。

## Instruction (解耦功能与张力矩阵)

### 1. 上眼睑的生理标尺 (Upper Lid Alertness Scale)
定义上眼睑边缘相对角膜（Cornea / Iris）的覆盖高度：
- **极度警觉/惊恐 (Wide Open / Terrified)**: 上眼睑上拉至角膜上方 1-2 毫米，露出眼球上方的白色巩膜（Sclera Ring），传达恐惧、狂喜或强刺激；
- **正常清醒 (Normal Alert)**: 上眼睑边缘切过角膜上缘约 $10\% \sim 15\%$ 的直径，遮盖少许虹膜；
- **倦怠/傲慢/冷漠 (Bored / Sleepy / Smug)**: 上眼睑下垂覆盖瞳孔顶部甚至接近瞳孔中心线，传达无精打采、藐视或情欲；
- **闭合 (Closed)**: 完全下落遮蔽眼球（主要行程由上眼睑完成）。

### 2. 下眼睑的心理张力标尺 (Lower Lid Psychological Tension)
下眼睑几乎不承担生理眨眼的主行程，但其细微上推具有极高心理暗示：
- **真笑挤压 (Duchenne Smile Squint)**: 颧大肌向上推挤面颊，带动下眼睑向上隆起，形成弯月眼弧线；若微笑时下眼睑完全平展不动，必定被观众识破为“皮笑肉不笑的假笑（Botox Smile）”；
- **怀疑/聚焦/瞄准 (Suspicion / Focusing)**: 下眼睑向上抬起 $30\% \sim 50\%$，边缘紧绷拉平，减小垂直进光量，表达角色正在深度怀疑或敏锐锁定目标；
- **松弛中性 (Relaxed Neutral)**: 下眼睑边缘刚好切过角膜底缘，不露下巩膜。

### 3. 视线偏差与注视线校准 (Eyeline Perception vs Reality)
- **视错觉感知陷阱**: 当眼球转向侧方时，由于白色巩膜在内眼角与外眼角的不对称显露，观众感知到的视线焦点往往与眼球数学几何轴向（Forward Vector）产生 $5^\circ \sim 10^\circ$ 的感知偏差；
- **校准法则**: 动画师必须以最终渲染镜头视角（Camera View）中的角膜高光中心为准微调眼球转向，而不是死板依赖三维空间的约束点对齐。

## Actionable Example (上下眼睑状态与情绪组合表)
| 情绪意图 | 上眼睑高度 (Upper) | 下眼睑紧绷度 (Lower) | 典型视觉效果 |
| :--- | :--- | :--- | :--- |
| **纯真狂喜** | 向上抬高露白 $(+0.8)$ | 向上饱满挤压 $(+0.7)$ | 眼睛又大又亮，苹果肌顶起，充满感染力 |
| **狐疑审视** | 略微压低 $(-0.2)$ | 强烈水平紧绷 $(+0.8)$ | 眯缝小眼，目光锐利，充满探究意味 |
| **冷笑嘲讽** | 下垂半遮瞳孔 $(-0.6)$ | 轻度上提 $(+0.3)$ | 傲慢藐视，居高临下看人 |
| **空洞发呆** | 正常偏低 $(-0.3)$ | 完全平展松弛 $(0.0)$ | 无心理张力，目光涣散脱焦 |

## Constraints (约束与禁止)
- **严禁下眼睑承担主要闭眼行程**: 眨眼时，上眼睑承担 $80\% \sim 90\%$ 的闭合位移，下眼睑仅微抬 $10\% \sim 20\%$，严禁让下眼睑像卷帘门一样向上拉升至眼眶中央；
- **下眼白露白限制 (下三白)**: 除非专门设计反派、惊悚或重度病态角色，中性表情下眼球角膜下缘绝对不可悬空露出白色巩膜。

## Verification (验收标准)
- **假笑识别测试**: 对比同一微笑口型下，“下眼睑静止不动”与“下眼睑上推 $50\%$”两个版本，后者在盲测中必须显著获得“真实情绪流露”的高置信度评价；
- **视线聚焦检验**: 让角色双眼凝视特写镜头正前方，观察双侧上眼睑弧度与瞳孔遮盖是否对称且对焦明确，无散光或斜视感。
