## 一、Rationale：核心力学与解剖机理（女性与男性的生物力学分型）

写实女性角色行走的本质**绝非刻意扭胯走猫步**，而是由女性特有的骨骼形态与重心平衡机制自发产生的自然动态：

```
       【男性骨架与步态: 双轨垂直下插】                 【女性骨架与步态: 单轨内收 + 倒 8 字驱动】
               [ 窄骨盆 ]                                [ 宽骨盆 / 大 Q 角 ]
              +----------+                              +--------------------+
              |  |    |  |                              \                    /
              |  |    |  | (垂直股骨下落)                \                  / (股骨向内大倾角)
              |  |    |  |                                \                /
             [足]    [足] (双轨平行落脚)                  [足]             [足] (单轨中线落脚)
```

### 1. 骨盆几何、Q 角与单轨落脚（The Single-Track Footpath）
- **骨架差异**：女性骨盆横向较宽、骨盆腔浅而宽大，股骨大转子（Greater Trochanter）间距显著大于男性；
- **Q 角（股骨内倾角）**：女性从髋臼到膝盖的内聚夹角（Q-Angle）约为 $15^\circ \sim 17^\circ$（男性仅约 $10^\circ \sim 14^\circ$）；
- **步态表现**：双腿迈出时并非平行下插，而是向身体中轴线自然汇聚。两只脚的落脚点几乎排列在同一直线上（**准单轨走线 / Near-Centerline Stepping**），在越过位（Passing）时，悬空脚内踝与承重脚内踝间距极小（通常仅 1~3cm 间隙）。

### 2. 单脚承重对立平衡（Contrapposto & Lazy S）
- 人体躯干由三大刚性体块（头骨、胸廓、骨盆）与两大弹性铰链（颈椎、腰椎）构成；
- 当单脚承重时，承重侧大转子顶出，承重侧骨盆**向上拔高倾斜（Pelvis Roll Hiking）**；
- 为了维持身体总重心垂线始终落于承重足弓之内，胸廓必须朝相反方向**反向倾斜代偿（Counter-Tilt）**，使脊椎形成连续平衡的“懒 S（Lazy S）”曲线。

### 3. 骨盆三轴复合运动与空间水平倒 8 字轨迹（Figure-8 / Lissajous 曲线）
骨盆在三维空间中不是简单的上下跳动，而是三轴旋转与位移复合而成的连续平滑**水平倒 8 字形轨迹**：
- **Roll（Z 轴倾斜）**：承重侧向上顶高，悬空侧顺重力下垂；
- **Yaw（Y 轴扭转）**：迈步侧髋骨向前送出，后蹬侧髋骨后撤，与胸廓形成剪刀式对拧；
- **Pitch（X 轴俯仰）**：女性骨盆天然具有 $5^\circ \sim 10^\circ$ 的前倾角，在下沉（Down）吸收冲击时微俯，在蹬离（High）时稍稍回正。

### 4. 提携角（Carry Angle）与手臂柔和拖尾
- 女性肘关节天然外翻的提携角比男性大约 $5^\circ$；
- 双臂摆动幅度整体比男性克制紧凑，双肘贴合躯干侧面；
- 腕关节（Wrist）与小臂保持柔和的**正弦波滞后跟随（Drag & Follow-Through）**，指关节自然松弛微屈，严禁形成男性紧绷握拳的刚性摆动。

## 二、Instruction：时空双轴规程与步频节奏标尺

### 1. 24 帧标准写实行走时空节奏标尺 (12 帧/步, 24 fps)

```
帧位:   F1 ------- F4 ------- F7 ------- F10 ------- F13 ------- F16 ------- F19 ------- F22 ------- F25 (Loop=F1)
姿态: [Contact] -> [Down] -> [Passing] -> [High] -> [Contact] -> [Down] -> [Passing] -> [High] -> [Contact]
状态:  双脚触地    膝盖深屈    单腿承重    承重蹬离    双脚触地    膝盖深屈    单腿承重    承重蹬离    双脚触地

重心:   (中立)     (最低谷)     (回升)      (最高峰)     (中立)     (最低谷)     (回升)      (最高峰)     (中立)
```

- **接触位（Contact - F1 / F13）**：步幅最大时刻，身体重心中轴处于中等高度，双脚同时着地；
- **下沉缓冲位（Down - F4 / F16）**：前膝深屈吸能，骨盆降至**全周期最低谷**，下沉速度在此制动；
- **越过位（Passing - F7 / F19）**：单腿独立支撑全部重量，承重侧骨盆倾斜顶至**全周期最高倾角**；
- **抬起最高位（High - F10 / F22）**：承重脚跟蹬离地面，骨盆推升至**全周期最高峰**，摆动腿向前抛射。

### 2. 28 帧优雅写实步频映射表 (14 帧/步, 优雅漫步)
如角色设定为穿高跟鞋、长裙或从容散步，可采用 28 帧循环：
- **Frame 1 / 15**: Contact（接触位）
- **Frame 4-5 / 18-19**: Down（下沉缓冲位）
- **Frame 8 / 22**: Passing（单腿越过位）
- **Frame 11-12 / 25-26**: High（蹬地最高位）

## 四、写实女性特有动态细节与次级运动调校

### 1. 走钢丝单轨走线（The Tightrope Effect）
- **脚底外展角（Foot Flare）**：女性自然外八字控制在 **3° ~ 5°**，切勿超过 8°（男性为 8°~12°）；
- **落脚横向间距（Stance Width）**：女性左右两脚着地时，内踝横向间距通常仅为 **3cm ~ 6cm**，近乎踩在同一条直线两侧交替推进。

### 2. 骨盆与胸廓相位差（Phase Shift）
- 在曲线编辑器中，胸廓的 `Rotate Y` 和 `Rotate Z` 曲线应当比骨盆的对应曲线**向后偏移（Offset）1 ~ 2 帧**；
- 这种微小的动力学滞后，能彻底消除 3D 角色常见的“木偶连体硬块感”，形成富有生命弹性的生物链传导。

### 3. 微克制胸部与软组织弹性（Subtle Secondary Dynamics）
- **重力滞后**：COG 在 F4 到达最低点时，胸部软组织在 **F5~F6** 到达最低点并产生微幅向上回弹阻尼；在 F10 达到最高点时，胸部在 **F11~F12** 到达顶点；
- **振幅控制**：写实日常步态中，胸部次级位移控制在极小的 **1mm ~ 3mm** 范围内，写实而不轻浮。

### 4. 颈部与头部防抖反射（Gaze Stabilization）
- 人类内耳前庭系统具有天然的“云台防抖反射”；
- 骨盆和胸腔在不断倾斜翻转时，颈部与头部需微调抵消身体的侧倾，确保角色的**双眼水平线始终平稳注视前进目标**。

## 五、Constraints：工业约束红线与曲线编辑器禁忌

```
[红线 1: 绝对禁止脚底滑步 (No Foot Sliding)]
  - 从 Down(F4) 到 High(F10) 期间，支撑脚 IK 控制器在世界空间中严禁有哪怕 1mm 的前后水平位移；
  - 曲线编辑器对应区间的 Translate/Rotate 必须使用 Flat Tangents（平直切线）锁死。

[红线 2: 严禁机械夸张走秀 (No Over-Exaggerated Catwalk)]
  - 写实日常女性步态不同于 T 台超模，骨盆 Roll 倾斜不可超过 7°，横向 TX 偏移不可超过 5cm；
  - 超过此阈值，角色会瞬间丧失写实生活质感，沦为油腻浮夸的滑稽表演。

[红线 3: 严禁同向倾斜（比萨斜塔病）]
  - 当骨盆右高左低时，胸廓绝不能也是右高左低！二者必须永远保持 Contrapposto 反向剪刀夹角；
  - 否则身体重心中轴将彻底脱离支撑面，角色视觉上会呈现倒塌感。

[红线 4: 严禁膝关节极限死锁抖动（Knee Popping）]
  - 在 Passing 与 High 阶段，腿部控制器伸直长度严禁达到 100% 骨骼极限；
  - 必须保留 1%~2% 的屈曲裕量，防止在曲线插值时单帧瞬发弹簧式爆闪跳帧。
```
