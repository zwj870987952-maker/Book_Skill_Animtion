# 《Stop Staring: Facial Modeling and Animation Done Right》核心专业术语表 (Glossary)

### 1. Viseme (视素)
- **定义**: 语言学中与听觉“音素（Phoneme）”相对应的**视觉发音嘴型单位**。多个听觉音素在发音时可对应同一个视素（例如 /p/, /b/, /m/ 均对应闭唇视素 MBP）。

### 2. Additive Blendshape (加算混合形)
- **定义**: 仅记录模型网格相对基准中性脸差分位移向量（$\Delta \vec{V} = \vec{V}_{\text{target}} - \vec{V}_{\text{base}}$）的变形目标体。在绑定计算中以线性矢量叠加方式作用于基准网格，允许多个目标体同时激活且不产生全量几何覆盖冲突。

### 3. Edge Flow (边流 / 拓扑循环线)
- **定义**: 三维多边形网格中连续四边形共用平行对边构成的几何循环路径（Edge Loop）。在面部建模中，边流必须严格拟合面部表情肌（如口轮匝肌、眼轮匝肌、提上唇肌）的生物同心环与收缩方向。

### 4. 2D Box Slider Interface (二维滑块控制器界面)
- **定义**: Jason Osipa 发明的面部绑定交互控制界面。将两组相互关联且具互斥约束的面部形变（如 Wide/Narrow 与 Open/Closed，或 Up/Down 与 Squeeze）映射至一个二维正方形平面手柄的 X/Y 轴，利用平面边界自然限制非法目标体组合。

### 5. Saccade / Eye Dart (眼动扫视 / 视线微跳)
- **定义**: 人类眼球在两个注视点之间发生的极高速（通常在 1 帧内完成）、离散跳跃式的转动生理现象。与平滑追踪不同，静态注视下的视线转移必须表现为瞬态微跳并伴随定格。

### 6. Lid Follow (眼睑跟随机制)
- **定义**: 眼球上下旋转时，眼睑软组织在眼球推挤与提上睑肌协同作用下产生的被动/主动联动位移。在绑定中通常以驱动键或表达式使上眼睑按眼球 Pitch 旋转角度的 25%-35% 比例随动。

### 7. Zipper Lips (拉链嘴唇 / 嘴角粘连)
- **定义**: 嘴唇从闭合状态过渡到张开状态时，嘴角外侧黏膜相互粘连、由内向外渐进分离的生物接触力学模拟。

### 8. Facial Landmarking (面部地标定位)
- **定义**: 动画师在进行面部表演前，通过追踪鼻唇沟（法令纹）、眉心折痕、头部三轴倾斜角（Pitch, Yaw, Roll）等标志性几何骨架线条，确定面部结构空间朝向与情绪基准的技术方法。

### 9. Squoosh (头部整体挤压拉伸多层变形系统)
- **定义**: Osipa 体系中独立于局部面部表情目标体的全局变形架构。通过包裹变形器或晶格变形器作用于头颅整体，在保持局部眼口细节的前提下，施加符合体积守恒的卡通夸张挤压拉伸与倾斜。
