# 能力卡: 方向力与施加力物理学 (Directional vs Applied Force)

## Rationale (核心原理)
在写实素描与动画速写中，最大的死板陷阱是“把人体看作静止的骨肉拼贴”。
Mike Mattesi 指出：生命的本质是**具有物理目的的能量（Energy with Purpose）**。人体无时无刻不在与重力（Gravity）对抗，并在肌肉协同作用下产生动能。
在 Force 理论中，人体内的一切动能被抽象为两大互为转化的力学矢量：
1. **方向力 (Directional Force)**: 能量沿着身体某一主导结构顺流推进的路径，类似于滑雪者在平缓斜坡上俯冲的惯性流；
2. **施加力 (Applied Force)**: 方向力在遭遇骨骼铰链、坚硬关节或外部支撑地面时，被阻挡并发生强烈的方向扭转与能量弹射，类似于滑雪者猛烈冲撞跳台边缘而凌空跃起。
理解方向力与施加力的转换，是把握动态姿态（Dynamic Pose）内在受力矢量的第一道大门。

## Instruction (受力矢量分析与绘制规程)

### 1. 动能分析三步法 (Force Vector Analysis)
1. **定位重力与支撑基底**:
   - 确定角色的重心（Center of Gravity）与受力脚掌支撑面；
   - 标注重力向下的加速度矢量 $\vec{G}$；
2. **绘制方向力 (Directional Force Curve)**:
   - 用一条轻盈、快速、连续的大弧线描摹动能从发力源顺流而下的通道（如从头部穿过颈部斜方肌冲向后背）；
   - 线条具有明确的速度感与导向性；
3. **标注施加力碰撞点 (Applied Force Apex)**:
   - 在骨骼受力阻挡处（如骨盆髂嵴、大转子、膝关节、后脚跟），画出带有强烈压感与阻滞感的弧顶顶点；
   - 施加力是**改变能量流动方向的引擎**，它迫使动能从身体一侧横向弹射至对侧结构。

```
                    [ 头部 / 重心点 ]
                          O
                         /   <- 方向力 (Directional Force): 顺着重力与姿态俯冲
                        /
                       (     <- 施加力 (Applied Force): 能量撞击背部脊椎突起，
                        \       发生强力反弹转向!
                         \
                          \  <- 次级方向力: 顺势冲向下方的骨盆与承重腿
```

## Actionable Example (投掷棒球姿态的受力分析)
- **阶段**: 后仰蓄力投掷姿态（Wind-up / Backswing）。
- **方向力 1**: 从后仰的头部穿过颈部，顺着脊椎前胸大弧线向前上方推进；
- **施加力 1**: 撞击挺拔的胸腔（Ribcage）前方胸骨柄，胸大肌受到极限拉伸，形成剧烈的施加力顶点；
- **反弹方向力 2**: 动能被反弹折向后背肩胛骨，并沿背阔肌向下俯冲至后侧骨盆；
- **施加力 2**: 撞击后侧臀大肌与股骨大转子，在此处被地面的支撑反作用力牢牢兜住；
- **绘制执行**: 仅用 3 根带有明显压感转折的强力弧线，在 5 秒内锁定全身体态受力框架。

## Constraints (约束与禁止)
- **严禁无方向的被动描边**: 严禁在不知道线条能量流向何方的情况下顺着边缘描线；
- **严禁死锁终止**: 施加力撞击点决不能是死胡同，必须带有指向下一个方向力的弹射切线；
- **力的平衡闭环**: 全身所有方向力与施加力的矢量代数和，必须在物理上与地面支撑反作用力维持动量守恒或角动量平衡。

## Verification (验收标准)
- **动能连续性测试**: 拿铅笔沿着绘制线条从头至脚滑行，整个笔尖运动应当如同滑过无阻力过山车轨道，在施加力处感受到清晰的弹跳推背感，中途无任何生硬折角或堵塞；
- **重量感盲测**: 遮挡面部五官和肌肉细节，仅看 3-4 根受力线条，观察者能够准确指出角色身体哪一侧正在承受百公斤重压，哪一侧正在极速释放。
