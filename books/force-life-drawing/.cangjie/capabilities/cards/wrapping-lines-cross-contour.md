# 能力卡: 环绕包裹线与三维透视进深 (Wrapping Lines & Form)

## Rationale (核心原理)
在纸面或数位板上画速写，最核心的错觉挑战是：**“画板是二维的，但人体是三维立体的。”**
如果只画边缘外轮廓（Silhouette Contours），角色看起来就像是用硬卡纸剪裁出的皮影戏人偶。
许多画者试图通过涂抹阴影调子（Tone / Shading）来创造体积感，但这在 30 秒至 1 分钟的极速动画草图中不仅耗时繁琐，而且往往把画面弄得脏乱不堪。
Mike Mattesi 提出了**环绕包裹线（Wrapping Lines / Cross-Contour Lines）**系统：
线条本身不仅具备外廓导向力，更是一条紧贴形体表面曲率滚动的立体圆环。通过弧线的弯曲朝向与笔触粗细，直接向观众视觉皮层宣告形体在三维空间中的前后进深、圆柱体仰角与透视朝向。

## Instruction (环绕线法则与空间构建规程)

### 1. 视平线与弧度朝向法则 (Eye Level & Curvature Direction)
任何肢体在几何上均可抽象为圆柱体（Cylinder）或圆截面锥体：
- **高于视平线（仰视视角 / Looking Up）**:
  - 圆柱体横截面的圆弧边缘朝上弯曲（凸向天花板，凹向地面）；
  - 环绕线画成深 U 形或下凸弧线，展现我们正在观察肢体的底面。
- **低于视平线（俯视视角 / Looking Down）**:
  - 圆柱体横截面的圆弧边缘朝下弯曲（凸向地面，凹向天花板）；
  - 环绕线画成倒 U 形或上凸弧线，展现我们正在俯瞰肢体的顶面。
- **正对视平线**:
  - 横截面压缩为一条平直横线。

```
     [ 高于视平线 (仰视) ]               [ 低于视平线 (俯视) ]
         .-------.                           .-------.
        (         ) <- 看到底部圆面         /         \  <- 看到顶部圆面
         \_______/                         (___________)
          |     |                            |       |
          |  U  |  <- 环绕线下凸             |  /-\  |  <- 环绕线上凸
          |     |                            |       |
```

### 2. 环绕线的物理锚定点 (Anatomical Landmarks)
环绕线绝不能随机乱涂，必须锚定在人体的关键骨骼地标截面上：
1. **胸腔环绕线**: 紧贴第十肋软骨下缘与剑突，环绕整个胸廓；
2. **骨盆环绕线**: 紧贴皮带线、髂嵴与耻骨联合；
3. **肢体关节环绕线**: 紧贴手腕腕骨环、肘窝弯折线、膝盖骨（髌骨）上下缘以及脚踝内外踝截面。

### 3. 力量与包裹的合体 (Force + Form)
- 环绕线不是与力量线断开的孤立线段，它是**力量线在三维曲面上的自然翻卷延伸**；
- 当一条大推力线条冲过大腿前侧时，笔锋顺势向大腿后侧内侧环绕过去，一气呵成将大腿的体积圆柱交代清楚。

## Actionable Example (前伸冲拳手臂的立体空间构建)
- **姿态**: 角色右臂正对镜头猛烈冲拳（极端透视缩短 / Foreshortening）。
- **执行步法**:
  1. 先画出从肩部到拳头的主推力方向矢量；
  2. 在前臂肌肉最饱满处，画出一道饱满的、凸向拳头方向的椭圆形环绕包裹线，笔触两端压深、中央轻快；
  3. 在拳头与小臂交接处，画出第二道手腕环绕线，并让手腕结构明确叠压在前臂肌肉前端；
  4. 结果：无需任何黑白明暗调子，仅凭 3 根线条，前臂破纸而出的强烈三维纵深感跃然纸上。

## Constraints (约束与禁止)
- **严禁反向透视弧度**: 同一个肢体上，严禁上一根环绕线上凸、下一根环绕线下凸（这会导致形体在空间中发生畸变骨折）；
- **严禁割裂形体的死黑硬圈**: 环绕线必须带有呼吸感，不可画成生硬的实心黑铁箍；
- **前后叠压一致性**: 前方体块必须遮挡后方体块的轮廓线，交接处必须形成清晰的 T 形交点（T-Junctions）。

## Verification (验收标准)
- **三维模型雕刻验证**: 将画出的速写草图交给 3D 建模师，建模师无需追问即可 100% 毫无歧义地判断出肢体的朝向角（Pitch & Yaw）；
- **空间厚度感测试**: 画面中的人体具有清晰的“可被双手环抱”的实体容积感，而非纸片贴画。
