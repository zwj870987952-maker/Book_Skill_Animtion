# 能力卡: 动作预感反冲与超量阻尼振荡 (Anticipation, Overshoot & Recoil)

## Rationale (核心原理)
在生物力学与戏剧表演中，没有任何剧烈动作是凭空爆发的。
在发力之前，生命体必须拉伸相对拮抗肌、调整重心并向相反方向压缩蓄力——这就是**动作预感（Anticipation）**。
同时，当高速运动的肢体突然刹车时，由于惯性作用，肢体会不可避免地冲过预定目标位置，再反弹回位——这就是**超量冲刺与反冲（Overshoot & Recoil）**。
理查德·威廉姆斯指出：
> **“Anticipation prepares the audience for what is going to happen; Overshoot makes the movement snap and settle realistically!”（动作预感让观众做好视觉准备迎接即将发生的动作；超量过冲让动作产生清脆的弹性与真实的物理沉降！）**

## Instruction (预感与超量编排四步规程)

### 1. 预感、爆发与超量全周期心智模型
```
  [ 1. 预感蓄力 Anticipation ] -> [ 2. 闪电爆发 Action ] -> [ 3. 超量过冲 Overshoot ] -> [ 4. 缓冲回位 Settle ]
        (向反方向压缩)                 (高速位移)                (冲过目标 110%)            (弹簧衰减至 100%)
  向前冲刺先向后拉弓              2-3 帧撕裂空间            手臂冲过目标位             回弹 98% 后归位
```

### 2. 预感与超量编排四步流
1. **反向预备矢量确立（Directional Counter-Vector）**:
   - 动作要向右跳，预感必须向左下蹲缩；拳头要向前打，手肘先向后极度拉扯；
2. **预感时间与幅度分配（Timing the Anticipation）**:
   - 预感越慢越深，随后的爆发动作显得越迅猛强大；
   - 喜剧性吃惊动作采用闪电短预感（2 帧极速下缩，随后爆起）；
3. **超量顶点标注（Define Overshoot Peak - Frame $N+1$）**:
   - 动作到达目标位置时不立即停死，在目标帧后插入 1 帧超量帧，位移超越目标 10%-20%；
4. **弹簧阻尼回弹（Damped Oscillation Settle）**:
   - 从 115% 超量点向 95% 反弹，最终在 100% 稳定，耗时 3-5 帧。

## Actionable Example (调校一个角色转头看左侧爆炸的动作)
1. **起始状态（Frame 1）**: 角色平静面向前方；
2. **预感蓄力（Frames 2-4）**:
   - 头部不立即向左转，而是先向右后方微退 5°，双眼微眯，下巴收缩蓄力；
3. **极速转向（Frames 5-6）**:
   - 头部在 2 帧内高速撕裂甩向左侧，五官被拉伸出轻微残影；
4. **超量过冲（Frame 7）**:
   - 头部转动超越目标角度，旋转到左侧 95°（目标本为 80°），头发被甩至极限；
5. **反弹沉降（Frames 8-11）**:
   - 第 8-9 帧头部回弹至 78°，第 10-11 帧最终稳定在 80° 定格。

## Constraints (约束与禁止)
- **严禁无预感突兀启动**: 除非模拟被无预警子弹击中，任何角色自主发起的剧烈动作必须具备反向预感；
- **严禁超量过大导致穿模脱臼**: 超量幅度必须控制在合理生物解剖范围内（通常为目标位移的 10%-20%），防止关节脱臼畸变。

## Verification (验收标准)
- **视觉引导有效性**: 观者的视线是否在动作爆发前被预感成功吸引并聚焦；
- **清脆弹性感**: 动作停止时是否有清脆的“咔哒”弹性入位感，无泥泞漂移。
