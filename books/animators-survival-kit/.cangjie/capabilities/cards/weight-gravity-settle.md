# 能力卡: 重量感传递、重力沉降与多级阻尼缓冲 (Weight, Inertia & Settle Mechanics)

## Rationale (核心原理)
为什么很多电脑动画看起来轻飘飘的，像宇航员在月球表面跳舞？或者像塑料玩具在虚空中滑行？
原因就在于缺乏对**重量感（Weight）与重力沉降（Settle）**的物理严密表达。
理查德·威廉姆斯与经典物理动力学指出：
1. **重力加速度不可违背**: 物体在下落时遵循奇数定律与自由落体定律 $d = \frac{1}{2}gt^2$，速度随着下落时间线性增加；
2. **质量与形变成反比**: 极重的物体（如保龄球、大象）刚性强、惯性极大，触地时几乎不发生弹性拉伸，而是以剧烈的地面震颤和快速制动沉降为特征；
3. **轻弹物体呈现多级阻尼振荡**: 轻而富有弹性的物体（如网球、卡通水球）触地时发生极大挤压横向展平，并产生多次衰减反弹。

## Instruction (重量感塑造与阻尼沉降四步规程)

### 1. 重型刚体 vs. 轻型弹性体受力心智模型
```
  [ 重型物体 (保龄球/重装机甲 - 巨大动量与刚性) ]
  空中下坠: 快速加速下沉 -> 触地冲击: 零挤压、瞬间砸地 -> 沉降: 仅 1-2 帧微小余震制动

  [ 轻型弹性体 (橡胶球/卡通角色 - 弹性形变与阻尼) ]
  空中下坠: 拉伸流线型 -> 触地冲击: 150% 横向挤压展平 -> 反弹: 多级正弦衰减振荡沉降
```

### 2. 重量感传递实战四步流
1. **下落速度曲线标尺（Gravity Timing）**:
   - 上方密集（慢出），下方极其稀疏（末速度极大），触地前 1 帧跨越全距离的 40% 以上；
2. **撞击形变控制（Squash on Impact）**:
   - 依据物体材质属性决定挤压幅度，严格保持容积恒定；
3. **超量过冲与重力沉降（Overshoot & Settle）**:
   - 角色落地时，重心中轴会冲过正常平衡点继续下沉（Overshoot），随后在肌肉力量支撑下慢慢反弹回升（Settle）；
4. **多级组织余震延迟（Flesh Tremors）**:
   - 身体骨骼停止运动后，角色的腹部肥肉、松弛面颊与胸肌会滞后 2-4 帧发生向下的次级余震颤动。

## Actionable Example (表现一个 200 公斤相扑手猛烈跺地)
1. **抬腿蓄力（Frames 1-16，超慢）**:
   - 相扑手单腿支撑，另一条巨腿极其缓慢沉重地抬起，全身重心剧烈倾斜代偿；
2. **重力加速坠落（Frames 17-19，极速）**:
   - 巨腿脱离肌肉阻拦，在重力作用下闪电下砸，第 19 帧脚底距地面仅 2 厘米；
3. **撞击震撼（Frame 20）**:
   - 脚掌重重跺入地面，脚底脂肪垫横向膨胀挤压，全身体块瞬间被压低；
4. **肚腩与肌肉余震沉降（Frames 21-28）**:
   - 第 21-22 帧：骨盆向上微弹；
   - 第 23-25 帧：巨大的腹部赘肉与胸部脂肪在惯性驱使下滞后下沉至极低点；
   - 第 26-28 帧：赘肉向上反弹回位，尘土向四周散开，地面震颤平息。

## Constraints (约束与禁止)
- **严禁匀速落地（No Linear Drop）**: 下落阶段严禁匀速插值，必须体现重力加速度；
- **严禁重物轻飘反弹**: 重型卡车或巨兽落地严禁像乒乓球一样高高弹起，必须体现巨大动能转化为地面震颤与深沉缓冲。

## Verification (验收标准)
- **质感可信度**: 闭上眼睛仅凭画面动态与速度分布，观者能否准确判断角色的体重（是 40kg 芭蕾舞演员还是 150kg 举重手）；
- **停顿沉降自然度**: 停止动作时是否有合理的超量下沉与反向回弹衰减过程。
