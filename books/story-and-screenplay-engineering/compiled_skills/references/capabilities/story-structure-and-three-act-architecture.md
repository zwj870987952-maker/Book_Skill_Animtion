# story-structure-and-three-act-architecture

三幕式剧本架构与节拍器（经典三幕式、建置激励中点危机高潮、悉德·菲尔德范式）。

## 核心法则与剧作力学

### 1. 悉德·菲尔德经典三幕式时间比例范式
在 120 页的标准好莱坞电影剧本（1 页 = 1 分钟银幕时间）中，三幕式结构呈现出绝对严格的物理能量比例：
1. **第一幕：建置（Act I: Setup，占 1-30 页 / 25%）**：
   - **日常平稳（Status Quo，第 1-10 页）**：展现主角在已知世界的生存状态、性格缺陷与潜在生活危机；
   - **激励事件（Inciting Incident，第 10-12 页）**：彻底打破主角生活平衡的外部冲击，提出全片核心戏剧问题（Dramatic Question）；
   - **情节点一（Plot Point 1，第 25-30 页）**：一个不可逆转的重大转折事件，主角越过“不归点（Point of No Return）”，被迫离开熟悉的生活圈，投身完全未知的第二幕世界。
2. **第二幕：对抗与升级（Act II: Confrontation，占 30-90 页 / 50%）**：
   - **上升对抗（Rising Confrontation，第 30-60 页）**：主角尝试用旧有手段解决问题，遭遇层层升级的阻力；
   - **中点危机（Midpoint / Mirror Moment，第 60 页）**：虚假胜利（False Peak）或虚假毁灭（False Collapse）。主角在此处由被动的“逃避应付”彻底转变为主动的“进攻出击”，故事的风险与赌注（Stakes）成倍翻番；
   - **灵魂黑夜（Dark Night of the Soul / All is Lost，第 75-85 页）**：全盘溃败，主角所有旧有生存策略彻底破产，导师死亡或搭档决裂，绝望降临；
   - **情节点二（Plot Point 2，第 85-90 页）**：在绝境中发现唯一一条险象环生的终极反击路径，引爆第三幕决战。
3. **第三幕：结局与决战（Act III: Resolution，占 90-120 页 / 25%）**：
   - **终极危机（The Crisis）**：面临残酷的两难决断；
   - **高潮（The Climax）**：主角付出不可逆的巨大代价，彻底消灭或战胜核心对抗力量；
   - **结局余韵（Resolution）**：建立全新的更高维度的生活平衡。

## 经典 110 页长片剧本时钟节拍表

```
页码范围        结构节拍名称                    戏剧功能与核心事件
Page 01-10     开篇与现状建置 (Opening Image)   主角缺陷生活展示，建立同理心
Page 11-12     激励事件 (Inciting Incident)     飞来横祸或命运召唤，打破生活平衡
Page 13-25     犹豫与辩论 (Debate)             主角抗拒召唤，试图维持旧平衡
Page 26-30     情节点一 (Plot Point 1)          跨越不归点，踏入第二幕新世界
Page 31-55     游戏与考验 (B-Story / Fun & Games) 结识新盟友，探索新规则，副线铺展
Page 56-60     中点危机 (Midpoint)              假性胜利/打击，赌注翻倍，主动出击
Page 61-75     恶魔逼近 (Bad Guys Close In)     对抗力量全面升级，内部团队信任瓦解
Page 76-80     一败涂地 (All is Lost)           死亡气息弥漫，旧有面具彻底粉碎
Page 81-85     灵魂黑夜 (Dark Night)            在绝望深渊中顿悟真正的人生需求 (Need)
Page 86-90     情节点二 (Plot Point 2)          绝地反击的新计划诞生，全军开拔决战
Page 91-105    终极高潮 (Climax)                两难绝境抉择，正面决战，核心矛盾决断

```

## 工业实操排障与反模式

- **禁忌 1：前 30 页无激励事件（The Slow-Motion Wandering）**：
  - *表现*：主角在咖啡馆闲聊、逛街、上班耗费了整整 25 页，故事毫无主线目标。
  - *修正*：激励事件必须严格在第 10-15 页引爆！如果主角在前 15 页没有强烈的欲望被激发，读者立刻弃剧。
- **禁忌 2：第二幕中段塌陷（The Sagging Second Act）**：
  - *表现*：过了解题一之后，主角在 35-75 页之间来回打转，剧情陷入重复的流水账。
  - *修正*：必须设置强大的**中点危机（Midpoint）**！在中点必须将主角从“被动防守”反转为“主动进攻”，并引入致命倒计时（Ticking Clock）。
