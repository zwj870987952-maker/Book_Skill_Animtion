# scene-design-and-conflict-beats

场景设计与冲突节拍（场景正负价值转换、转折点Turning Point、期望与现实裂隙Gap）。

## 核心法则与剧作力学

### 1. 场景的本质：价值两极转换（The Value Charge Shift）
场景不是角色坐在一起喝茶聊天的物理容器，场景是故事能量的最小发动机：
- **定义**：一个场景是发生在特定时空内的戏剧事件，它必须**使角色生活情境中的至少一个核心价值状态发生正负反转（+ 到 -，或 - 到 +）**；
- **废戏检测公式**：
  $$\text{场景起始状态 } (+ / -) \neq \text{场景终结状态 } (- / +)$$
  - 如果一个场景开始时两个人相爱（+），结束时两人依然相爱（+），这个场景就是**彻头彻尾的废戏**！
  - 必须是从“亲密信任（+）”走向“猜忌背叛（-）”，或者从“穷途末路（-）”走向“绝处逢生（+）”。

### 2. 现实与期望的裂隙（The Gap Between Expectation and Reality）
场景中真正的戏剧爆发点，永远发生在“裂隙”张开的瞬间：
1. **主观期望**：角色想要达成一个微小目标（如跟老板提出加薪），角色根据主观经验采取了自以为最小阻力的行动（微笑着递上咖啡）；
2. **现实深渊裂开（The Gap Opens）**：客观现实没有给予预期的顺从，反而爆发了超出意料的巨大阻力（老板冷笑并扔下一叠辞职信，指出公司正在破产调查主角）；
3. **被迫加码升级（Escalation）**：角色被迫面对裂隙，无法退回原点，被迫承担更大的风险，采取次级更大规模的对抗行动。

### 3. 微观节拍递进（Beats & Rhythm）
一个场景内部是由一系列微观**节拍（Beats）**构成的行动与反应链条：
$$\text{行动（Action）} \longrightarrow \text{意外阻力（Reaction / Obstacle）} \longrightarrow \text{情绪裂隙（Beat Turn）} \longrightarrow \text{升级行动（New Action）}$$
- 每一对行动与反应之间，冲突必须逐级升级，绝不允许在同一强度的抱怨上打转。

## 经典场景冲突排查表

```
[场景五问检视表]
1. 这个场景谁拥有最强烈的目标 (Objective)?
2. 谁在极力阻止他实现这个目标 (Obstacle)?
3. 场景开始时的价值状态是什么 (Starting Value: +/-)?
4. 期望与现实的裂隙在哪里裂开 (The Turning Point / Gap)?
5. 场景结束时的价值状态是什么 (Ending Value: -/+)?
   * 如果起始与终结价值相同，立即重写或直接删除该场景！
```

## 工业实操排障与反模式

- **禁忌 1：客套闲聊入场（Hello/Goodbye Syndrome）**：
  - *表现*：场景前三句对白是“嗨，约翰，今天天气真好”、“是的，你吃了么”、“我刚吃了，我们来谈正事吧”。
  - *修正*：**晚入早出（Enter Late, Leave Early）**！直接在冲突爆发前最后一秒切入场景，在胜负决断瞬间立即切出，坚决砍掉一切现实社交废话。
- **禁忌 2：毫无阻力的愿望达成（Smooth Easy Sailing）**：
  - *表现*：主角想要借一笔钱，走进银行，行长微笑着把钱递给他，主角道谢离开。
  - *修正*：世界上不存在顺畅的场景。行长必须刁难、必须揭示主角账户被冻结、或者银行正好遭遇劫匪抢劫！
