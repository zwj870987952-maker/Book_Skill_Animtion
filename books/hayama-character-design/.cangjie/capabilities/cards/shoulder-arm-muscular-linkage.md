# 锁骨、三角肌与手臂肌群旋转联动（衣架力学与体块交错）

## 1. 原理与肩带骨骼关节联动模型

在热血格斗与动作原画中，上肢（手臂与肩膀）是角色直接挥拳、挥剑、格挡与撕扯对手的主要发力工具。许多原画新人最常出现的致命崩坏，是把手臂当成插在胸口两侧的“独立面条”，手臂一旦抬高，整个肩膀要么脱臼，要么平直僵硬如木雕。

羽山淳一的肩臂解剖力学建立在三大物理联动铁律之上：
1. **锁骨衣架力学（The Clavicle Coat-Hanger Axiom）**：
   - 锁骨（Clavicle）内侧端通过胸锁关节（Sternoclavicular joint）死死锚定在胸骨柄上，外侧端连接肩胛骨肩峰（Acromion）。两者构成了悬挂在胸腔顶部的硬质活动衣架；
   - **联动法则**：手臂每上抬 $30^{\circ}$，锁骨外端**必须向上旋转提升约 $10^{\circ}-15^{\circ}$**！当手臂完全举过头顶（$180^{\circ}$）时，锁骨外端几乎竖起呈 $45^{\circ}-60^{\circ}$ 的陡峭斜坡，斜方肌（Trapezius）受挤压隆起饱满硬块；
2. **三角肌扣抱结构（The Deltoid Muscle Clasp）**：
   - 三角肌（Deltoid）分为前束（锁骨部）、中束（肩峰部）与后束（肩胛冈部），呈倒水滴状自上方骨架辐射向下，**紧紧扣抱在上臂肱骨外侧中央的三角肌粗隆上**；
   - 它像一副坚硬的肩铠（Shoulder Armor），将上臂与躯干融为一个紧密的力学整体；
3. **手臂内外旋转的体块交错（Pronation & Supination Twisted Blocks）**：
   - 上臂的肱二头肌（Biceps）与肱三头肌（Triceps）是一对拮抗肌群；
   - 前臂由尺骨与桡骨构成，桡骨围绕尺骨旋转带动前臂旋前（Pronation / 掌心向下）与旋后（Supination / 掌心向上）。旋前时，前臂外侧的肱桡肌与旋前圆肌呈斜向螺旋体块跨越前臂，形成极其生动的螺旋肌肉线条。

## 2. 核心量化指标与手臂形态学参数

### 手臂姿态与肌群三维形变矩阵

| 手臂空间姿态 | 锁骨空间倾角 | 三角肌形变状态 | 二头肌 / 三头肌状态 | 肘部鹰嘴突 (Olecranon) 指向 |
| :--- | :--- | :--- | :--- | :--- |
| **自然下垂 (Neutral)** | 微倾角（向下倾斜 $5^{\circ}$ 或水平） | 水平拉伸，呈饱满长水滴状，盖在肱骨头外侧 | 肱二头肌放松平直，肱三头肌内/外侧头轮廓微显 | 肘尖朝向后方偏内 |
| **水平平举 (Abducted $90^{\circ}$)** | 向上倾斜 $20^{\circ} \sim 25^{\circ}$ | 中束强烈向心收缩隆起，上表面凹入肩峰下窝 | 二头肌被拉长，前臂肌群呈水平圆柱展开 | 肘尖朝向下方地面 |
| **高举过头 (Overhead $180^{\circ}$)** | **陡峭向上拔起 $45^{\circ} \sim 60^{\circ}$** | **被压缩堆叠在锁骨上方**，与斜方肌挤成一团 | 肱三头肌长头被拉伸至极限，腋窝深陷露出前锯肌 | 肘尖朝向画外上方 |
| **蓄力屈肘 (Bent Arm Flex)** | 锁骨微向前倾探出 | 前束绷紧，中束横向隆起 | **肱二头肌爆发性缩短拱起呈球体**；三头肌长头拉直 | 肘尖（鹰嘴突）锐利如刀峰，形成近 $90^{\circ}$ 硬折角 |

## 3. 肘关节骨性三角与鹰嘴突（Olecranon Triangle）

- **肘部不可变硬核**：
  肘关节背侧由三个骨骼标志点构成：尺骨鹰嘴突（Olecranon）以及肱骨内上髁、外上髁。
  - **手臂伸直时**：三个骨点在同一直线上；
  - **手臂弯曲成直角时**：三点构成一个顶角向下的等腰三角形；
  - 在热血动画中，鹰嘴突是表现手臂骨骼硬度最核心的锐角转折点。任何画成圆滑弯管的手肘都会彻底丧失硬派格斗力量。

## 4. 工业级执行步骤与落地流水线

1. **第 1 步：锁骨“V”字形衣架骨架定位（Clavicle V-Hanger Pass）**
   - 确定胸骨柄凹窝（Suprasternal Notch）；
   - 从凹窝向两侧肩膀拉出两条坚硬的锁骨直线，根据手臂抬升高度确定外端拔起角度（手臂举多高，锁骨拔多高）。
2. **第 2 步：三角肌倒水滴罩帽雕刻（Deltoid Cap Placement）**
   - 沿锁骨外侧三分之一与肩峰下沿，将三角肌画成一个厚实的面包块或倒水滴，罩在肱骨上端；
   - 三角肌下尖端死死插在二头肌与三头肌外侧缝隙之间。
3. **第 3 步：前臂螺旋肌肉带铺设（Forearm Spiral Block）**
   - 根据掌心朝向确定前臂旋转：
     - 若出拳握拳掌心向下（旋前），从肘关节外上方向内侧手腕画一条有力的斜向螺旋弧线（肱桡肌流线），界定前臂前表面受光面与侧表面阴影面。

## 5. 典型案例与对比

- **高举重剑蓄力：脱臼直角木偶 vs 锁骨一体化联动**：
  - **错误画法**：画师把男主的双手举过头顶，但锁骨依然横平竖直像一根晾衣杆，肩膀像一个被割裂的圆球，手臂看起来随时会折断脱落；
  - **羽山大师画法**：两根锁骨如大鹏展翅般陡峭向上拔起，几乎贴住下巴两侧。斜方肌如两座小山峰在脖子两侧耸起，三角肌死死卡在头颅两侧，二头肌与背阔肌形成拉直如钢缆的连贯受力线。整个人体呈现出由核心脊椎发力将重剑拔起的浑然一体之势。

## 6. 常见反模式与纠偏排障

- **反模式 1：直插胸侧香肠臂（Sausage Arm Plugg-in Trap）**
  - *现象*：手臂画成两条平行线，直接插在肋骨侧面，肩膀处毫无体积过渡。
  - *纠偏*：必须在手臂根部画出饱满的三角肌罩帽，并连接锁骨与胸大肌锁骨头，使肩膀具有至少一个头长的厚度。
- **反模式 2：圆滑弯曲水管肘（Rubber Pipe Elbow）**
  - *现象*：弯曲的手臂像折弯的橡胶软管，肘部是一个平滑圆弧。
  - *纠偏*：强力切出锐利的鹰嘴突骨性切面，在手肘最凸出点定下坚硬的折角，并画出肱三头肌腱下附着的平整扁平腱膜区。

## 7. 质量验收硬门

- [ ] 手臂在任何上抬姿态中均严格遵循锁骨衣架力学，锁骨外端倾角与手臂高度同向联动。
- [ ] 三角肌作为倒水滴体块紧紧扣抱肩关节，起止点解剖逻辑严密。
- [ ] 前臂在旋前与旋后状态下呈现出自然的肌肉螺旋交错，无扁平平行圆柱。
- [ ] 肘关节具备清晰锐利的尺骨鹰嘴突骨性结构与屈伸三角形态。
