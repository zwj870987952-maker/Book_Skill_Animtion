# 候选案例库 (Case Candidates) - Force: Character Design

## 案例 1: 街头路人向黑帮打手角色的转化 (Case-Reportage-Thug)
- **原型观察**: 地铁车厢中一位身体前倾、双肩耸起、双腿大跨度踩地的壮硕男子。
- **主观观点 (Opinion)**: “这个人像一头随时准备撞碎大门的犀牛。”
- **推挤极值 (Pushing Poses)**: 将前倾角度从原本的 $15^\circ$ 推至 $40^\circ$，将颈部缩进高耸的斜方肌中。
- **形状与三分法**: 采用方形与倒三角形大包围盒，小腿肚与上臂肌肉顶点锁定在 1/3 处。
- **面部比例**: 下巴占面部总长的 $60\%$，额头压缩至 $15\%$，展现粗暴蛮横的性格符号。

## 案例 2: 空间包围盒透视拳击出击 (Case-Box-Punch)
- **情景**: 角色向镜头猛烈挥拳。
- **尺寸即深度**: 近端拳头与拳击手套放大到占据画面面积的 $40\%$，而面部与后侧肩膀缩小至原本的 $1/3$。
- **位置即深度**: 前脚踏在画面最底部边缘，后脚位于画面中上部，两脚之间以强劲的透视对角线连结，制造破屏而出的冲力。

## 案例 3: 3 阶明度控制的夜行刺客 (Case-Tone-Assassin)
- **明度分配**:
  - Value 1 (白/高光): 仅出现在刺客匕首刃口的寒光与面具眼孔；
  - Value 2 (浅灰): 照亮面具前半部与左肩受光面；
  - Value 3 (深灰): 斗篷与皮甲的主体受光区；
  - Value 4 (黑): 斗篷背光阴影与背景暗部。
- **效果**: 视线在 0.1 秒内被匕首白光与面具暗部形成的极值对比牢牢锁定。

## 案例 4: 破旧小镇木屋的拟人化生命速写 (Case-Architecture-Cabin)
- **情景**: 一座经历数十年风吹雨打的淘金热老木屋。
- **拟人化设计**:
  - 倾斜的屋顶如同一个疲惫老人耷拉的肩膀，烟囱向一侧歪斜犹如脱帽致意；
  - 门廊柱子呈微微的 C 曲线下弯，表现承托重力的沉重叹息；
  - 建筑不再是冷冰冰的透视网格，而是具备沧桑性格的“木头角色”。
