# 能力卡: 力量形状抽象与动能引导三角形 (Forceful Shape & Triangle)

## Rationale (核心原理)
复杂的生物形态若缺乏清晰的底层几何形状抽象（Shape Abstraction），画面就会沦为杂乱无章的线条泥潭。
在 Mike Mattesi 的角色设计体系中，几何形状不仅是轮廓外框，更是**动能载体与视线导航仪**。
在所有基础几何图形中，**三角形（The Forceful Triangle）是终极的动能引导结构**：
- 三角形天生具有极高的非对称性与方向性；
- 其锐角顶点（Apex）犹如物理矢量箭头，能以最高流速驱使观众视线沿着斜边飞驰，直达角色的戏剧动作焦点；
- 结合“直曲对抗（Straight vs. Curved）”，一条富有弹性做功的外凸弧线与两条刚劲收拢的支撑导向直线配对，构成了极具生命张力的“力量三角形”。

## Instruction (力量形状抽象法则与动能三角形布局)

### 1. 力量三角形的动能流向结构
```
              [ 锐角顶点 Apex: 视线射出点 / 动能箭头 ]
                                /\
                               /  \
                              /    \  (受力外凸弧线 Force Curve)
    (刚性平直导向边 Straight) /      )
                            /        )
                           /          \
                          +------------+
                    [ 宽阔底边 Base: 重力沉降 / 支撑底盘 ]
```
1. **底边支撑（The Base）**:
   - 代表重量沉降、肌肉发力起点或稳固底盘；底边越宽，力量蓄积越厚重；
2. **两腰不对称对抗（Asymmetrical Sides）**:
   - 一侧为笔直刚劲的引导直线，另一侧为饱满发力的受力外凸抛物线；
3. **锐角顶点（The Apex Arrow）**:
   - 三角形两条斜边汇聚的锐角，直观指向下一个运动体块或角色的攻击目标；
   - 绝不可将锐角置于几何正中央（等腰三角形），必须偏向一侧以赋予速度感。

### 2. 角色设计中动能三角形配置矩阵
| 应用部位 | 宽阔底边所在 | 锐角顶点指向 | 角色戏剧效果 |
| :--- | :--- | :--- | :--- |
| **整体躯干剪影 (倒三角)** | 宽阔双肩与胸大肌 | 极其狭窄的腰部与骨盆 | 英雄、超级猛男、敏捷战士（高机动压迫感） |
| **整体躯干剪影 (正三角)** | 巨大肥硕的腹部与臀部 | 尖细狭窄的脖颈与小脑袋 | 笨拙巨人、怪兽、贪婪地主（不可动摇的低重力） |
| **四肢肌肉与肢节** | 关节近端宽厚肌肉群 | 远端脚踝/手腕收缩点 | 飞速引导视线流向拳头与利爪（穿刺攻击感） |
| **面部五官轮廓** | 宽额头与双眼连线 | 尖锐前突的下巴与吻部 | 狡黠、刺客、狡诈恶棍、狐狸型人格 |

## Actionable Example (敏捷刺客全身三角形串联构图)
1. **第一三角形（上身主导）**:
   - 双肩形成水平宽底边，肋骨向内急剧收缩，腰部作为第一个倒三角形顶点，视线被强行向下压缩；
2. **第二三角形（骨盆与支撑腿）**:
   - 腰部顶点瞬间翻转为第二个三角形的底边，右腿大腿与小腿形成向前下方急剧刺出的长锐角三角形，顶点直钉地面脚尖；
3. **第三三角形（持刃手臂）**:
   - 匕首与小臂呈第三个狭长锐角三角形，顶点直指画面前方目标咽喉；
4. **全画动能**: 三个三角形像串联的箭头连环弹射，形成一气呵成的刺杀动能通道。

## Constraints (约束与禁止)
- **严禁使用规整等腰三角形**: 左右完全对称的等腰三角形是静态锁死的几何死刑，两侧线条曲率与倾角必须不对称；
- **严禁全钝角三角形**: 钝角三角形缺乏明确的方向指向性，角色设计中关键引导结构必须包含明显的锐角；
- **严禁尖端指向画面外无意义空白**: 三角形锐角必须精准指向下一个故事元素或角色交互点，不能造成视觉能量泄露。

## Verification (验收标准)
- **视线流速测试**: 观者视线是否能在 0.2 秒内顺着三角形边缘被自动吸附并甩向尖端焦点；
- **直曲对抗自查**: 三角形的三条边中是否至少包含一条长平直线与一条外凸弧线。
