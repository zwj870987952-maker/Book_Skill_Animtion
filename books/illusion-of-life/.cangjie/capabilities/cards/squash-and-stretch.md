# 能力卡: 挤压与拉伸：生物组织弹性与常数体积守恒 (Squash & Stretch & Volume Conservation)

## Rationale (核心原理)
在迪士尼动画黄金九老弗兰克·托马斯（Frank Thomas）与奥利·约翰斯顿（Ollie Johnston）确立的十二黄金法则中，**挤压与拉伸（Squash & Stretch）**被公推为“无可争议的第一法则”。
没有挤压与拉伸，所有的运动物体都显得如同石头或未经退火的生铁一般僵死。挤压与拉伸赋予了物体真实的生物肉体弹性、内部水分子流动感与对抗重力做功的生命机能。
然而，九老提出了绝对不容妥协的物理底线：
> **“No matter how much a shape squashes or stretches, its VOLUME MUST REMAIN ABSOLUTELY CONSTANT! If an object gets wider when it stretches, it is not stretching — it is ballooning and destroying all credibility!”（无论形体如何挤压或拉伸，其体积必须保持绝对恒定！如果一个物体拉伸时反而变粗，它不是在拉伸——它是在充气，并且正在摧毁所有的物理可信度！）**

数学公理：
若物体在纵向压缩 $Y$ 轴比例为 $k$（其中 $0 < k < 1$），则水平 $X$ 轴与深度 $Z$ 轴必须反向膨胀为 $rac{1}{\sqrt{k}}$！

## Instruction (挤压拉伸形变与容积守恒四步规程)

### 1. 恒定容积挤压拉伸心智模型
```
  [ 正常稳态 Normal ]       [ 纵向拉伸 Stretch (高速下落/做功) ]      [ 落地挤压 Squash (撞击/蓄力) ]
       +-------+                         +---+                                +---------------+
       |       |                         |   |                                |               |
       |  V=1  |                         |V=1| (纵向拉长，径向急剧收窄)        +---------------+
       +-------+                         |   |                                (纵向压缩，横向剧烈展平)
                                         +---+
```

### 2. 挤压拉伸工业级实战四步流
1. **刚性骨架 vs. 软组织解耦（Separate Rigids from Soft Tissue）**:
   - 严禁将刚性头颅骨骼、前臂尺桡骨或小腿胫骨弯曲折断；挤压拉伸发生在面颊肉垫、腹腔腰窝、臀肌与脊柱活动关节上；
2. **运动矢量对齐拉伸（Align Stretch to Velocity Vector）**:
   - 拉伸形变的长轴必须与瞬时速度矢量方向严格平行，前端保持受风阻挤压，尾端向后拉长；
3. **撞击展平与地面紧贴（Squash Flush Against Contact Plane）**:
   - 落地瞬间，形体接触地面的底部必须完全展平成一条紧贴地面的直线，横向膨胀必须均匀对称释放；
4. **容积守恒自检计算（Volume Check）**:
   - 检查横向宽度与纵向高度之乘积，确保整体表面积与体积无肉眼可见的膨胀（Ballooning）或萎缩（Shrinkage）。

## Actionable Example (调校经典“面团袋”从两米高台跳下落地)
1. **下落准备（Frame 1-6）**: 面团袋向上微微充气挺胸，随后向下深屈压缩 20%（预备蓄力）；
2. **空中下坠拉伸（Frame 7-10）**:
   - 在重力加速度驱动下，面团袋沿下落方向拉伸至原长度的 160%，横向宽度收缩为原宽度的 79%；
3. **触地瞬间撞击（Frame 11）**:
   - 底部猛烈撞击地面展平，高度在 1 帧内剧烈压缩至原高度的 45%，腰部软肉横向摊开至原宽度的 150%；
4. **弹性阻尼回弹（Frame 12-16）**:
   - 第 12 帧向上反弹拉伸至 115%，第 14 帧微压至 95%，第 16 帧恢复正常 100% 稳态。

## Constraints (约束与禁止)
- **严禁无动机的胶质软化**: 写实角色不能变成史莱姆软泥怪，骨骼比例必须在挤压拉伸中保持空间锚定；
- **严禁吹气球失真**: 严禁拉伸变长的同时横向变粗。

## Verification (验收标准)
- **容积恒定感知**: 在 24fps 播放下，观者感知到的是有弹性的实体，无任何“充气泡泡”或“脱水干瘪”感；
- **弹性做功可信度**: 挤压是否准确发生在动量传递与受压阻滞的瞬间。
