# 能力卡: 五官解剖体块：眼眶球体、鼻软骨、口轮匝肌筒与耳廓 (Facial Features Volume)

## Rationale (核心原理)
在面部五官建模与表情雕刻中，最常出现的业余缺陷是将五官视为二维平面图案贴在脸上——眼皮像剪纸薄片、鼻子像一条实心泥棒、嘴唇像浮在表面的扁平香肠、耳朵像捏不平的面团。
Uldis Zarins 明确指出：**五官的每一个部件都是严密遵循生物力学与几何厚度的三维独立容积结构（3D Features Volumes）**：
1. **眼睛**：是直径约 $24\text{mm}$ 的三维球体深嵌在骨眶中，眼睑是具有 $2\text{mm}$ 边缘厚度的包裹曲面；
2. **鼻子**：由鼻骨、外侧鼻软骨与大翼软骨构成的 7 个平截面三棱台；
3. **嘴唇**：并非平贴在脸上，而是横跨在上下颌抛物线牙弓之上的**半圆柱拱形肌肉桶（The Barrel of the Mouth）**；
4. **耳朵**：是由耳轮、对耳轮与耳甲腔构成的螺旋立体回旋漏斗。

## Instruction (五官三维解剖体块与几何构造法则)

### 1. 眼睛与眼眶：球体包裹与厚度结构
```
              [ 眉骨骨性遮阳檐 Superciliary Arch ]
                             |
             [ 上眼睑 Upper Eyelid: 覆盖球体上 1/3 ]
           /      (最高点偏向内侧 1/3 Medial)      \
    (内眼角高)                                   (外眼角低/向外后方收缩)
           \      (最低点偏向外侧 1/3 Lateral)     /
             [ 下眼睑 Lower Eyelid: 托举球体下缘 ]
                             |
              [ 眶下缘骨性台阶 Infraorbital Margin ]
```
- **眼睑厚度（Margin Thickness）**:
  - 上下眼睑接触面必须清晰雕刻出约 $1.5 \sim 2$ 毫米的垂直朝向接触切面；
  - 仰视时能清晰看到上眼睑底厚度面，俯视时能清晰看到下眼睑顶厚度面；
- **不对称落差**: 上眼睑弧顶偏向内侧 $1/3$；下眼睑弧底偏向外侧 $1/3$；内眼角位置明显低于外眼角或呈微倾斜。

### 2. 鼻子七大平截面（Planes of the Nose）
1. **鼻根斜面（Root Plane）**: 眉间双眉汇聚向下切入的倾斜倒三角；
2. **鼻骨桥（Bridge Plane）**: 硬骨支撑的狭窄平坦正面；
3. **左右侧壁斜面（Side Planes）**: 由上颌骨额突与外侧软骨构成的坚实侧斜面；
4. **鼻尖双球球冠（Tip Lobule Planes）**: 大翼软骨构成的两个微小并列球体正面；
5. **鼻下底面（Base / Nostril Plane）**: 包含鼻小柱（Columella）与倾斜泪滴状鼻孔的水平朝下底平面；
6. **左右鼻翼（Ala of Nose）**: 紧贴面颊的两个独立半球形软骨翼。

### 3. 口部口轮匝肌半圆桶（The Mouth Barrel）
- **牙弓基座（Dental Arch）**: 门牙与犬齿构成一个向前凸出的抛物线弧形牙槽骨，导致闭嘴时整个口轮匝肌呈拱桥状隆起；
- **上唇两山一谷**: 正中唇结节突出，两侧斜面下挂，人中沟形成正中凹槽；
- **下唇双垫托举**: 由左右两块饱满的卵圆形脂肪垫构成，下缘受颏唇沟（Mentolabial Sulcus）清晰截断。

### 4. 外耳螺旋折叠拓扑（The Ear）
- 外耳轮（Helix）呈 C 形外边缘外卷；对耳轮（Antihelix）呈 Y 字形向上分叉；
- 耳屏（Tragus）遮挡外耳道前孔；耳朵长轴与鼻梁长轴呈完全一致的向后倾斜平行角度（约 $15^\circ \sim 20^\circ$）。

## Actionable Example (雕刻带有立体厚度的眼部与口部)
1. **放置眼球基底**:
   - 在骨眶内插入一个标准的 $24\text{mm}$ 独立球体模型；
2. **拉出上下眼睑厚度带**:
   - 用 ClayBuildup 笔刷沿着球体曲面拉出两条三维立体缎带；
   - 削出厚度面：上眼睑底面朝下，下眼睑顶面朝上，在内外眼角处紧密咬合；
3. **架设口部拱桶**:
   - 在下颌骨前方垫出一块向前隆起的马蹄形肌肉桶；
   - 在拱桶表面切出上唇的三大体块与下唇的两大体块，确保嘴角向面颊深处深陷进去（结节 Modiolus 锚定点）。

## Constraints (约束与禁止)
- **严禁眼睑无厚度刀片边缘**: 眼睑如果雕刻成刀刃般的单线锐角，在打光下会彻底丧失真实感与湿润高光反弹；
- **严禁嘴唇平贴在同一平面上**: 嘴角必须向头部后方大幅弯入，俯视观察嘴部必须是圆润的抛物线拱桥，绝不能是平面的；
- **严禁鼻孔雕成正圆穿孔**: 鼻孔是由鼻小柱与鼻翼包裹形成的倾斜倾角斜水滴形，绝对不是垂直向上的大圆洞。

## Verification (验收标准)
- **俯仰视眼睑厚度检测**: 俯视时能否清晰看到下眼睑完整的受光水平厚度边缘；
- **口角内陷深度测量**: 嘴角连接点（Modiolus）距离面颊前平面的深度差是否达到 1 厘米以上。
