# rigging-interfacing-and-animation-caching

三维角色绑定接口与动画缓存导出管线（控制器命名规范、变形器解耦与Alembic/USD点缓存）。

## 核心法则与工程机制

### 1. 动画与绑定工程接口规范（Rigging API Standard）
动画师与绑定师之间的协同必须建立在坚固的接口契约之上：
1. **统一控制器选集组（Master Character Set / Selection Sets）**：
   - 提供 `ALL_CTRLS`、`BODY_CTRLS`、`FACE_CTRLS` 选集组，支持一键全选打关键帧（Key All）；
2. **控制器归零法则（Default Zero Pose）**：
   - 所有控制器在默认 T-Pose 或 A-Pose 下，所有平移、旋转属性数值必须绝对为 `0.0`，缩放数值为 `1.0`；
3. **IK/FK 无缝匹配与空间切换（IK/FK Seamless Match & Space Switching）**：
   - 手臂与腿部必须提供一键 IK 转 FK、FK 转 IK 的物理空间匹配脚本，严禁动画师手动肉眼对齐。

---

### 2. 动画点缓存导出管线（Alembic .abc / USD Caching）
- **核心痛点**：带有复杂肌肉系统、布料解算、毛发动力学与上百级骨骼绑定的场景文件，在渲染农场打开极其缓慢甚至直接 OOM 崩溃；
- **工业降维方案**：
  - 在动画部门完成最终表演审核后，通过自动化脚本将几何体网格解耦，烘焙输出为 **Alembic (.abc)** 或 **USD** 点缓存；
  - 点缓存仅保留顶点随时间变化的纯三维世界空间坐标序列，彻底剥离全部骨骼与表达式计算，渲染提速 10 倍以上且绝对零穿模风险。

---

## 工业实操排障与反模式

| 常见致命失误 | 缺陷诊断 | 工业标准重构法 |
| :--- | :--- | :--- |
| **控制器初始值带脏数据** | 角色默认姿态下旋转属性为 `0.347`、`-1.205`，动画师归零时角色瞬间扭曲 | 绑定发布前必须执行 `Freeze Transformations` 并通过零值审计测试 |
| **带重型绑定进入渲染农场** | 直接将绑定文件发给灯光渲染组，导致农场并发读取绑定节点死锁 | 强制执行缓存烘焙交接标准，下游只接收纯 Alembic / USD 点缓存资产 |
