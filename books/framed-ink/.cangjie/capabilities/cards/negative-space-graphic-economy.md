# 能力卡: 留白力量、纯粹极简与负空间引力场 (Negative Space, Subtraction & Graphic Gravity)

## Rationale (核心原理)
初级画师最大的恐惧是“白纸上的空白”，因而拼命在画面每个角落塞满琐碎的砖石纹理、落叶、杂草与排线，生怕别人觉得自己“偷懒”。
但好莱坞顶级视觉总监 Marcos Mateu-Mestre 告诫：
> **“Negative space is NOT empty space; it is an invisible ocean of emotional gravity! What you leave out defines what you put in. Master the courage of SUBTRACTION!”（负空间绝非虚无的空白，它是承载情感重力的无形海洋！你所舍弃的，定义了你所保留的。大师必须掌握减法的勇气！）**

- **负空间（Negative Space）**: 画面中主体之外的空旷区域（大面积阴影、万里无云的天空、空旷水面）；
- **极简明晰（Graphic Economy）**: 剥离所有对戏剧冲突无贡献的杂乱细节，使画面的轮廓像图形商标一样强悍清晰；
- **空间引力场（Gravitational Pull）**: 负空间本身具有巨大的物理压迫感，能像重锤一样把主体推向画框边缘，或像黑洞一样将观者视线强力吸附。

## Instruction (负空间减法与图形极简四步规程)

### 1. 杂乱堆砌 vs. 负空间引力场心智模型
```
  [ 错误: 琐碎堆砌 (视网膜视觉噪音，毫无呼吸感) ]
  画面每个角落填满砖缝、云朵碎片、细碎杂草与排线，主体淹没在灰尘中，大脑神经疲惫。

  [ 大师级工程: 负空间引力场与纯粹减法 ]
  +-----------------------------------------------------------+
  |                                                           |
  |             [ 巨大的纯黑 / 纯白负空间海洋 ]               |
  |             (承载不可言说的孤独、死寂与等待)               |
  |                                                           |
  | [ 角色极度紧缩在右下角角落 ]                               |
  +-----------------------------------------------------------+
```

### 2. 负空间提炼实战四步流
1. **执行 40% 减法清理（The 40% Subtraction Test）**:
   - 审视草图，无情抹去 40% 的琐碎背景线条，若画面的故事与力量未受丝毫损耗，果断永久剔除；
2. **大形状负空间雕刻（Carve the Negative Void）**:
   - 确保主体角色外围形成的空气负空间呈现连贯、优雅或锋利的几何形态（如一个巨大的负空间 C 弧或楔形）；
3. **推向画框边缘（Push to the Edge）**:
   - 让负空间占据画面的 70%-80%，将主体逼至画框的极限边角，制造绝境求生的紧绷感；
4. **留白作为呼吸停顿（The Visual Rest）**:
   - 在高潮打斗或剧烈爆炸画面之后，安排一张极简大留白的分镜，赋予观者大脑消化情节的心理呼吸窗口。

## Actionable Example (表现刺客在暴风雨前夕的屋顶孤身守候)
1. **构图减法**:
   - 不画整座繁复城市的千家万户与窗框细缝；
2. **负空间布局**:
   - 整个画幅上方与中部 85% 是一大片压抑深沉、不带任何多余杂线的纯黑色阴沉夜空；
   - 唯有一轮冰冷修长的白色弯月静静悬在负空间中央；
3. **主体克制安置**:
   - 仅在画面最右下角的微小角落，勾勒出一道尖锐的黑色哥特式屋顶檐角；
   - 刺客宛如一只黑色石雕鬼怪，单膝跪在檐角尖端，风衣下摆随风拉出几根利落的硬直线；
4. **结果**: 巨大的黑色夜空负空间释放出山雨欲来的深沉死寂，刺客的孤独与冷酷深入骨髓。

## Constraints (约束与禁止)
- **严禁无意义的装饰性排线（No Ornamental Hatching）**: 严禁为了“显得画面丰富”而添加任何与光影、结构或情绪无关的细碎交叉排线；
- **严禁负空间形状零碎割裂**: 负空间必须是连贯贯通的大海洋，严禁被散乱的细小物件分割成一地碎瓦。

## Verification (验收标准)
- **图形剪影纯度测试**: 将画面反色观察负空间，负空间外轮廓自身是否呈现强烈的雕塑美感；
- **呼吸感体验**: 观者在凝视画面时是否能感受到空旷区域带来的情感重力与心理呼吸。
