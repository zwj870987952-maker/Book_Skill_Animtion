# 能力卡: 前景压迫、中景叙事与远景空气纵深 (Foreground, Midground & Background 3-Layer Depth)

## Rationale (核心原理)
很多初学者绘制的分镜或概念图看起来像平面的“剪纸皮影戏”——所有人物和物体仿佛贴在同一块玻璃板上，缺乏令人身临其境的真实空间深度。
在 Marcos Mateu-Mestre 的构图哲学中，银幕是必须被刺穿的三维幻觉空间。构建宏大空间纵深的核心引擎是**严谨的三层空间架构（3-Layer Spatial Depth Engine）**：
1. **前景（Foreground）**: 扮演“空间标尺”与“画中画框架（Framing within a Frame）”，以巨大、虚焦或纯黑的剪影体块压迫在镜头前，赋予受众身临其境的偷窥感与沉浸感；
2. **中景（Midground）**: 戏剧舞台的核心所在，角色在这里展开互动、交谈与搏杀；
3. **远景（Background）**: 世界观与宏观环境的容器，通过大气透视（Atmospheric Perspective）与对比度阶梯式衰减，推开无穷无尽的空间维度。

## Instruction (三层空间纵深构建四步规程)

### 1. 三层空间纵深与明度衰减心智模型
```
  [ 前景 Foreground (离镜头 0.5-2 米) ] -> 巨大尺度 / 纯黑重剪影 / 框架遮挡 (带来临场压迫)
                 |
                 v  (清晰轮廓 / 物理重叠 Overlap)
  [ 中景 Midground (离镜头 5-15 米) ] ---> 角色核心舞台 / 满对比度 / 戏剧冲突爆发点
                 |
                 v  (对比度衰减 / 大气透视 Air Perspective)
  [ 远景 Background (离镜头 50-1000米) ] -> 微弱低对比 / 浅灰剪影 / 雾气吞没 / 地平线广度
```

### 2. 三层空间构建实战四步流
1. **前景框选（Frame the Frame）**:
   - 寻找前景遮挡物：门框、斑驳断墙、马车车轮、潜伏同伴的肩背剪影；将其推至画面边缘，遮挡住画幅的 20%-30%；
2. **中景核心安置（Anchor the Midground Subject）**:
   - 将主体角色置于中景，并确保前景遮挡物部分叠压在中景角色身前，产生确凿的**遮挡前后层次（Overlapping Depth）**；
3. **远景推开大气透视（Push Back Atmospheric Depth）**:
   - 远景的山脉、森林或摩天大楼严禁使用死黑纯线！将其压制为 20%-30% 的浅灰色调，模拟空气中悬浮颗粒对光线的散射（Fog/Haze）；
4. **尺度阶梯递减（Scale Stepping）**:
   - 前景人头高占画幅 80%，中景角色高占画幅 30%，远景行人高占画幅 5%，形成清晰可测的三维空间标尺。

## Actionable Example (构建刺客潜行刺杀公爵的宫殿宴会厅构图)
1. **前景（刺客窥视框架）**:
   - 画面左侧与上方被一根巨大的大理石廊柱与刺客漆黑的兜帽侧脸剪影牢牢占据，呈现深沉的纯黑；
   - 刺客手中出鞘的匕首寒刃反射出一道锐利的白光，悬在前景下方；
2. **中景（宴会厅戏剧舞台）**:
   - 穿过廊柱空隙，中景被金碧辉煌的吊灯照亮；
   - 毫无察觉的公爵手举酒杯，与贵族们开怀大笑，人物轮廓清晰、对比度饱满；
3. **远景（深邃宫殿大殿）**:
   - 宴会厅后方是数十米深的大殿拱门与漫长廊道，层层拱门逐渐没入朦胧的浅灰烟气与阴影中，消失在深邃远方；
4. **结果**: 三层空间的严密咬合，赋予画面无与伦比的临场窒息感与空间真实度。

## Constraints (约束与禁止)
- **严禁全层同等对比度**: 如果远景的山脉画得和前景的刀刃一样黑白分明，空间纵深会瞬间塌陷为扁平贴纸；
- **严禁无遮挡漂浮**: 物体之间若各不相挨、互无重叠，大脑无法建立三维深度序列，必须施加果断的前后空间重叠遮挡。

## Verification (验收标准)
- **空间图层分层检查**: 画面是否能清晰拆解为前景、中景、远景三个物理层次；
- **纵深沉浸感自检**: 观者是否有被拉入画中、透过前景缝隙向内窥探的强烈身临其境感。
