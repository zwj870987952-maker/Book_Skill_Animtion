# 能力卡: 对角斜线、尖锐三角形与几何张力构图 (Diagonals, Triangles & Visual Tension)

## Rationale (核心原理)
在几何心理学与构图动力学中，形状具有直接激发人类神经本能的力量：
- **水平线与垂直线**: 代表大地与引力平衡，传达安全、稳定、永恒、平静与安宁，但过量使用会导致画面呆滞死寂；
- **对角斜线（Diagonals）**: 破坏重力平衡，代表运动矢量、未完成的速度、不稳定性、奔涌的动能与危险；
- **三角形与尖锐锐角（Triangles & Acute Angles）**: 具有极强的方向导向性与侵略性，锐角宛如箭头或长矛直刺核心；
Marcos Mateu-Mestre 告诫画师：
> **“If a scene feels static, search for the hidden diagonals! Tilting the axis, crossing lines, and creating triangular force fields will inject instant adrenaline into the frame!”（如果一个场景显得死板无趣，去寻找隐藏的对角线！倾斜轴线、让线条交错相撞、构建三角形力场，将瞬间向画框注入肾上腺素！）**

## Instruction (几何张力构建与对角线力场四步规程)

### 1. 几何情绪能量阶梯心智模型
```
  [ 稳态能量 (Static) ]   水平线 + 垂直线 (90° 直角) -----> 平静、威严、停滞、秩序
             |
  [ 动态能量 (Kinetic) ]  对角斜线 (30°-60° 倾角) ---------> 速度、冲击、下坠、做功
             |
  [ 危险侵略 (Aggressive) ] 锐角三角形 (< 45° 尖角) --------> 刺穿、暴力、危机逼近、撕裂
```

### 2. 几何张力编排实战四步流
1. **打破水平网格（Break the Orthogonal Grid）**:
   - 避免将墙壁、地平线与道路画成死板的横平竖直，将镜头旋转或走位，使其以斜切对角线切入画框；
2. **构建对抗力场斜线（Opposing Diagonals / X-Crossing）**:
   - 画面中一条向右下方倾斜的大主线（如山坡、光束），必须遭遇一条向左下方倾斜的对抗斜线（如长矛、角色身体挺直的前倾线），两线在视觉上构成对撞绞杀；
3. **三角形稳固 vs. 尖刺倒立（Triangular Dynamics）**:
   - 正三角形（底边在下）: 赋予角色坚不可摧的山峦般防御与威严；
   - 倒三角形（尖端在下）: 赋予动作极度不稳定、随时准备向前方爆发倾泻的动量；
4. **视线汇聚尖端（Vertex as Arrow）**:
   - 将三角形最锋利的锐角尖端精确指向核心戏剧目标（如凶手的刀尖指向受害者咽喉）。

## Actionable Example (调校骑兵冲锋撞击步兵防线的构图)
1. **对角线动能加速跑道**:
   - 整个骑兵方阵的行进轨迹设计为一条从画面左上角凶狠贯穿至右下角的 45° 剧烈下冲斜线；
   - 战马扬起的飞扬泥土、骑兵高举的长矛与披风全部顺应这条斜线平行展开，形成强大的动量流；
2. **对抗斜线对撞**:
   - 右下角的步兵防线长盾与反击长矛组成一道斜向左上的 60° 对抗线，如尖刺拒马般逆流相撞；
3. **三角形爆炸焦点**:
   - 骑兵长矛刺入盾牌交汇的瞬间，二者交汇出多重尖锐三角形几何负空间，火星与碎木向四周喷射；
4. **结果**: 强烈的对角线碰撞与三角形锋芒使画面充斥着骨肉碎裂的巨大冲击力。

## Constraints (约束与禁止)
- **严禁无对冲的孤立斜线**: 画面中若只有单向斜线而没有任何反向力量抵消，观者会产生画面即将“倾覆滑落出画框”的不适感；
- **严禁钝角松散无力**: 表达冲突与危险时，避免使用圆钝宽阔的角度，必须锐化折角以增强侵略性。

## Verification (验收标准)
- **骨架线条动势测试**: 将画面简化为纯线条矢量骨架，线条之间是否充斥着强烈的对角交叉碰撞；
- **动感直觉检验**: 即使画面处于静止单张，观者是否能清晰感知到位移的爆发方向与不可阻挡的速度。
