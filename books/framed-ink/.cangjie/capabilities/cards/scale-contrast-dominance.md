# 能力卡: 尺度悬殊对比、环境吞噬与角色威严霸气 (Scale Contrast, Dominance & Vulnerability)

## Rationale (核心原理)
在视网膜视觉神经学中，“大”与“小”从来不是绝对尺寸，而是**在同一个画框内通过剧烈的相对比例对撞产生的心理威慑力**。
Marcos Mateu-Mestre 指出：
> **“If you want to show that a character is doomed, don’t just draw a sad face — DROWN HIM IN AN IMMENSE WORLD! When the environment occupies 95% of the frame and the character is a mere speck of dust, the drama becomes cosmic!”（如果你想表现一个角色注定毁灭，不要只是画一张悲伤的脸——将他淹没在浩瀚的世界中！当环境占据画框的 95%，而角色只是微不足道的一粒尘埃时，戏剧性就上升到了宇宙级别！）**

相反，当你想表现一个反派的不可战胜时，将其头部推至前景占据画幅的 80%，让远景里正义主角的全力一击看起来微弱如蚊虫叮咬，绝对的支配权（Dominance）便跃然纸上。

## Instruction (尺度悬殊对比编排四步规程)

### 1. 尺度对比两极心理场域心智模型
```
  [ 极小个体 (占画面 2%-5%) vs. 浩大环境 (占画面 95%) ] -> 孤独、脆弱、被自然吞噬、宿命挣扎
  +-----------------------------------------------------------+
  |  (铺天盖地的万丈绝壁 / 惊涛骇浪 / 无垠沙漠)                 |
  |                                                           |
  |        . (微小如黑点的逃亡者)                              |
  +-----------------------------------------------------------+

  [ 极近前景庞然大物 (占画面 70%) vs. 远景微小猎物 (占画面 5%) ] -> 绝对捕食、支配、不可抵挡的威权
  +-----------------------------------------------------------+
  |  /=======\ (前景巨兽的狰狞下颌与利齿)                      |
  |  |       |                                                |
  |  \=======/                 (远景逃亡的士兵小人)           |
  +-----------------------------------------------------------+
```

### 2. 尺度悬殊对比实战四步流
1. **确立戏剧悬殊比率（Determine Scale Ratio）**:
   - 设定主体与环境或对手的面积比率（如 1:20 甚至 1:50）；
2. **极端推开空间景别（Push Extreme Shots）**:
   - 表现脆弱：采用超远全景（Extreme Long Shot），将地平线推到天际，主角退缩为纯黑小剪影；
   - 表现支配：采用大特写前景压迫（Extreme Close-Up Foreground），巨兽的手掌或巨人的战靴占据前景下半部；
3. **保留人本尺度标尺（Keep Human Reference Anchors）**:
   - 庞大建筑或怪兽身旁，必须布置熟悉的人类尺度参考物（如一扇小窗户、一匹马、一棵树），防止观众失去对庞大体积的感知坐标；
4. **视线反差牵引（Contrast Magnetism）**:
   - 即使角色只占 3% 面积，必须通过周围环境线条全部向其汇聚，或让角色成为巨大暗部包围下的唯一白色光斑，确保观者第一眼依然能瞬间锁定。

## Actionable Example (展现独行侠穿越冰封死亡绝壁的孤独绝望)
1. **画幅布局**: 选用 1.85:1 画幅；
2. **环境吞噬设计**:
   - 画面上部 90% 是一座拔地而起、刺破苍穹的纯黑冰川绝壁，陡峭山体上布满如雷电般撕裂的白色冰裂纹；
   - 狂风卷起暴风雪的朦胧斜线充斥全图；
3. **微小主角安置**:
   - 绝壁最下方狭窄的冰棱边缘，独行侠牵着一匹瘦马，缩成一个仅有指甲盖大小的微小黑色剪影；
   - 一道微弱的侧向夕阳金光恰好擦过这具黑色剪影，将其在周围浩瀚的冷黑山体中凸显为唯一的生命火种；
4. **结果**: 自然宇宙的浩大冷酷与人类血肉之躯的顽强生存意志形成悲壮的史诗共振。

## Constraints (约束与禁止)
- **严禁失去尺度参考系**: 绘制巨型战舰或巨兽时，若背景没有云层、山峰或地面微小建筑对比，观众无法感知其“巨大”，只会误以为是个近处的小模型；
- **严禁微小主体被杂乱细节淹没**: 主体虽小，周围必须保留纯净反差，严禁被背景复杂纹理吞噬导致观者找不到主角。

## Verification (验收标准)
- **尺度震撼度测试**: 观者是否能在看到画面的第一秒被场景的巨大体量或角色的压倒性气场深深震撼；
- **微小主角定位速度**: 在 1 秒内，受众是否能在辽阔的宏观大景深中毫不费力地定位到主角的存在。
