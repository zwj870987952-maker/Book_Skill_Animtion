# 能力卡: 故事板节拍编排、景别交替与动作分镜流水线 (Storyboard Cadence, Shot Hierarchy & Action Flow)

## Rationale (核心原理)
单个画面的构图只是“静止的单字”，而故事板（Storyboard）则是**由一系列画格在时空中编织而成的动态交响诗**。
缺乏节拍编排的故事板往往陷入两大致命缺陷：
1. **景别单一无趣**: 连续十几个镜头全是平庸的中景正反打，缺乏大环境交代与特写冲击；
2. **节奏均速拖沓**: 每一格的戏剧停留时间均等，动作毫无轻重缓急与呼吸顿挫。

好莱坞工业级故事板设计要求严谨的**景别层级交替体系（Shot Scale Hierarchy）**与**动作节拍节奏（Editorial Cadence）**：
- **大远景（ELS / Establishing Shot）**: 交代宏观世界观与环境压力；
- **全景（Long Shot）**: 确立角色与环境的空间相对位置；
- **中景（Medium Shot）**: 叙事推进与肢体动作交互的主力；
- **特写与大特写（Close-Up & ECU）**: 戏剧高潮、心理微表情与致命线索的绝对爆破！

## Instruction (故事板节拍编排与动作分镜四步规程)

### 1. 经典影视分镜景别节拍金字塔心智模型
```
  [ 1. 建立环境 ELS/LS (宏观设立) ] ---------> 荒凉小镇 / 烈日当空 (环境压力注入)
                 |
  [ 2. 推进动作 MS/MCU (角色交互) ] --------> 枪手推门步入酒馆 / 众酒客转头注视 (推进冲突)
                 |
  [ 3. 情绪高潮爆破 CU/ECU (致命一击) ] ------> 枪套解开特写 / 瞳孔猛烈收缩 / 枪口喷火!
                 |
  [ 4. 结果余震缓冲 LS/FS (局势重置) ] -------> 尸体倒地尘土飞扬 / 独行侠转身离去
```

### 2. 故事板分镜编排实战四步流
1. **剧本节拍提炼（Beat-by-Beat Breakdown）**:
   - 提取剧本的核心节拍：设定（Setup）、推进（Progression）、转折（Twist）、爆发（Climax）、余震（Aftermath）；
2. **景别交替阶梯设计（Shot Scale Pacing）**:
   - 坚决杜绝同景别连续出现 3 次以上！遵循“远 -> 中 -> 特 -> 远”的波浪式景别阶梯；
3. **动作连贯切分（Cutting on Action）**:
   - 在角色发力动作的最高潮切入下一镜头（如 A 镜头挥刀挥到一半，B 镜头特写刀刃劈中盾牌），利用动量惯性掩盖剪辑痕迹；
4. **故事板阅读流向与附注（Panel Flow & Action Notes）**:
   - 在画格下方严格标注摄影机运动指示（PAN 平移、TILT 俯仰、TRACK 跟随、DOLLY 推拉）与对白音效标注（SFX）。

## Actionable Example (编排一段特工在屋顶遭遇伏击的 4 格动作分镜)
1. **Panel 1 (大远景 ELS，建立危机)**:
   - 暴雨中夜幕笼罩的巴黎屋顶全景，特工在错落的黑色烟囱之间快速奔跑；
   - 远景闪电划过，勾勒出四周 3 名黑衣杀手正在包抄的剪影；
2. **Panel 2 (中景 MS，遭遇伏击)**:
   - 特工冲过一道斜坡，前方一名杀手突然持霰弹枪破窗而出；特工重心下沉准备滑铲；
3. **Panel 3 (大特写 ECU，电光石火爆发)**:
   - 极度紧迫：特工滑铲贴地，右手拔出消音手枪直接顶住杀手下颌，枪口火光在纯黑雨夜中瞬间炸开；
4. **Panel 4 (全景 LS，结果沉降)**:
   - 杀手向后翻滚跌落屋顶天窗，特工滑行在积水中刹车站定，雨水顺着枪口滴落，镜头恢复冷峻客观。

## Constraints (约束与禁止)
- **严禁无动机的乱切镜头**: 每一个画格的切换必须有明确的戏剧动机（交代新信息、强化情绪反应或跟上动作位移）；
- **严禁视觉信息超载**: 单个画格内只讲一件事！严禁在一个画格中企图同时塞入 3 个正在爆发的核心冲突。

## Verification (验收标准)
- **连环翻阅流畅度**: 连续快速翻看故事板序列，动作流向是否清晰如电影动态播放，无断裂卡顿；
- **戏剧呼吸节奏**: 景别大小与镜头密集度是否与故事的情绪高潮完美契合，高潮前有蓄力，高潮后有释放。
