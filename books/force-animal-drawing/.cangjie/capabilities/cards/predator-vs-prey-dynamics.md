# 能力卡: 掠食者进攻与草食者防御动力学 (Predator vs. Prey Dynamics)

## Rationale (核心原理)
在百万年的演化军备竞赛中，捕食者（Predator）与被捕食者（Prey）的骨骼肌理、五官朝向与体态重心形成了截然相反的动力学生理构造。
画师如果不能从生物力学本质区分掠食者与草食动物，画出的老虎就会像温顺的牛犊，画出的斑马也会缺乏逃生的紧绷警觉。
Mike Mattesi 强调：**掠食者是由“聚焦、压缩、低重心潜伏与向心内收的攻击力场”驱动的；而被捕食者则是由“全景感知、高耸警戒、随时四向弹跳逃窜的发散力场”塑造的**。

## Instruction (掠食者 vs 草食被捕食者动力学矩阵)

### 1. 进攻 vs 防御生物力学对比表
| 力学与生理维度 | 掠食者 (Predator - 狮/虎/狼/猛禽) | 草食被捕食者 (Prey - 鹿/马/斑马/野牛) |
| :--- | :--- | :--- |
| **眼睛与视野** | **双眼向前正视 (Binocular Focus)**: 视野重叠大，具备精准立体视距测算与锁定猎物能力 | **双眼位于头侧 (Monocular Panoramic)**: 接近 $360^\circ$ 无死角广角视野，随时察觉地平线异动 |
| **重心高度 ($H_{\text{cog}}$)** | **低重心潜伏**: 重心紧贴地面，关节深度屈曲，身体呈水平扁平流线 | **高重心悬空**: 四肢修长如高跷，躯干悬在高空，便于视野开阔与大步幅狂奔 |
| **颈部与头部姿态** | 头颅常与脊背齐平甚至低垂，下巴内收向前，如拉紧的弓弩蓄势待发 | 长颈高高垂直耸立（Periscope 潜望镜形态），头部处于全身最高点以远眺 |
| **肩背与肌肉力矩** | 肩胛骨沿胸壁大幅隆起，胸肌粗壮，前爪强健可抓抱摔角 | 肩部平滑贴合，胸腔狭深（用于长途通气），前肢仅负责向前摆动 |
| **神经与动作张力** | **凝聚向心压缩力 (Coiled Inward Tension)**: 潜伏时如一团压缩的弹簧，伺机爆破 | **离心散射逃逸力 (Explosive Centrifugal Strain)**: 肌肉紧绷，肌腱绷紧如拉满的钢丝 |

```
【掠食者: 水平压缩向心力场】                 【草食被捕食者: 垂直高耸逃逸力场】
          (双眼正视 Focus)                           (潜望镜长颈 Periscope)
               v                                              ^
  [低平头颅] <==== [扁平低伏躯干] ===== [蓄力后腿]               | [高耸头颅+侧视眼睛]
      |                               |                       |
   (贴地潜行，前爪扑击)             (弹簧待发)            [狭深胸廓] ====== [高位骨盆]
                                                              |                 |
                                                          [高跷长腿]        [高位长炮骨]
```

### 2. 角色设计中的符号化运用
- **进攻姿态构建**:
  - 降低动物肩部与胸部高度，使前额与地面倾角小于 $20^\circ$；
  - 缩短颈部视觉露出，将前腿关节大幅度内折，线条密集向前聚合；
- **防御/惊恐逃窜构建**:
  - 极大拉长颈部线条，头部猛烈向后上方抽离；
  - 四肢线条垂直坚挺、末端蹄尖轻盈点地，随时准备向任意对角线方向无惯性弹射。

## Actionable Example (非洲狮潜行伏击 vs 瞪羚受惊跳跃)
1. **绘制伏击非洲狮**:
   - 抓取一条极平缓贴近地面的波形力线：头部低垂至两肩前下方，下巴距离地面仅数寸；
   - 肩胛骨高耸刺破背部轮廓；后腿飞节贴近腹部极度压缩，全身肌肉呈蓄能压扁态；
   - 目光双线平行笔直向前射穿画面，牢牢咬死目标；
2. **绘制受惊跳跃瞪羚**:
   - 抓取一条垂直高拔的折线：长颈几乎垂直于地面拔起，头部警惕后仰，耳朵竖立成雷达状；
   - 躯干高高悬挂在四根如箭杆般的纤细长腿之上，蹄尖几乎不沾地面，呈现反重力的悬浮感。

## Constraints (约束与禁止)
- **严禁草食动物低头伏击视线**: 草食动物低头进食时身体也是警觉松散的，绝不可画出掠食者特有的双眼聚焦凝视感；
- **严禁将掠食者画成高跷身架**: 狮虎如果四肢过长、重心过高，就会丧失潜伏与摔抱大型猎物的物理可信度；
- **严禁眼睛朝向混淆**: 掠食者眼睛必须长在正面，草食者眼睛必须长在头部两侧。

## Verification (验收标准)
- **意图可读性**: 不看动物外形轮廓，仅凭姿态力线，观者是否能清晰判断其处于“捕猎进攻”还是“警觉防御/逃生”状态；
- **重心高低测量**: 掠食者质心高度是否显著低于同等体量草食动物。
