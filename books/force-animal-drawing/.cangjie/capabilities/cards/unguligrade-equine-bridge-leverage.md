# 能力卡: 蹄行动物奇蹄偶蹄长杠杆力矩 (Unguligrade Equine Bridge & Leverage)

## Rationale (核心原理)
蹄行哺乳动物（奇蹄目如马、斑马；偶蹄目如鹿、牛、羚羊、长颈鹿）代表了生物力学中**机械传动效率与长杠杆力矩的演化巅峰**。
与猫科动物柔软的弓弦脊椎不同，马等大型草食动物的脊椎是一个**高刚性悬索桥（Rigid Suspension Bridge）**：它横跨在肩胛骨与骨盆两大桥墩之间，用于在承受重达数千磅内脏重量的同时，以最小的肌能消耗维持巡航奔跑。
而在其四肢末端，掌骨/跖骨极端拉长并融合为超长刚体——**炮骨（Cannon Bone）**，动物仅靠角质指甲（蹄）触地，形成陆生动物中最长的摆动杠杆手臂。

## Instruction (悬索桥脊椎与超长炮骨杠杆)

### 1. 马体悬索桥力学架构
```
       [ 前桥墩: 肩胛骨与前腿 ]                  [ 后桥墩: 骨盆与后腿 ]
             /                                         \
            /                                           \
    =======O=============================================O=======
           |  \                                       /  |
    (项韧带 Ligament)  \  [ 桥索: 刚性悬索脊椎 Rigid Spine ] /   |
           |     \     ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~    /    |
           |      \                                   /      |
       [头部悬臂]    [ 悬挂负载: 巨大胸腹部内脏 Mass (500kg) ]   [推进力来源]
```
1. **水平桥梁脊椎**: 马的背部从肩峰（Withers）到十字部（Croup）几乎保持刚性水平，奔跑时垂直上下起伏极小（防止巨大的盲肠和胃部在腔内震荡造成内脏损伤）；
2. **项韧带悬索（Nuchal Ligament）**: 一条强大的弹性韧带如悬索拉索般从背部高耸的脊椎棘突一直连接到颅骨枕骨，不用肌肉收缩就能自动抵消沉重头颅的下坠重力；
3. **炮骨长杠杆（Cannon Bone Leverage）**:
   - 飞节（Hock）被抬高至下肢 $50\%$ 的高度；
   - 飞节以下到球节（Fetlock）之间是长达 40-50 厘米的垂直无肌炮骨（仅有致密肌腱滑车系统），挥动惯性极小，步幅巨大。

### 2. 奇蹄目（马）vs 偶蹄目（鹿/牛）力学差异
| 对比维度 | 奇蹄目 (Perissodactyla - 马/斑马) | 偶蹄目 (Artiodactyla - 鹿/羚羊/牛) |
| :--- | :--- | :--- |
| **负重中轴** | 单指（第三指/趾高度发达骨化成单蹄） | 双指（第三、四指/趾平分体重，形成开叉双蹄） |
| **地表适应** | 平坦开阔坚硬平原高速直线巡航 | 崎岖山地、泥沼、林地，双蹄开合具备抓地微调力 |
| **脊椎刚性** | **极高刚性**：背线平直，靠后腿独立推进 | **中等刚性**：鹿与羚羊脊椎具备弹跳弯曲度，善于跳跃（Pronking） |
| **骨盆角度** | 相对倾斜角平缓，推力方向更偏向水平向后 | 骨盆下倾角陡峭，利于垂直向上起跳逃逸 |

## Actionable Example (纯血马奔跑动态力量线)
1. **第一笔（平直桥梁脊椎）**:
   - 划出一条强劲、平缓微沉而后水平收住的脊背力线，从肩隆（Withers）延伸至十字部（Croup），表现高强度钢梁般的承托力；
2. **第二笔（超长垂直炮骨）**:
   - 后腿飞节高悬于半空，向下一笔拉出坚挺硬朗的炮骨直线；
   - 炮骨末端在球节处向后稍作微屈过渡，随后以坚硬的角质单蹄猛烈插击地面；
3. **第三笔（项韧带与长颈张力）**:
   - 从肩峰划出一条向上隆起、充满伸肌张力的优美颈项弧线，直达耳根与下颌。

## Constraints (约束与禁止)
- **严禁将马背画成猫狗式的过度弓背**: 马的胸腰椎绝对无法做出猫科动物那种向腹部极限折叠的弓形动作，画出此类形变会导致骨折般的荒诞感；
- **严禁弱化飞节高度**: 蹄行动物的飞节如果画得离地过近，马腿就会退化成短腿骡子或狗腿；
- **严禁忽略球节（Fetlock）与蹄系（Pastern）的弹性斜角**: 触地瞬间蹄系必须呈 $45^\circ \sim 50^\circ$ 前倾受压，展现悬韧带吸收撞击的弹性缓冲。

## Verification (验收标准)
- **杠杆比例校验**: 飞节下方的炮骨长度是否占下肢总长的 $40\% \sim 50\%$；
- **悬索刚度校验**: 奔跑过程中脊背中段是否保持沉稳刚性的桥跨结构。
