# 能力卡: 四足步态行走、小跑与飞奔时序 (Quadruped Gait Timing)

## Rationale (核心原理)
四足动物的步态运动不是机械的腿部摆动，而是**重心在动态平衡与自由落体之间的高精度时空转移**。
在历史上，埃德沃德·迈布里奇（Eadweard Muybridge）的连续摄影彻底打破了“马奔跑时前后腿向外反向劈叉”（Rocking Horse 摇马幻觉）的错误认识。
Mike Mattesi 强调：掌握四足动物的行走（Walk）、小跑（Trot）与飞奔（Gallop）三大基础步态，本质是理解四只脚何时为身体提供支撑三角面，何时让身体重力完全离地抛射。
只有掌握严格的落足时序与身体重心波形，动画师和速写创作者才能捕捉到四足动物奔跑中令人窒息的速度与律动。

## Instruction (三大步态足序与力学时序表)

### 1. 三大陆生四足步态对比表
| 步态类型 | 拍子与节奏 (Beats) | 触地足序 (Footfall Sequence) | 腾空期 (Suspension) | 重心起伏与身体姿态 |
| :--- | :--- | :--- | :--- | :--- |
| **行走 (Walk)** | **四拍均等节奏 (4-beat)**: 1-2-3-4 均匀敲击 | **LH $\to$ LF $\to$ RH $\to$ RF** (左后 $\to$ 左前 $\to$ 右后 $\to$ 右前) | **无腾空期**: 始终有 2 至 3 只脚同时触地，三角形支撑面稳定交替 | 重心起伏较小，骨盆与肩胛骨呈现反向小幅倾斜摆动 |
| **小跑 (Trot)** | **两拍对角节奏 (2-beat)**: 1-2, 1-2 双响 | **(LH + RF) $\leftrightarrow$ (RH + LF)** (左后与右前同时触地，随后右后与左前同时触地) | **有极短腾空期**: 对角肢体交替转换瞬间，四足有 1-2 帧完全离地 | 身体呈极高的水平对称刚性，躯干无扭曲，上下颠簸剧烈 |
| **飞奔 (Gallop)** | **四拍/非对称节奏 (4-beat asymmetrical)** | **LH $\to$ RH $\to$ LF $\to$ RF** (后腿先后蹬出 $\to$ 前腿先后触地缓冲) | **明确腾空期 (Suspension)**: 至少有 1 个或 2 个全离地阶段（聚拢或伸展腾空） | 脊椎剧烈屈伸，腰背如波浪起伏，重力在腾空时完全被抛射 |

```
【四足行走 4-Beat 循环落足图谱】
  Frame 1: 左后腿 (LH) 落地推进
  Frame 2: 左前腿 (LF) 落地支撑
  Frame 3: 右后腿 (RH) 落地推进
  Frame 4: 右前腿 (RF) 落地支撑
  * 核心规律: 后腿永远先动，同侧前腿紧随其后！

【两拍快跑 Trot (对角连线)】          【极速飞奔 Gallop (极端屈伸)】
    LF (触地) ---- RF (悬空)               (前腿落地缓冲 LF/RF)
        \         /                                 \
         \       /                                   \ [脊椎拉平伸长]
          \     /                                     \
    LH (悬空) ---- RH (触地)                 (后腿离地飞跃 LH/RH)
   [对角线 (LF+RH) 形成刚性支点]
```

### 2. 飞奔中的“聚拢腾空” vs “伸展腾空”
- **旋转飞奔 (Rotary Gallop - 猎豹/猎犬)**:
  - 拥有**两次离地腾空期**：一次是四肢在腹部下方极度收拢折叠的“腹下聚拢腾空（Gathered Suspension）”；另一次是四肢在空中前后完全拉开伸展的“拉伸腾空（Extended Suspension）”；
- **横向飞奔 (Transverse Gallop - 马/大型蹄类)**:
  - 通常只拥有**一次离地腾空期**——即四肢收于腹下时的聚拢腾空，伸展状态下往往至少有一只前腿仍在地面滑行。

## Actionable Example (猎豹飞奔关键姿态捕捉)
1. **画极端收拢姿态 (Gathered)**:
   - 脊椎向上极度弯折拱起成拱门，骨盆深扣前倾；
   - 两条后腿大腿紧贴肋骨，后脚爪远远探出到前腿外侧前方；
   - 身体完全脱离地平面，四爪全缩在空中，能量蓄满如紧绷的铁球；
2. **画极端伸展姿态 (Extended)**:
   - 脊椎向下拉长拉平，甚至腰部微向地面下凹；
   - 前肢像长矛一样笔直刺向前方地平线，后腿像拖网一样笔直向后甩出；
   - 全身形成一条几乎与地面平行的水平箭头，展现离弦之箭的极速动量。

## Constraints (约束与禁止)
- **严禁摇马式劈叉落地 (Rocking Horse Fallacy)**: 绝对不可画成四条腿同时向前后两端伸直并在空中停滞，这在自然界物理上是不存在的错误；
- **严禁行走时同侧肢体同步落地 (除非骆驼踱步 Pace)**: 绝大多数哺乳动物行走都是对角交错支撑，切忌画成同侧两腿同时迈出的同手同脚（Pace 仅属于骆驼、长颈鹿等极少数物种）；
- **严禁马背在小跑时过度下凹**: Trot 步态要求马脊椎保持最高刚性，若画成波浪形会导致机械结构崩塌。

## Verification (验收标准)
- **步态节奏对照**: 检查序列中每一帧的触地腿数是否符合对应步态的物理定律（Walk 2-3腿，Trot 2腿，Gallop 0-1-2腿）；
- **重心转移平滑度**: 身体质心轨迹是否呈现连续的重力抛物线。
