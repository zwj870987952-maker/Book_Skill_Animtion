# 能力卡: 挤压拉伸与恒定容积重力感 (Squash & Stretch & Constant Volume)

## Rationale (核心原理)
“挤压与拉伸”（Squash and Stretch）是动画十二黄金法则之首。然而在实际创作中，很多艺术家极易将角色画成“忽大忽小的充气气球”——拉伸时体积暴增，挤压时肉量蒸发。
Walt Stanchfield 强调：**挤压与拉伸不是为了追求橡皮泥式的失真，而是为了表现生命肉体在承受大地重力与加速度做功时的真实物理重量感（Weight & Gravitational Pressure）**。
其不可动摇的物理硬门在于：**质量与体积必须绝对守恒（Constant Volume Rule）**！
当活体或柔性组织在一个轴向上被重力压扁挤压（Squash）时，它在另外两个轴向上必须发生等量的横向膨胀；当其在一个轴向上被拉长（Stretch）时，其腰身截面必须相应收窄变细。

## Instruction (体积守恒形变公式与重力挤压步骤)

### 1. 恒定体积物理形变守恒公式
$$V = X \times Y \times Z = \text{Constant}$$
- **挤压态 (Squash - 触地撞击 / 蓄能预备)**:
  - 若垂直高度 $Y$ 压缩为原本的 $60\%$（$Y' = 0.6 Y$）；
  - 则横向宽度 $X$ 与空间深度 $Z$ 必须膨胀为原本的约 $129\%$（$X' = 1.29 X, Z' = 1.29 Z$）；
  - 表现出肌肉肉块受挤压向四周溢出、饱满下垂的沉重质感；
- **拉伸态 (Stretch - 极速弹射 / 自由落体下坠)**:
  - 若垂直高度 $Y$ 拉伸为原本的 $150\%$（$Y' = 1.5 Y$）；
  - 则横向宽度 $X$ 与空间深度 $Z$ 必须紧缩为原本的约 $81.6\%$（$X' = 0.816 X, Z' = 0.816 Z$）；
  - 表现出肌肉紧绷变细、充满蓄势待发的纤维张力。

```
【中立态 Neutral】              【极速拉伸 Stretch】              【着地挤压 Squash】
      +-------+                        +---+                            +---------------+
      |       |                        |   | (变长变窄)                  |               | (变扁变宽)
      |   V   |                        | V |                            +---------------+
      |       |                        |   |                             (横向膨胀 / 容积守恒)
      +-------+                        +---+
                                   (收紧变细 / 容积守恒)
```

### 2. 人体各解剖构件的刚性与柔性分层
- **刚性骨骼不变体块**: 头颅骨、胸腔骨架（轻微柔性）、骨盆（绝对刚体）；这些部位绝不能像果冻一样随意挤压变形；
- **柔性血肉形变区域**: 颈部、腰腹软组织（肚腩与腹外斜肌）、大腿与小腿肌腹、臀部脂肪；挤压与拉伸主要发生在这些关节与肌肉连接段上。

## Actionable Example (大力士重重坐入沙发的 Squash 刻画)
1. **中立站立**: 大力士腰腹与大腿保持正常比例；
2. **臀部撞击沙发瞬间 (Squash)**:
   - 骨盆被沙发面急剧托住，躯干高度压扁 $35\%$；
   - 腹部与腰侧肌肉受强压横向大幅爆开外溢，搭在腰带上方形成饱满下垂的横向宽体块；
   - 脸颊肉受惯性下坠下垂，下巴与脖子堆叠出三道饱满的重叠双下巴肉褶；
3. **体积校验**: 尽管人物矮了一截，但整个人物在画面上的总面积与质量感显著增强，沙发坐垫被压陷深坑，重力感破屏而出。

## Constraints (约束与禁止)
- **严禁等轴缩放 (Uniform Scaling)**: 绝不能将形变画成同比例整体放大或缩小，必须一轴收缩、另两轴扩张；
- **严禁无质量果冻软泥 (Rubber Hose Without Weight)**: 挤压拉伸必须有重力与反作用力的物理因果驱动，不可为了变形而无理形变；
- **严禁破坏头骨刚性**: 除非极为夸张的特克斯·艾弗里式滑稽动画，写实与半写实角色的眼眶骨与下颌骨必须保持骨骼刚度。

## Verification (验收标准)
- **容积测量检验**: 关键帧序列中，拉伸姿态与挤压姿态的投影总容积误差是否控制在 $5\%$ 以内；
- **重力可信度**: 挤压发生的部位是否精准对应重力下砸的撞击接触面。
