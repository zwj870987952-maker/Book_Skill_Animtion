# 能力卡: 剪影清晰度与舞台视线引导 (Silhouette Clarity & Staging)

## Rationale (核心原理)
动画是时间流逝中的视觉艺术，观众的大脑在每一帧画面上停留的时间往往只有二十四分之一秒。
如果在这一瞬间动作意图无法被直接读懂，观众就会感到困惑，动画的叙事魔力就会彻底瓦解。
Walt Stanchfield 强调：**动画的最高美学标准之一是“清晰度”（Clarity）与“纯黑剪影可读性”（Silhouette Readability）**。
一个成功的动作姿态，**即使被彻底涂抹为一团死黑剪影，它的情绪、手势、视线朝向以及核心道具也必须在 0.1 秒内被瞬间理解**。
为了实现这种绝对清晰度，创作者必须：
1. **展开肢体打破身体内侧泥泞团块（Open the Pose）**；
2. **严密排查并消灭一切“切线”（Tangents）**。

## Instruction (剪影测试规程与消灭切线六大法则)

### 1. 纯黑剪影测试（The Black Silhouette Test）
```
  [ 错误姿态: 肢体粘连在躯干内侧 ]               [ 正确姿态: 剪影展开 / 瞬间可读 ]
             (头)                                          (头)
          /========\                                     /======\
         |  (手胸)  |  (手脚抱在胸腹前，剪影是一团泥)    |        |---\ (手势指向空间)
         |  (泥团)  |                                   |  (躯干) |   \
          \========/                                     \======/     O (道具突出轮廓)
            |    |                                        /    \
                                                         /      \ (迈开大步 / 三角负空间)
```
- **核心操作**:
  - 在草图阶段，将线稿整体填充为全黑纯色块；
  - 检查关键叙事元素（持枪手、指向手势、惊恐表情、道具轮廓）是否全部清晰“凸出”在躯干外轮廓之外，绝不能贴在胸腹内部化为黑糊糊的一团。

### 2. 空间切线（Tangents）的七大杀手与纠偏
切线是两条空间深度不同的物体轮廓线在二维纸面上无意中“相切或刚好并列接触”，它会彻底摧毁画面深度并将空间压扁为纸片：
| 切线类型 | 错误形态表现 | 空间塌陷后果 | 正确纠偏法则 |
| :--- | :--- | :--- | :--- |
| **边缘擦碰切线** | 手臂轮廓线刚好与身躯外边缘贴合擦碰 | 观众无法分辨手臂是在身前还是身后 | **大幅重叠 (Overlap)** 或 **彻底拉开间隙 (Negative Space)** |
| **末端对齐切线** | 手指尖端刚好落在腰带线或门框边缘上 | 手指仿佛粘在背景门框上，失去空间距离 | 缩短或拉长手臂，打破水平等高 |
| **关节对齐切线** | 膝关节横线与背景地平线刚好重合 | 角色下半身被地平线切断 | 调整地平线高低，使其穿透大腿或小腿中段 |
| **方向共线切线** | 剑身轴线刚好与后景立柱边缘在一条直线上 | 剑失去独立三维角度，融入背景立柱 | 旋转剑身倾斜角度，形成明确的相交夹角 |

## Actionable Example (修改一名侦探持放大镜的姿态)
1. **原始错误稿**:
   - 侦探双手将放大镜举在胸前，手和放大镜都在胸腔剪影内部；
   - 涂黑后，剪影看起来像一个挺着大肚腩的臃肿矮子，完全看不出是在查案；
2. **迪士尼大师级修正**:
   - 让侦探身体向后倾斜拉伸，将持放大镜的手臂向前大幅度伸出，使放大镜和弯曲手肘完全“悬空”在躯干外轮廓前方；
   - 放大镜内部镂空出清晰的透明圆形负空间；
   - 头部前探，视线穿过放大镜；
3. **效果**: 涂黑剪影后，即使闭上一只眼睛在 5 米外看，也能瞬间识别出这是一名正在专注搜寻线索的侦探。

## Constraints (约束与禁止)
- **严禁肢体自相并拢遮挡**: 核心做功肢体绝不能紧贴大腿或胸口，必须在肢体与身体之间拉出透气的负空间三角形；
- **严禁双腿紧并成单柱**: 站立行走时双腿之间必须留出光线能够穿透的负空间缝隙，防止剪影变成无腿圆筒；
- **严禁任何形式的切线并列**: 只要出现两条轮廓线刚好相切，必须立刻二选一——要么狠狠重叠，要么彻底分开！

## Verification (验收标准)
- **0.1 秒剪影盲测**: 找一个未看过草图的观者看纯黑剪影，能否在 1 帧时间内准确说出角色的动作与手持道具；
- **零切线自查**: 画面中所有交叉轮廓线是否均为清脆坚定的 T 型交错（T-Junctions）。
