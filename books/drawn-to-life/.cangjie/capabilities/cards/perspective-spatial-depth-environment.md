# 能力卡: 空间进深、透视力学与角色环境互动 (Space, Perspective & Ground Plane)

## Rationale (核心原理)
很多画师画出的角色，仿佛漂浮在毫无重力的真空中，脚底与地面接触虚浮，角色与周围的桌椅、墙壁和门窗像贴在不同图层上的孤立贴纸。
迪士尼大师 Walt Stanchfield 强调：**没有无环境的纯粹角色，角色永远生活在一个具有三维重力场与透视网格的真实空间中（The Ground Plane & Environment）**。
角色与环境的关系是绝对物理互动的：
1. **地平面法线与坚实接触（Planting on the Ground Plane）**：双脚必须真正“压入”地平面，地面必须提供向上支撑的法线反作用力；
2. **环境对身体力矩的反作用（Interacting with Props）**：靠墙、坐椅、倚栏杆或提重物，环境必须切实吸收或改变角色的重心中轴；
3. **透视包围感（Perspective Enclosure）**：通过前景、中景与后景的层叠与尺寸衰减，让角色被三维空气完全包裹。

## Instruction (地平面锚定与环境互动构建流程)

### 1. 地平面锚定（Ground Plane Anchoring）几何法则
```
               ---------------- 视平线 (Eye Level / Horizon) ----------------
                     /                                               \
                    /                                                 \
                   /  [ 远景脚部触地点 (垂直位置高 / 尺寸小) ]           \
                  /                 \                                   \
                 /                   \== [ 坚实三维地平面透视网格 ] ===== \
                /                                                         \
               [ 近景承重足 (垂直位置低 / 尺寸大 / 完全压死地平线法线) ]
```
- **触地点决定空间纵深**:
  - 绝不能把站立行走的两只脚画在同一水平横线上（除非正交平视且并拢）；
  - 迈出的前脚与后腿触地点之间必须有明确的垂直高度落差 $\Delta Y$ 与透视对角线连线；
- **足底肉垫受压形变**:
  - 踩在地面上的脚底不能画成圆滑弧线，受重力挤压必须画成一条**完全贴死地平面的平直线**，鞋底两端因负重微微受挤上翘。

### 2. 角色与环境道具相互做功矩阵
| 环境交互场景 | 环境道具的物理状态 | 角色身体的力矩代偿形变 | 空间真实感关键点 |
| :--- | :--- | :--- | :--- |
| **疲惫靠在砖墙上** | 砖墙提供坚硬垂直阻挡力 | 身体骨盆与肩膀向墙面深凹压实，脊椎产生水平剪切力矩 | 衣服在身体与墙面接触点被压平，形成闭塞接触阴影（Ambient Occlusion） |
| **单手撑在吧台上** | 吧台台面承受上半身 $60\%$ 重力 | 支撑臂肩膀被向上顶起（肩峰耸高），躯干向同侧深陷倾斜 | 吧台边线必须明确穿插在手臂后方，形成前后遮挡 |
| **陷入泥泞或厚地毯** | 地表凹陷吞没脚踝下段 | 角色脚部轮廓被地面边缘部分截断，重心更显深陷沉重 | 严禁脚悬空漂浮在草地或泥土表面上，必须画出下沉深度 |

## Actionable Example (绘制一位斜靠在路灯柱下吸烟的流浪汉)
1. **画地平面与透视网格**:
   - 确定一条微仰视平线；画出人行道地砖向远处消失点汇聚的透视斜线；
2. **角色与路灯柱接触**:
   - 右肩与右大臂结结实实地撞在路灯金属柱外表面上，大臂肌肉被硬柱子压出一个明显的内陷凹弧；
   - 躯干向左侧大倾斜，骨盆向外伸出，右脚踩在路灯底座台阶上（触地点较高），左脚踩在下方路面上（触地点较低且放大 $140\%$）；
3. **接触阴影加重**:
   - 在左脚鞋底与水泥路面接触的窄缝处，用一记深重的死黑接触阴影将脚掌死死“焊”在地面上；
4. **效果**: 观者能切实感受到金属柱的冰冷坚硬与地面的坚实平整，流浪汉与街头环境浑然一体。

## Constraints (约束与禁止)
- **严禁角色双脚悬空漂浮 (Floating Feet Syndrome)**: 任何时候脚底必须有明确的地面阴影或法线咬合，决不能像漂在水里一样；
- **严禁道具毫无负重变形**: 角色坐椅子时椅子垫不凹陷、提包时提带不绷直，都会瞬间破坏物理真实感；
- **严禁角色与背景透视冲突**: 角色的近大远小衰减率必须与背景建筑或地砖的透视灭点严格保持在同一几何视平线系统内。

## Verification (验收标准)
- **接触阻力检验**: 观察角色与地表及道具的接触边缘，是否有明确的受压扁平形变与重力闭塞阴影；
- **空间包裹感**: 角色是否呈现被环境空气包裹的前后纵深层次，而非浮在背景层上方的贴纸。
